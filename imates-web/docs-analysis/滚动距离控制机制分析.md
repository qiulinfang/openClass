# 滚动距离控制机制分析

## 一、概述

PDF查看器的滚动距离控制涉及多个场景：双指滑动、惯性滚动、鼠标滚轮滚动和缩放时的滚动补偿。本文档详细分析各种场景下的滚动距离计算和控制机制。

## 二、滚动容器获取

### 2.1 获取滚动容器

```typescript
// PdfPage.vue - getScrollContainer
const getScrollContainer = (): HTMLElement | null => {
  let parent = pdfCanvas.value?.parentElement
  
  while (parent) {
    // 1. 优先查找 Quasar 虚拟滚动容器
    if (parent.classList.contains('q-virtual-scroll')) {
      const scrollContent = parent.querySelector('.q-virtual-scroll__content')
      if (scrollContent?.parentElement) {
        return scrollContent.parentElement as HTMLElement
      }
      return parent
    }
    
    // 2. 查找有滚动条的父元素
    const overflowY = window.getComputedStyle(parent).overflowY
    if (overflowY === 'auto' || overflowY === 'scroll') {
      return parent
    }
    
    parent = parent.parentElement
  }
  
  // 3. 默认返回 document.documentElement
  return document.documentElement
}
```

**查找优先级**：
1. Quasar虚拟滚动容器（`.q-virtual-scroll`）
2. 有滚动条的父元素（`overflow-y: auto/scroll`）
3. 文档根元素（`document.documentElement`）

## 三、双指滑动滚动距离

### 3.1 滚动距离计算

```typescript
// PdfPage.vue - handleTouchMove
if (event.touches.length === 2 && touchState.value.isTwoFinger) {
  // 判断是缩放还是滑动
  const currentDistance = getDistance(touch1, touch2)
  const initialDistance = touchState.value.initialDistance
  const currentY = getTwoFingerCenterY(event.touches)
  const deltaY = Math.abs(currentY - touchState.value.startY)
  const distanceChange = Math.abs(currentDistance - initialDistance)
  
  // 如果距离变化较小，且垂直移动较大，则认为是滑动
  if (!touchState.value.isZooming && deltaY > distanceChange) {
    const scrollContainer = getScrollContainer()
    if (scrollContainer) {
      // 计算滚动距离：当前Y坐标 - 上次Y坐标
      const deltaY = currentY - touchState.value.lastY
      
      // 直接应用滚动距离（负号表示向上滚动）
      scrollContainer.scrollTop -= deltaY
      
      // 更新上次Y坐标
      touchState.value.lastY = currentY
    }
  }
}
```

**关键点**：
- **滚动距离** = `currentY - lastY`（双指中心点的Y坐标差值）
- **滚动方向**：向上滑动时`deltaY > 0`，`scrollTop`减少（内容向上移动）
- **1:1映射**：手指移动1像素，页面滚动1像素

### 3.2 速度计算（用于惯性滚动）

```typescript
// 记录速度（用于惯性滚动）
const now = Date.now()
if (touchState.value.lastMoveTime > 0) {
  const timeDelta = now - touchState.value.lastMoveTime
  if (timeDelta > 0) {
    // 计算速度（像素/毫秒），负号表示向上滚动
    const velocity = -deltaY / timeDelta
    
    // 记录速度历史（保留最近10次）
    touchState.value.velocities.push(velocity)
    if (touchState.value.velocities.length > 10) {
      touchState.value.velocities.shift()
    }
    
    // 计算平均速度（使用最近5次的速度）
    const recentVelocities = touchState.value.velocities.slice(-5)
    touchState.value.velocity = recentVelocities.reduce((a, b) => a + b, 0) / recentVelocities.length
  }
}
touchState.value.lastMoveTime = now
```

**速度计算**：
- **速度单位**：像素/毫秒（px/ms）
- **速度方向**：向上滚动为负值，向下滚动为正值
- **平滑处理**：使用最近5次速度的平均值，避免抖动

## 四、惯性滚动距离

### 4.1 启动惯性滚动

```typescript
// PdfPage.vue - handleTouchEnd
if (touchState.value.isTwoFinger && !touchState.value.isZooming) {
  // 如果是滑动（不是缩放），且有速度，启动惯性滚动
  if (touchState.value.velocities.length > 0 && Math.abs(touchState.value.velocity) > 0.1) {
    // 将速度从像素/毫秒转换为像素/帧（假设60fps，每帧16ms）
    const velocityPerFrame = touchState.value.velocity * 16
    startMomentumScroll(velocityPerFrame)
  }
}
```

**启动条件**：
- 双指滑动结束（不是缩放）
- 有速度历史记录
- 速度绝对值 > 0.1 px/ms

**速度转换**：
- 从像素/毫秒转换为像素/帧
- 假设60fps，每帧16ms
- `velocityPerFrame = velocity * 16`

### 4.2 惯性滚动动画

```typescript
// PdfPage.vue - startMomentumScroll
const startMomentumScroll = (initialVelocity: number) => {
  // 摩擦力系数（每次减少速度的比例）
  const friction = 0.95
  // 最小速度阈值（低于此值停止滚动）
  const minVelocity = 0.05
  
  momentumVelocity = initialVelocity
  
  const animate = () => {
    // 1. 检查速度是否太小
    if (Math.abs(momentumVelocity) < minVelocity) {
      momentumAnimationFrame = null
      momentumVelocity = 0
      return
    }
    
    // 2. 应用速度（每帧滚动距离）
    scrollContainer.scrollTop += momentumVelocity * 16 // 16ms 一帧
    
    // 3. 检查是否到达边界
    const maxScrollTop = scrollContainer.scrollHeight - scrollContainer.clientHeight
    if (scrollContainer.scrollTop <= 0) {
      scrollContainer.scrollTop = 0
      momentumVelocity = 0
      momentumAnimationFrame = null
      return
    }
    if (scrollContainer.scrollTop >= maxScrollTop) {
      scrollContainer.scrollTop = maxScrollTop
      momentumVelocity = 0
      momentumAnimationFrame = null
      return
    }
    
    // 4. 应用摩擦力（速度衰减）
    momentumVelocity *= friction
    
    // 5. 继续下一帧
    momentumAnimationFrame = requestAnimationFrame(animate)
  }
  
  momentumAnimationFrame = requestAnimationFrame(animate)
}
```

**滚动距离计算**：
- **每帧滚动距离** = `momentumVelocity * 16`（像素）
- **速度衰减**：每帧速度乘以摩擦力系数（0.95）
- **停止条件**：
  - 速度绝对值 < 0.05 px/帧
  - 到达滚动边界（顶部或底部）

**物理模拟**：
- **摩擦力系数**：0.95（每帧速度减少5%）
- **帧率**：60fps（每帧16ms）
- **衰减曲线**：指数衰减，速度逐渐减小

### 4.3 停止惯性滚动

```typescript
// PdfPage.vue - stopMomentumScroll
const stopMomentumScroll = () => {
  if (momentumAnimationFrame !== null) {
    cancelAnimationFrame(momentumAnimationFrame)
    momentumAnimationFrame = null
  }
  momentumVelocity = 0
}
```

**停止时机**：
- 用户开始新的滑动操作
- 到达滚动边界
- 速度衰减到阈值以下

## 五、鼠标滚轮滚动距离

### 5.1 滚轮滚动

```typescript
// PdfPage.vue - handleWheel
const handleWheel = (event: WheelEvent) => {
  // 如果按住Ctrl键，则进行缩放
  if (event.ctrlKey || event.metaKey) {
    // ... 缩放逻辑
  } else {
    // 否则正常滚动
    const scrollContainer = getScrollContainer()
    if (!scrollContainer) return
    
    // 直接使用浏览器提供的滚动距离
    scrollContainer.scrollTop += event.deltaY
  }
}
```

**滚动距离**：
- **直接使用**：`event.deltaY`（浏览器提供的滚动距离）
- **单位**：像素（px）
- **方向**：`deltaY > 0`向下滚动，`deltaY < 0`向上滚动

**特点**：
- 浏览器自动处理滚动距离
- 支持平滑滚动（如果浏览器启用）
- 支持加速滚动（根据滚轮速度）

### 5.2 Ctrl+滚轮缩放


## 六、缩放时的滚动补偿

### 6.1 滚动补偿原理

缩放时，需要调整滚动位置，使缩放点（鼠标位置）保持在视口中的相同位置。

```typescript
// PdfPage.vue - zoomAtPoint
const zoomAtPoint = async (point: { x: number, y: number }, oldScale: number, newScale: number) => {
  const scrollContainer = getScrollContainer()
  if (!scrollContainer) return
  
  // 1. 计算缩放点在文档中的绝对位置（相对于文档顶部）
  const containerRect = scrollContainer.getBoundingClientRect()
  const pointRelativeToContainer = {
    x: point.x - containerRect.left,
    y: point.y - containerRect.top
  }
  const pointInDocument = {
    y: scrollContainer.scrollTop + pointRelativeToContainer.y
  }
  
  // 2. 计算缩放点在当前页面布局中的位置
  // ... 页面布局计算 ...
  
  // 3. 计算缩放后的新位置
  const scaleRatio = newScale / oldScale
  const newPointInDocument = {
    y: pointInDocument.y * scaleRatio
  }
  
  // 4. 调整滚动位置，使缩放点保持在视口中的相同位置
  const newScrollTop = newPointInDocument.y - pointRelativeToContainer.y
  scrollContainer.scrollTop = Math.max(0, newScrollTop)
}
```

**滚动补偿计算**：
1. **缩放点在文档中的绝对位置** = `scrollTop + pointRelativeToContainer.y`
2. **缩放后的新位置** = `pointInDocument.y * scaleRatio`
3. **新的滚动位置** = `newPointInDocument.y - pointRelativeToContainer.y`

**关键点**：
- 缩放点（鼠标位置）在文档中的绝对位置会随缩放比例变化
- 需要调整滚动位置，使缩放点在视口中的相对位置保持不变

## 七、滚动边界控制

### 7.1 边界检查

```typescript
// 检查是否到达边界
const maxScrollTop = scrollContainer.scrollHeight - scrollContainer.clientHeight

// 顶部边界
if (scrollContainer.scrollTop <= 0) {
  scrollContainer.scrollTop = 0
  momentumVelocity = 0
  momentumAnimationFrame = null
  return
}

// 底部边界
if (scrollContainer.scrollTop >= maxScrollTop) {
  scrollContainer.scrollTop = maxScrollTop
  momentumVelocity = 0
  momentumAnimationFrame = null
  return
}
```

**边界计算**：
- **最大滚动距离** = `scrollHeight - clientHeight`
- **顶部边界**：`scrollTop <= 0`
- **底部边界**：`scrollTop >= maxScrollTop`

**边界处理**：
- 到达边界时，停止滚动
- 停止惯性滚动动画
- 重置速度

## 八、滚动距离控制参数总结

## 九、性能优化

### 9.1 滚动性能优化

1. **requestAnimationFrame**：使用RAF进行动画，确保60fps
2. **速度平滑**：使用平均值平滑速度，避免抖动
3. **边界检查**：及时停止无效的滚动动画
4. **任务取消**：缩放时取消之前的滚动任务

### 9.2 滚动距离优化

1. **1:1映射**：双指滑动时，手指移动距离 = 页面滚动距离
2. **平滑衰减**：惯性滚动使用指数衰减，体验自然
3. **边界保护**：防止滚动超出边界

## 十、总结

滚动距离控制机制包括：

1. **双指滑动**：1:1映射，手指移动距离 = 页面滚动距离
2. **惯性滚动**：基于速度的指数衰减，摩擦力系数0.95
3. **鼠标滚轮**：直接使用浏览器提供的滚动距离
4. **缩放补偿**：自动调整滚动位置，保持缩放点位置不变

所有滚动操作都通过`getScrollContainer()`获取滚动容器，统一管理滚动位置，确保一致性和可维护性。
