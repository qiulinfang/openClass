# 笔记功能实现分析

## 一、功能概述

笔记功能是PDF查看器的核心功能，允许用户在PDF页面上进行绘制、标注等操作。当前系统已从Fabric.js迁移到**MuPDF原生注释系统**，注释直接保存在PDF文件中，具有更好的兼容性和性能。

### 2.2 核心组件职责

#### 2.2.1 PdfPage.vue
- **职责**：PDF页面组件，负责PDF渲染和笔记绘制
- **功能**：
  - PDF内容渲染（使用MuPDF.js）
  - Drawing Canvas实时预览绘制内容
  - MuPDF注释的创建和管理
  - 触摸手势处理（双指缩放/滑动）
  - 撤销/重做功能

#### 2.2.2 MuPDFAnnotationService
- **职责**：MuPDF注释服务，管理原生注释的创建、编辑、删除
- **功能**：
  - INK注释（签字笔）的创建
  - HIGHLIGHT注释（荧光笔）的创建
  - 注释的读取和删除
  - 坐标转换（Canvas坐标 ↔ PDF页面坐标）

#### 2.2.3 pdfViewerStore.ts
- **职责**：状态管理中心，管理PDF和标注数据
- **功能**：
  - PDF文档状态管理
  - 标注数据内存管理（`allAnnotations`）
  - 自动保存（防抖机制，1秒延迟）
  - IndexedDB持久化（`textbooks.localFiles[].annotations`）

#### 2.2.4 Drawing Canvas
- **职责**：实时预览层，显示正在绘制的内容
- **功能**：
  - 绘制路径的实时预览
  - 临时对象的显示
  - 选择框的显示

## 三、数据流程

### 3.1 绘制流程

```
用户操作（鼠标/触摸）
    ↓
PdfPage.vue 事件处理
    ↓
Drawing Canvas 实时预览（tempObject）
    ↓
MuPDFAnnotationService 创建注释
    ↓
注释保存到PDF文件（MuPDF原生）
    ↓
loadAnnotations() 重新加载注释
    ↓
转换为DrawObject显示在Drawing Canvas
    ↓
saveAnnotations() 更新Store
    ↓
防抖保存到IndexedDB（1秒延迟）
```

### 3.2 加载流程

```
PDF页面初始化
    ↓
从PDF文件读取注释（MuPDF原生）
    ↓
MuPDFAnnotationService.getAnnotations()
    ↓
转换为DrawObject格式
    ↓
显示在Drawing Canvas（预览）
    ↓
PDF渲染层自动显示注释（MuPDF原生渲染）
```

### 3.3 保存流程

```
注释变更事件
    ↓
store.updateAnnotations()
    ↓
更新内存数据（allAnnotations）
    ↓
触发防抖保存（debouncedSave）
    ↓
1秒后执行 autoSaveAnnotations()
    ↓
保存PDF文件到IndexedDB（pdfDoc.saveToBuffer()）
    ↓
保存注释元数据到IndexedDB（saveAnnotationsToLocalFile()）
```

## 四、核心实现

### 4.1 注释服务初始化

```typescript
// PdfPage.vue - initPdfPage
const initPdfPage = async () => {
  // 1. 获取PDF页面代理
  currentPageProxy = await pdfDoc.getPage(props.layout.pageNum - 1)
  
  // 2. 创建注释服务
  annotationService = new MuPDFAnnotationService(store.drawingConfig)

    onAnnotationChanged: (annotations) => {
      // 更新 store 中的注释
      store.updateAnnotations(props.layout.pageNum, annotations as object[])
    }
  })
  
  // 4. 加载现有注释
  await loadAnnotations()
}
```

```typescript
// PdfPage.vue - handleDrawingMouseDown
const handleDrawingMouseDown = (e: MouseEvent) => {

      type: 'path',
      color: config.penColor,
      lineWidth: config.penWidth,
      points: [...currentPath.value]
    }
    render()
  }
}

// handleDrawingMouseUp
const handleDrawingMouseUp = () => {
  if (tool === 'pen') {
    // 1. 完成绘制，创建MuPDF注释
    const annotData = annotationService.finishInkDrawing()
    
    // 2. 重新加载注释（从PDF读取）
    await loadAnnotations()
    
    // 3. 保存到Store
    saveAnnotations()
  }
}
```

### 4.4 注释加载

```typescript
// PdfPage.vue - loadAnnotations
const loadAnnotations = async (skipStoreUpdate = false) => {
  // 1. 从PDF读取注释（MuPDF原生）
  const annotations = annotationService.getAnnotations()
  
  // 2. 转换为DrawObject格式（用于Drawing Canvas预览）
  objects.value = annotations.map(annot => {
    if (annot.type === 'ink') {
      // INK注释转换为路径对象
      return {
        type: 'path',
        color: annot.color || '#000000',
        lineWidth: annot.width || 1,
        points: annot.points || []
      }
    } else if (annot.type === 'highlight') {
      // HIGHLIGHT注释转换为路径对象
      return {
        type: 'path',
        color: annot.color || '#FFFF00',
        lineWidth: annot.width || 5,
        opacity: annot.opacity || 0.5,
        points: annot.quadPoints || []
      }
    }
  })
  
  // 3. 渲染Drawing Canvas
  render()
  
  // 4. 更新Store（可选）
  if (!skipStoreUpdate) {
    saveAnnotations()
  }
}
```

### 4.5 注释保存

```typescript
// PdfPage.vue - saveAnnotations
const saveAnnotations = () => {
  // 1. 从注释服务获取所有注释
  const annotations = annotationService.getAnnotations()
  
  // 2. 更新Store
  store.updateAnnotations(props.layout.pageNum, annotations as object[])
  
  // 3. 更新最近修改的页面
  store.setLastModifiedPage(props.layout.pageNum)
}

// pdfViewerStore.ts - updateAnnotations
updateAnnotations(pageNum: number, annotations: object[]) {
  // 1. 更新内存中的数据
  if (annotations && annotations.length > 0) {
    this.allAnnotations[pageNum] = annotations
  } else {
    delete this.allAnnotations[pageNum]
  }
  
  // 2. 更新兼容性Map（notes）
  const pageId = `page-${pageNum}`
  if (annotations && annotations.length > 0) {
    const noteData: NoteData[] = annotations.map((obj: object, index: number) => ({
      id: `${pageId}-${index}`,
      pageId,
      type: 'mupdf', // MuPDF注释类型
      content: obj,
      config: this.drawingConfig,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString()
    }))
    this.notes.set(pageId, noteData)
  } else {
    this.notes.delete(pageId)
  }
  
  // 3. 触发防抖自动保存
  this.debouncedSave()
}

// 防抖保存
debouncedSave() {
  if (saveDebounceTimer) {
    clearTimeout(saveDebounceTimer)
    saveDebounceTimer = null
  }
  
  // 1秒后保存
  saveDebounceTimer = setTimeout(async () => {
    await this.autoSaveAnnotations()
  }, 1000)
}

// 自动保存
async autoSaveAnnotations() {
  if (!this.currentFileId || !this.currentResourceId) {
    return
  }
  
  try {
    this.isSaving = true
    
    // 1. 保存PDF文件（注释已保存在PDF中）
    if (this.pdfDoc) {
      const updatedPdfBytes = await this.pdfDoc.saveToBuffer()
      this.originalPdfBytes = updatedPdfBytes
      await this.savePdfToLocalFile(updatedPdfBytes)
    }
    
    // 2. 保存注释元数据到IndexedDB
    await this.saveAnnotationsToLocalFile()
    
    this.lastSaveTime = Date.now()
  } catch (error) {
    console.error('自动保存笔记失败:', error)
  } finally {
    this.isSaving = false
  }
}
```

## 五、关键设计点

### 5.1 双层Canvas架构

- **PDF Canvas**：渲染PDF内容和MuPDF原生注释（由MuPDF.js自动渲染）
- **Drawing Canvas**：实时预览层，显示正在绘制的内容和临时对象

**优势**：
- PDF Canvas专注于PDF渲染，性能更好
- Drawing Canvas提供实时反馈，用户体验更好
- 两者分离，职责清晰

### 5.2 MuPDF原生注释

- **优势**：
  - 注释直接保存在PDF文件中，兼容性好
  - 使用PDF标准格式，其他PDF阅读器也能识别
  - 性能更好，不需要额外的序列化/反序列化

- **实现**：
  - 使用MuPDF.js的`PDFPage.addInkAnnotation()`和`addHighlightAnnotation()`
  - 注释数据格式符合PDF标准

### 5.3 坐标转换

```typescript
// MuPDFAnnotationAdapter.canvasToPageCoords
// 将Canvas坐标转换为PDF页面坐标
const pagePoint = MuPDFAnnotationAdapter.canvasToPageCoords(
  { x, y },
  pageBounds,
  canvasSize
)
```

**关键点**：
- Canvas坐标是像素坐标
- PDF页面坐标是逻辑坐标（点，1点=1/72英寸）
- 需要根据页面边界和Canvas尺寸进行转换

### 5.4 撤销/重做机制

```typescript
// PdfPage.vue - 历史记录管理
const history = ref<DrawObject[][]>([])
const historyIndex = ref(-1)

// 保存状态
const saveState = () => {
  const currentState = JSON.parse(JSON.stringify(objects.value))
  history.value.push(currentState)
  historyIndex.value = history.value.length - 1
}

// 撤销
const undo = (): boolean => {
  if (historyIndex.value <= 0) return false
  historyIndex.value--
  objects.value = JSON.parse(JSON.stringify(history.value[historyIndex.value]))
  render()
  saveAnnotations() // 同步到PDF和Store
  return true
}
```

**注意**：
- 撤销/重做操作会同步到PDF文件
- 每次操作都会重新加载注释，确保一致性

### 5.5 防抖保存机制

```typescript
// pdfViewerStore.ts
debouncedSave() {
  if (saveDebounceTimer) {
    clearTimeout(saveDebounceTimer)
  }
  
  // 1秒后保存
  saveDebounceTimer = setTimeout(async () => {
    await this.autoSaveAnnotations()
  }, 1000)
}
```

**保护机制**：
- `onBeforeUnmount`时调用`flushSave()`立即保存
- `visibilitychange`事件触发时立即保存
- 避免频繁写入IndexedDB，提升性能

## 七、性能优化

### 7.1 防抖保存
- 避免频繁写入IndexedDB
- 1秒延迟，平衡性能和实时性

### 7.2 双层Canvas
- PDF Canvas只渲染PDF内容，性能更好
- Drawing Canvas只显示预览，轻量级

### 7.3 注释直接保存在PDF
- 不需要额外的序列化/反序列化
- 使用PDF标准格式，兼容性好

### 7.4 按需加载
- 只加载当前可见页面的注释
- 页面切换时才加载对应页面的注释

## 八、总结

当前笔记功能实现采用**MuPDF原生注释系统**，具有以下特点：

1. **双层Canvas架构**：PDF Canvas渲染PDF内容，Drawing Canvas提供实时预览
2. **MuPDF原生注释**：注释直接保存在PDF文件中，兼容性和性能更好
3. **防抖保存机制**：1秒延迟保存，避免频繁写入IndexedDB
4. **撤销/重做支持**：完整的历史记录管理
5. **触摸手势支持**：双指缩放/滑动，单指绘制

相比之前的Fabric.js方案，新方案具有更好的性能、兼容性和可维护性。
