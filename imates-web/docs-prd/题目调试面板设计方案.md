# 题目调试面板设计方案

## 一、需求分析

在 `ExerciseSolveView.vue` 中增加一个题目调试面板，用于开发调试时查看和操作题目相关的数据。

### 1.1 功能需求

调试面板应包含以下功能：

1. **题目统计信息**
   - 题目总数
   - 当前选中题目索引
   - 按科目分类统计
   - IndexedDB 存储状态

2. **题目列表查看**
   - 显示所有题目
   - 显示题目基本信息（ID、标题、科目等）
   - 高亮显示当前选中的题目
   - 支持搜索和筛选

3. **题目详情查看**
   - 查看题目的完整信息（题目内容、答案、解析等）
   - 查看题目的原始数据（JSON格式）

4. **调试操作**
   - 选择指定题目
   - 删除题目
   - 刷新题目列表
   - 清空 IndexedDB 数据
   - 导出题目数据
   - 导入题目数据

5. **数据对比**
   - 显示本地 IndexedDB 数据与内存中的数据对比
   - 显示不同科目的数据统计

## 二、设计方案

### 2.1 组件结构

参考现有的 `ChatSessionDebugPanel.vue` 实现模式，创建 `QuestionDebugPanel.vue` 组件。

**组件位置：** `imates-web/src/components/debug/QuestionDebugPanel.vue`

**使用方式：**

- 通过工具栏按钮或快捷键打开

### 2.3 功能模块

#### 2.3.1 统计信息模块

显示以下统计信息：
- 题目总数
- 当前选中题目索引
- 按科目分类统计（数学、生物、化学、物理、语文、英语）
- IndexedDB 存储大小估算

#### 2.3.2 操作按钮模块

- **刷新**：重新从 Store 加载数据
- **清空本地**：清空 IndexedDB 中的所有题目数据
- **导出数据**：导出所有题目数据为 JSON 文件
- **导入数据**：从 JSON 文件导入题目数据

#### 2.3.3 搜索和筛选模块

- 搜索框：根据题目标题或内容搜索
- 科目筛选：按科目筛选题目

#### 2.3.4 题目列表模块

- 显示题目列表（可滚动）
- 每个题目显示：
  - 题目标题（截断显示）
  - 科目标识
  - 是否当前选中（高亮显示）
- 操作按钮：
  - **查看详情**：打开题目详情对话框
  - **选择题目**：将题目设置为当前选中
  - **删除题目**：从列表中删除题目

#### 2.3.5 题目详情对话框

- 显示题目的完整信息：
  - ID、bmNo
  - 标题
  - 题目内容
  - 答案
  - 解析
  - 科目
  - 原始 JSON 数据（可展开/折叠）

- **Store**: `useQuestionStore` - 获取题目数据和操作方法

## 三、集成方案

### 3.1 在 ExerciseSolveView.vue 中集成

1. **引入组件**
   ```vue

   import QuestionDebugPanel from '../components/debug/QuestionDebugPanel.vue'
   </script>
   ```

2. **添加显示控制**
   ```vue
   <template>
     <!-- 其他内容 -->

     <QuestionDebugPanel
       v-if="isDev"
       v-model="showQuestionDebugPanel"
     />
   ```

   - 在筛选面板中添加一个"题目调试"按钮（仅开发环境显示）

使用现有的 `VITE_ENABLE_DEBUG` 环境变量控制调试面板的显示，与现有的调试功能保持一致。

## 五、测试要点

1. **功能测试**
   - 统计信息是否正确显示
   - 操作按钮是否正常工作
   - 题目列表是否正确显示
   - 题目详情是否正确显示

2. **数据一致性测试**
   - 操作后 Store 数据是否同步
   - IndexedDB 数据是否同步

3. **边界情况测试**
   - 空题目列表
   - 大量题目时的性能
   - 删除最后一个题目时的状态

## 六、后续扩展

1. **题目搜索优化**
   - 支持全文搜索
   - 支持正则表达式搜索

2. **批量操作**
   - 批量删除题目
   - 批量导出题目

3. **数据可视化**

## 七、注意事项

1. **仅在开发环境显示**
   - 必须通过 `VITE_ENABLE_DEBUG` 环境变量控制
   - 生产环境不包含调试面板代码

2. **数据安全**
   - 清空操作需要确认提示
   - 导出/导入操作需要验证数据格式

3. **性能考虑**
   - 大量题目时使用虚拟滚动
   - 避免阻塞主线程的操作

4. **代码复用**
   - 参考现有的调试面板实现
   - 复用现有的工具函数和样式

## 八、总结

题目调试面板将为开发调试提供便利，帮助开发者：
- 快速查看题目数据
- 调试题目相关功能
- 管理和清理题目数据
- 导出/导入题目数据进行测试

实现时需遵循现有代码规范，保持与现有调试面板一致的风格和交互方式。
