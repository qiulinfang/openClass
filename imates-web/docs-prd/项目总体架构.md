# imates-web 项目总体架构 PRD

## 📋 概述

**项目名称**：imates-web（学班前端项目）  
**技术栈**：Vue 3 + TypeScript + Quasar + Vite  
**项目类型**：教育类移动应用（WebView 内嵌）  
**目标平台**：Android WebView（当前）、React Native（迁移目标）

## 🏗️ 架构概览

### 1. 技术架构

```
┌─────────────────────────────────────────┐
│          Android WebView                │
│  ┌───────────────────────────────────┐  │
│  │      imates-web (Vue3 App)       │  │
│  │  ┌─────────────────────────────┐ │  │
│  │  │   Presentation Layer         │ │  │
│  │  │   (Views + Components)       │ │  │
│  │  └─────────────────────────────┘ │  │
│  │  ┌─────────────────────────────┐ │  │
│  │  │   Business Logic Layer      │ │  │
│  │  │   (Stores + Services)       │ │  │
│  │  └─────────────────────────────┘ │  │
│  │  ┌─────────────────────────────┐ │  │
│  │  │   Data Layer                │ │  │
│  │  │   (API + IndexedDB)         │ │  │
│  │  └─────────────────────────────┘ │  │
│  └───────────────────────────────────┘  │
│           ↓ JavaScript Bridge          │
│  ┌───────────────────────────────────┐  │
│  │   Android Native Layer           │  │
│  │   (Java/Kotlin)                  │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

## 🔑 核心功能模块

### 1. 用户认证模块
- **位置**：`src/views/LoginView.vue`
- **功能**：用户登录、token 管理
- **存储**：localStorage + Android Bridge

### 2. 习题解答模块
- **位置**：`src/views/ExerciseSolveView.vue`
- **功能**：习题展示、AI 解答、相似题推荐
- **核心组件**：`ChatView.vue`, `QuestionList.vue`

### 3. 知识图谱模块
- **位置**：`src/views/KnowledgeGraphView.vue`
- **功能**：知识节点展示、交互、学习状态管理
- **核心组件**：`KnowledgeGraph.vue`, `GraphNode.vue`

### 4. AI 聊天模块
- **位置**：`src/components/AIChatDialog.vue`
- **功能**：AI 对话、流式响应、多策略支持
- **核心组件**：`ChatInput.vue`, `ChatMessage.vue`, `StreamingMessage.vue`

### 5. 资源管理模块
- **位置**：`src/views/MyResourcesView.vue`
- **功能**：PDF/视频/HTML 查看、下载管理
- **核心组件**：`PdfPage.vue`, `VideoViewerView.vue`

### 6. 数据持久化模块
- **位置**：`src/services/indexeddb-service.ts`
- **功能**：IndexedDB 存储、离线缓存
- **核心服务**：`question-storage.ts`, `resource-storage.ts`

## 🔌 核心技术依赖

### 1. UI 框架
- **Quasar Framework**：UI 组件库

## 🚀 迁移到 React Native 的架构变化

### 当前架构（Vue + WebView）
```
Vue 3 App → JavaScript Bridge → Android Native
```

### 目标架构（React Native）
```
React Native App → Native Modules → Platform APIs
```

### 关键变化点

1. **框架变更**
   - Vue 3 → React
   - Quasar → React Native 组件
   - Vue Router → React Navigation

2. **状态管理**
   - Pinia → Redux / Zustand / Context API

3. **原生交互**
   - Android Bridge → React Native Modules
   - Capacitor → React Native Libraries

4. **UI 组件**
   - Quasar Components → React Native Components
   - Web CSS → React Native Styles

5. **路由导航**
   - Vue Router → React Navigation

6. **数据存储**
   - IndexedDB → AsyncStorage / Realm / SQLite

## 🔍 技术难点分析

### 1. 知识图谱渲染
- **当前**：使用 Fabric.js 在 Canvas 上绘制
- **迁移**：使用 `react-native-svg` 或 `react-native-canvas`
- **挑战**：性能优化、交互手势

### 2. PDF 查看
- **当前**：使用 PDF.js 在 WebView 中渲染
- **迁移**：使用 `react-native-pdf` 或 `react-native-view-pdf`
- **挑战**：大文件加载、页面渲染

### 3. 数学公式编辑
- **当前**：使用 MathLive
- **迁移**：需要找到 React Native 替代方案或使用 WebView
- **挑战**：输入法适配、公式渲染

### 4. 流式响应
- **当前**：使用 WebSocket 或 Server-Sent Events
- **迁移**：使用 React Native 的网络库
- **挑战**：连接稳定性、数据解析

### 5. 原生功能调用
- **当前**：通过 Android Bridge 调用
- **迁移**：编写 React Native Native Modules
- **挑战**：API 映射、错误处理
