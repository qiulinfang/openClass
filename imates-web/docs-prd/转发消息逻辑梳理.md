# 转发消息逻辑梳理

## 一、功能概述

转发消息功能允许学生将AI对话中的消息转发给老师，实现学生与老师之间的沟通。该功能仅在AI对话场景下可用，支持单条消息转发和批量消息转发两种模式。

## 二、核心流程分析

### 2.1 单条消息转发流程

#### 2.1.1 触发入口

**触发方式：**
- 消息气泡长按/右键菜单中的"转发"按钮
- 消息操作菜单中的"转发"选项

**触发函数：**
```typescript
handleForwardMessage(message: ChatBubble)
```

**位置：** `imates-web/src/components/ChatView.vue` 第1981行

#### 2.1.2 完整流程

```
用户点击转发按钮
  ↓
handleForwardMessage(message)
  ↓
【第1步】验证页面类型
  - 检查 props.type 是否为 'ai-general'、'ai-exercise' 或 'ai-textbook'
  - 如果不支持，直接返回，不执行转发
  ↓
【第2步】选择老师会话并转发
  - 调用 selectTeacherSessionAndForward([message])
  - 该函数会处理会话选择/创建和消息转发
  ↓
【第3步】显示转发结果
  - 如果转发成功：
    - ai-exercise 类型：只显示简单提示 "转发成功"
    - 其他类型：显示对话框询问是否前往老师对话
  - 如果转发失败：显示错误提示
```

#### 2.1.3 关键函数：selectTeacherSessionAndForward

**位置：** `imates-web/src/components/ChatView.vue` 第1792行

**功能：** 选择或创建老师会话，并在选择后转发消息

**详细流程：**

```
selectTeacherSessionAndForward(forwardMessages?)
  ↓
【第1步】获取当前科目
  - 调用 getCurrentSubjectForForward()
  - 根据不同页面类型获取科目：
    * ai-general: 返回 null（需要用户手动选择）
    * ai-textbook: 从 knowledgeGraphStore 获取
    * ai-exercise: 从 currentQuestion.subject 获取
  ↓
【第2步】处理AI通用场景（subject === null）
  - 如果页面类型是 ai-general 且 subject 为 null：
    - 显示对话框让用户选择老师类型（生物/数学）
    - 用户选择后：
      * 加载老师会话列表
      * 查找该类型是否有会话
      * 如果有会话：复用已有会话
      * 如果没有会话：创建新会话
      * 如果提供了消息：调用 forwardMessageToTeacher 转发
  ↓
【第3步】处理其他场景（subject !== null）
  - 如果 subject 为 null（且不是 ai-general）：返回 false
  - 加载老师会话列表
  - 查找对应科目的会话
  - 如果找到会话：
    * 设置 teacherSession.value
    * 设置到 teacherStore
    * 加载该会话的历史消息
    * 如果提供了消息：调用 forwardMessageToTeacher 转发
  - 如果没找到会话：
    * 调用 initializeTeacherSession() 创建新会话
    * 如果提供了消息：调用 forwardMessageToTeacher 转发
```

#### 2.1.4 关键函数：forwardMessageToTeacher

**位置：** `imates-web/src/components/ChatView.vue` 第2055行

**功能：** 统一的转发函数，处理消息格式转换和API调用

**详细流程：**

```
forwardMessageToTeacher(messages: ChatBubble[])
  ↓
【第1步】转换消息格式
  - 调用 convertMessageForForwarding 转换每条消息
  - 转换规则：
    * 获取消息类型（TEXT/IMAGE/VOICE）
    * 根据发送者添加角色前缀：
      - 用户消息：[学生] + 内容
      - AI消息：[AI助手] + 内容
    * 清理LaTeX公式：
      - 移除 $...$ 格式的LaTeX
      - 移除 \command 格式的LaTeX命令
      - 移除LaTeX括号 {}()[]
      - 合并多个空格
  ↓
【第2步】序列化消息数据
  - 使用 JSON.stringify 序列化消息数组
  - 如果序列化失败，返回 false
  ↓
【第3步】验证会话ID
  - 检查 teacherSession.value?.sessionId 是否存在
  - 如果不存在，返回 false
  ↓
【第4步】调用API转发
  - 调用 apiService.forwardAiChatToTeacher(selectedMessagesData, sessionId)
  - API调用链：
    * ApiService.forwardAiChatToTeacher()
      ↓
    * AndroidBridge.forwardAiChatToTeacher()
      ↓
    * window.AndroidBridge.forwardAiChatToTeacher()
      ↓
    * Android端 WebAppInterface.forwardAiChatToTeacher()
  ↓
【第5步】处理转发结果
  - 如果转发成功：
    * 转换消息格式（添加 forwarded_ 前缀到消息ID）
    * 设置 sender = 'user'，type = 'user'
    * 添加到 teacherStore.messages
    * 调用 teacherStore.saveChatHistory() 持久化
    * 返回 true
  - 如果转发失败：
    * 返回 false
```

### 2.2 批量消息转发流程

#### 2.2.1 触发入口

**触发方式：**
- 多选模式工具栏中的"转发"按钮

**触发函数：**
```typescript
forwardToTeacher(messageList?: ChatBubble[])
```

**位置：** `imates-web/src/components/ChatView.vue` 第2378行

#### 2.2.2 完整流程

```
用户在多选模式下点击转发按钮
  ↓
forwardToTeacher()
  ↓
【第1步】验证页面类型
  - 检查 props.type 是否为 'ai-general'、'ai-exercise' 或 'ai-textbook'
  - 如果不支持，直接返回
  ↓
【第2步】获取要转发的消息列表
  - 如果提供了 messageList 参数：使用参数
  - 否则：从 displayedMessages 中筛选 selectedMessages 中的消息
  - 如果消息列表为空，直接返回
  ↓
【第3步】执行转发
  - 如果处于选择模式（isSelectionMode.value === true）：
    * 退出选择模式
    * 调用 forwardAsSeparateMessages(selectedMessageList, '')
  - 否则：
    * 调用 handleForwardMessage(selectedMessageList[0]) 单条转发
```

#### 2.2.3 关键函数：forwardAsSeparateMessages

**位置：** `imates-web/src/components/ChatView.vue` 第2405行

**功能：** 将多条消息逐条发送给老师

**详细流程：**

```
forwardAsSeparateMessages(messages: ChatBubble[], additionalMessage: string)
  ↓
【第1步】验证页面类型
  - 检查 props.type 是否为 'ai-general'、'ai-exercise' 或 'ai-textbook'
  - 如果不支持，直接返回
  ↓
【第2步】选择老师会话（不转发，仅选择）
  - 调用 selectTeacherSessionAndForward()（不传消息参数）
  - 如果选择失败或会话不存在，直接返回
  ↓
【第3步】逐条转发消息
  - 遍历消息列表，对每条消息：
    * 转换消息格式（convertMessageForForwarding）
    * 序列化消息数据（JSON.stringify）
    * 调用 apiService.forwardAiChatToTeacher() 转发
    * 统计成功数量
  ↓
【第4步】处理转发结果
  - 如果成功数量 > 0：
    * 转换消息格式（添加 forwarded_ 前缀）
    * 添加到 teacherStore.messages
    * 调用 teacherStore.saveChatHistory() 持久化
    * 显示转发结果：
      - ai-exercise 类型：只显示简单提示
      - 其他类型：显示对话框询问是否前往老师对话
  - 如果成功数量 = 0：
    * 显示错误提示 "转发失败，请重试"
```

## 三、消息格式转换

### 3.1 convertMessageForForwarding 函数

**位置：** `imates-web/src/components/ChatView.vue` 第1712行

**功能：** 将聊天消息转换为转发格式

**转换规则：**

```typescript
convertMessageForForwarding(msg: ChatBubble)
  ↓
【第1步】获取消息类型
  - 从 msg.messageType 获取数据类型（默认为 'text'）
  - 转换为大写格式（TEXT/IMAGE/VOICE）
  ↓
【第2步】添加角色前缀
  - 如果 msg.type === 'user'：添加 '[学生] ' 前缀
  - 如果 msg.type === 'ai'：添加 '[AI助手] ' 前缀
  ↓
【第3步】清理LaTeX公式
  - 移除 $...$ 格式的LaTeX：.replace(/\$[^$]*\$/g, '')
  - 移除 \command 格式的LaTeX命令：.replace(/\\[a-zA-Z]+/g, '')
  - 移除LaTeX括号：.replace(/[{}()[\]]/g, '')
  - 合并多个空格：.replace(/\s+/g, ' ')
  - 去除首尾空格：.trim()
  ↓
【第4步】构建转发格式对象
  {
    id: msg.id,
    type: messageType,  // TEXT/IMAGE/VOICE
    content: cleanedContent,
    timestamp: ''
  }
```

## 四、科目获取逻辑

### 4.1 getCurrentSubjectForForward 函数

**位置：** `imates-web/src/components/ChatView.vue` 第1749行

**功能：** 根据不同场景获取当前科目

**逻辑：**

```typescript
getCurrentSubjectForForward(): 'biology' | 'math' | null
  ↓
根据 props.type 判断：
  - ai-general: 返回 null（需要用户手动选择）
  - ai-textbook: 
    * 从 knowledgeGraphStore.getCurrentSubjectLowercase() 获取
    * 返回 'biology' 或 'math' 或 null
  - ai-exercise:
    * 从 currentQuestion.value.subject 获取
    * 转换为小写格式
    * 如果为 'biology' 或 '生物'：返回 'biology'
    * 如果为 'math' 或 '数学'：返回 'math'
    * 否则返回 null
  - 其他类型：返回 null
```

### 5.2 Android端处理流程

**位置：** `app/src/main/java/com/cosinetech/imates/ui/webview/common/WebAppInterface.java` 第883行

**详细流程：**

```
forwardAiChatToTeacher(selectedMessagesData, teacherSessionId)
  ↓
【第1步】验证用户登录
  - 获取 userId = AppUtils.getUserId()
  - 如果 userId 为 null，返回错误响应
  ↓
【第2步】检查RabbitMQ连接状态
  - 检查 MessagingManager.isInitialized()
  - 如果未初始化：
    * 检查是否正在初始化中
    * 如果正在初始化：等待完成（最多10秒）
    * 如果未初始化：自动初始化 MessagingManager
    * 等待初始化完成（最多10秒）
  - 如果初始化失败，返回错误响应
  ↓
【第3步】解析消息列表
  - 使用 JSONArray 解析 selectedMessagesData
  - 如果解析失败或消息列表为空，返回错误响应
  ↓
【第4步】获取学科信息
  - 从 SharedPreferences 获取当前教师科目
  - 如果为 BIOLOGY：subject = "biology"
  - 否则：subject = "math"
  ↓
【第5步】遍历消息列表，根据类型发送
  - 对每条消息：
    * 获取消息类型（TEXT/IMAGE/VOICE）
    * 根据类型调用不同的发送方法：
      - TEXT: sendTextMessageToTeacher(content, sessionId, subject)
      - IMAGE: sendPictureToTeacher(imagePath, sessionId, subject)
      - VOICE: sendVoiceMessageToTeacher(voicePath, duration, sessionId, subject)
    * 统计成功/失败数量
    * 每条消息之间延迟50ms
  ↓
【第6步】返回结果
  - 如果全部成功：返回成功响应
  - 如果部分成功：返回部分成功响应（包含成功/失败数量）
  - 如果全部失败：返回失败响应
```

## 十、逻辑梳理总结

### 10.1 核心流程

1. **单条消息转发：**
   - `handleForwardMessage` → `selectTeacherSessionAndForward` → `forwardMessageToTeacher` → API调用

2. **批量消息转发：**
   - `forwardToTeacher` → `forwardAsSeparateMessages` → 循环调用API

### 10.2 关键决策点

1. **科目获取：**
   - ai-general：需要用户手动选择
   - ai-textbook：从知识图谱store获取
   - ai-exercise：从题目subject获取

2. **会话管理：**
   - 优先查找已有会话
   - 如果没有会话，创建新会话
   - 每个科目只维护一个会话

3. **消息格式转换：**
   - 添加角色前缀
   - 清理LaTeX公式
   - 转换为API需要的格式

4. **用户交互：**
   - ai-exercise：只显示简单提示
   - 其他类型：显示对话框询问是否跳转

### 10.3 潜在问题点

1. **科目获取失败：**
   - 如果无法获取科目，转发会失败
   - 需要确保科目信息正确传递

2. **会话创建失败：**
   - 如果会话创建失败，转发会失败
   - 需要确保会话创建逻辑正确

3. **API调用失败：**
   - 如果API调用失败，需要显示错误提示
   - 需要确保错误信息正确传递

4. **消息格式转换：**
   - LaTeX公式会被清理，可能丢失重要信息
   - 需要确保转换后的消息仍然有意义
