# 撤销重做按钮置灰问题分析与修复

## 问题描述
PdfViewerView.vue 的撤销和重做按钮一直处于置灰状态，即使用户进行了绘制操作也无法使用撤销重做功能。

## 问题分析

### 1. 历史记录未初始化

**位置**：`src/components/PdfPage.vue` 的 `loadAnnotations` 函数

**问题**：
- 第520行有注释："历史记录功能已移除，不再初始化历史记录状态"
- `historyIndex` 初始化为 -1
- `history` 数组为空
- 加载注释后，历史记录没有被初始化

**影响**：
- `canUndo` 始终为 false（因为 `historyIndex.value > 0` 永远不成立）
- `canRedo` 始终为 false（因为 `history.value.length - 1` 为 -1，`historyIndex.value >= -1` 永远不成立）

### 2. 绘制操作未保存历史记录

**位置**：`src/components/PdfPage.vue` 的 `handleDrawingMouseUp` 函数

**问题**：
- 第1336行：绘制完成时只调用了 `saveAnnotations()`
- 没有调用 `saveState()` 来保存历史记录
- 橡皮擦删除对象时也没有调用 `saveState()`

**影响**：
- 即使历史记录被初始化，用户绘制后也不会保存到历史记录中
- 撤销重做功能无法工作

### 3. 响应式更新问题

**位置**：`src/views/PdfViewerView.vue` 的 `toolStates` 计算属性

**问题**：
- `pageComponents` 是一个 `ref<Map<...>>`，但 Map 内部的对象属性变化不会触发响应式更新
- `canUndo` 和 `canRedo` 是 getter，但 Vue 无法追踪到 Map 内部对象属性的变化
- 当页面组件的 `historyIndex` 变化时，`toolStates` 可能不会重新计算

**影响**：
- 即使历史记录状态变化，工具栏按钮状态也不会更新

## 解决方案

### 方案1：初始化历史记录

在 `loadAnnotations` 函数中，加载注释后初始化历史记录：

```typescript
const loadAnnotations = async () => {
  try {
    // ... 加载注释数据 ...
    
    // 初始化历史记录
    if (objects.value.length > 0) {
      // 如果有初始数据，保存两个状态：空状态和当前状态
      history.value = [[], JSON.parse(JSON.stringify(objects.value))]
      historyIndex.value = 1  // 指向当前状态
    } else {
      // 如果没有数据，只保存空状态
      history.value = [[]]
      historyIndex.value = 0
    }
  } catch (err) {
    // ... 错误处理 ...
    history.value = [[]]
    historyIndex.value = 0
  }
}
```

### 方案2：在绘制操作时保存历史记录

在绘制完成、删除对象等操作时调用 `saveState()`：

```typescript
// 绘制完成时
objects.value.push(tempObject.value)
tempObject.value = null
saveState()  // 保存历史记录
saveAnnotations()  // 保存到Store

// 橡皮擦删除对象时
if (toDelete.length > 0) {
  objects.value = objects.value.filter((_, index) => !toDelete.includes(index))
  saveState()  // 保存历史记录
  saveAnnotations()
  render()
}
```

### 方案3：修复响应式更新

使用 `watchEffect` 或响应式对象来确保 `toolStates` 能够响应页面组件状态变化：

```typescript
// 方案3.1：使用响应式对象替代 Map
const pageComponents = ref<
  Record<number, { undo: () => boolean; redo: () => boolean; canUndo: Ref<boolean>; canRedo: Ref<boolean> }>
>({})

// 方案3.2：使用 watchEffect 强制更新
const toolStates = computed(() => {
  // 访问 store.lastModifiedPage 触发响应式
  const lastModifiedPage = store.lastModifiedPage
  
  // 访问 pageComponents.value 触发响应式

```
