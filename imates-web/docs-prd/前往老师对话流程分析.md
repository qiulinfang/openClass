# 前往老师对话流程分析

## 概述

本文档详细分析当用户点击"前往老师对话"按钮后，系统执行的完整流程。

## 触发入口

### 1. 用户操作
用户在 AI 对话页面转发消息后，系统弹出对话框询问是否前往老师对话：
- **位置**：`ChatView.vue` 第 2007-2042 行
- **对话框内容**：
  - 标题：转发成功
  - 消息：消息已成功转发给老师，是否前往老师对话查看？
  - 按钮：
    - 取消：留在当前会话
    - 确认：前往老师对话

### 2. 事件触发
当用户点击"前往老师对话"按钮时：
```typescript
// ChatView.vue:2028-2032
emit('open-teacher-dialog', {
  sessionId: teacherSession.value.sessionId,
  message: message,
})
```

## 完整执行流程

### 阶段 1：事件处理（UnifiedChatDialog）

#### 1.1 接收事件
- **位置**：`UnifiedChatDialog.vue` 第 442-457 行
- **方法**：`handleOpenTeacherDialog`
- **执行步骤**：
  1. 确保会话列表已加载（如果还未加载）
  2. 调用 `setTeacherSession(sessionId)` 设置会话
  3. 自动切换到教师分类

#### 1.2 设置会话
- **位置**：`UnifiedChatDialog.vue` 第 429-439 行
- **方法**：`setTeacherSession`
- **执行步骤**：
  1. 设置 `teacherSessionId.value = sessionId`
  2. 从会话列表中找到对应会话
  3. 调用 `teacherChatStore.setSession(session)` 设置到 Store
  4. 保存当前教师科目到 localStorage
  5. 设置 `activeCategory.value = 'teacher'` 切换到教师分类

### 阶段 2：组件切换（ChatView）

#### 2.1 组件渲染
- **位置**：`UnifiedChatDialog.vue` 第 87-92 行
- **条件渲染**：
```vue
<ChatView 
  v-else-if="activeCategory === 'teacher' && teacherSessionId"
  type="teacher"
  :session-id="teacherSessionId"
  :key="teacherSessionId"
/>
```

#### 2.2 组件初始化
- **位置**：`ChatView.vue` 第 700-750 行（watch props.type）
- **触发条件**：`props.type === 'teacher'`
- **执行步骤**：
  1. 调用 `initializeTeacherSession()` 初始化老师会话
  2. 设置聊天策略为 `TeacherStrategy`

### 阶段 3：会话初始化（ChatView.initializeTeacherSession）

#### 3.1 初始化消息接收器
- **位置**：`ChatView.vue` 第 864 行
- **方法**：`teacherStore.initMessageReceiver()`
- **作用**：设置消息接收回调函数，初始化 Android 端消息监听器

#### 3.2 判断会话类型
根据 `props.sessionId` 判断是加载已有会话还是创建新会话：

**场景 A：加载已有会话**
- **条件**：`props.sessionId` 存在且格式为 `teacher-{hex}-{timestamp}`（不是临时ID）
- **位置**：`ChatView.vue` 第 937-966 行
- **执行步骤**：
  1. 从 Store 获取已有会话：`teacherStore.getSession(props.sessionId)`
  2. 构建 `ChatMessageSession` 格式的会话对象
  3. 设置到 Store：`teacherStore.setSession(existingSession)`
  4. 从本地存储加载聊天记录：`teacherStore.loadChatHistory(existingSession.sessionId)`
  5. 从 API 加载聊天记录：`loadTeacherChatHistory()`

**场景 B：创建新会话**
- **条件**：临时ID或未找到已有会话
- **位置**：`ChatView.vue` 第 969-1015 行
- **执行步骤**：
  1. 生成会话ID：`teacher_general_${Date.now()}_${random}`
  2. 生成会话名称（根据科目：生物/数学）
  3. 创建老师会话：`teacherStore.createTeacherSession(...)`
  4. 构建 `ChatMessageSession` 格式的会话对象
  5. 从本地存储加载聊天记录：`teacherStore.loadChatHistory(createdSession.sessionId)`
  6. 从 API 加载聊天记录：`loadTeacherChatHistory()`

### 阶段 4：Store 操作（teacherGeneralChatStore）

#### 4.1 设置会话（setSession）
- **位置**：`teacherGeneralChatStore.ts` 第 75-81 行
- **执行步骤**：
  1. 设置 `currentSession.value = session`
  2. 清除该会话的未读标记

#### 4.2 加载聊天历史（loadChatHistory）
- **位置**：`teacherGeneralChatStore.ts` 第 850-875 行
- **存储键名**：`teacher-general-${sessionId}`（独立存储格式）
- **执行步骤**：
  1. 从 IndexedDB 加载消息历史
  2. 设置 `messages.value = history.messages || []`
  3. 设置 `chatResponseTimes.value = history.chatResponseTimes || 0`
  4. 从 localStorage 加载会话信息（键名：`${userId}_teacher-general-${sessionId}_session`）
  5. 设置 `currentSession.value = sessionInfo`

#### 4.3 初始化消息接收器（initMessageReceiver）
- **位置**：`teacherGeneralChatStore.ts` 第 1930-2096 行
- **执行步骤**：

**步骤 1：设置回调函数**
```typescript
window.onTeacherMessageReceived = async (messageData: string) => {
  // 处理接收到的消息
  // 1. 解析消息数据
  // 2. 检查消息是否已存在（去重）
  // 3. 根据消息类型（文本/图片/语音）构建消息对象
  // 4. 添加到消息列表
  // 5. 保存聊天历史
}
```

**步骤 2：初始化 Android 端监听器**
1. 检查 `AndroidBridge` 是否已初始化
2. 检查 `MessagingManager` 是否已初始化
3. 如果未初始化：
   - 清理旧的监听器
   - 调用 `AndroidBridge.initTeacherMessageListener()`
   - 等待初始化完成（最多10秒）
4. 如果已初始化：
   - 确保监听器已添加（清理后重新添加）

**步骤 3：验证初始化结果**
- 验证回调函数是否已设置
- 验证 Android 端是否已初始化

### 阶段 5：API 同步（loadTeacherChatHistory）

#### 5.1 从 API 加载历史
- **位置**：`ChatView.vue` 第 1084-1150 行
- **方法**：`loadTeacherChatHistory`
- **执行步骤**：
  1. 调用 `apiService.getTeacherChatHistory(sessionId)` 获取远程消息
  2. 解析消息类型（TEXT/IMAGE/VOICE/DATE）
  3. 构建 `ChatBubble` 格式的消息对象
  4. 去重检查（避免覆盖已存在的消息）
  5. 合并到 Store 的消息列表
  6. 保存到本地存储

### 阶段 6：UI 更新

#### 6.1 消息列表渲染
- **位置**：`ChatView.vue` 第 64-79 行
- **数据源**：`displayedMessages`（来自 Store）
- **渲染组件**：`ChatMessageComponent`

#### 6.2 滚动到底部
- **位置**：`ChatView.vue` 第 750-760 行
- **触发时机**：消息加载完成后
- **方法**：`scrollToBottom()`

## 关键数据结构

### 会话信息（TeacherSession）
```typescript
interface TeacherSession {
  sessionId: string        // 会话ID，格式：teacher-{hex}-{timestamp}
  sessionName: string      // 会话名称
  subject: string          // 科目：'biology' | 'math'
  createTime: number       // 创建时间
  msgCount?: number        // 消息数量
  updateTime?: number      // 更新时间
}
```

### 存储键名
- **IndexedDB 消息存储**：`teacher-general-${sessionId}`
- **localStorage 会话信息**：`${userId}_teacher-general-${sessionId}_session`
- **localStorage 会话列表**：`${userId}_teacher-general-sessions`

## 注意事项

### 1. 消息接收器初始化
- 消息接收器只需要初始化一次
- 如果已初始化，只更新回调函数，不重复初始化 Android 端
- 初始化失败时会清除标志，允许重试

### 2. 消息去重
- 加载历史消息时会检查消息ID，避免重复添加
- API 同步时会检查已存在的消息ID，避免覆盖

### 3. 存储格式
- 使用独立存储格式，每个会话的消息独立存储
- 会话信息存储在 localStorage，消息数据存储在 IndexedDB

### 4. 错误处理
- 如果会话不存在，会创建临时会话
- 如果加载失败，会清空消息列表，不影响后续操作

## 相关文件

- `ChatView.vue`：聊天视图组件，处理会话初始化
- `UnifiedChatDialog.vue`：统一聊天对话框，处理会话切换
- `teacherGeneralChatStore.ts`：教师通用对话 Store，管理状态和逻辑
- `api-service.ts`：API 服务，处理远程数据同步
