## 二、存在问题的数据（❌）

### 1. 题目列表存储（question-storage.ts）❌ **严重**

**问题描述**:
- 数据库名固定为 `ExerciseQuestionsDB`，没有用户ID隔离
- 所有用户共享同一个题目列表数据库
- 切换账号后，题目列表会混乱

**影响范围**:
- 所有用户共享题目列表数据
- 账号切换后可能看到其他用户的题目

**修复方案**:
```typescript
// 修改前
const questionStorage = IndexedDBService.getInstance({
  dbName: 'ExerciseQuestionsDB',  // ❌ 固定名称
  // ...
})

// 修改后
const userId = getCurrentUserIdOrDefault()
const questionStorage = IndexedDBService.getInstance({
  dbName: `ExerciseQuestionsDB_${userId}`,  // ✅ 包含用户ID
  // ...
})
```

**文件位置**: `imates-web/src/services/question-storage.ts:16`

---

### 2. 聊天历史 IndexedDB 数据库（chat-storage.ts）❌ **严重**

**问题描述**:
- localforage 配置的数据库名固定为 `ExerciseSolveApp`，没有用户ID隔离
- 所有用户共享同一个 IndexedDB 数据库

**影响范围**:
- 所有用户的聊天历史可能混在一起
- 虽然key中有用户ID，但数据库本身是共享的

**修复方案**:
```typescript
// 修改前
localforage.config({
  name: 'ExerciseSolveApp',  // ❌ 固定名称
  // ...
})

// 修改后
const userId = getCurrentUserIdOrDefault()
localforage.config({
  name: `ExerciseSolveApp_${userId}`,  // ✅ 包含用户ID
  // ...
})
```

**注意**: localforage 是全局配置，需要在每次使用时动态配置，或者为每个用户创建独立的实例。

**文件位置**: `imates-web/src/services/chat-storage.ts:6-12`

### 8. 收藏功能 Bug（favorites.ts）❌ **Bug**

**问题描述**:
- `removeQaFavorite` 和 `removeExerciseFavorite` 函数中使用了未定义的常量 `FAVORITES_STORAGE_KEY`
- 应该使用 `getFavoritesStorageKey()` 函数

**影响范围**:
- 取消收藏功能可能无法正常工作

**修复方案**:
```typescript
// 修改前
localStorage.setItem(FAVORITES_STORAGE_KEY, JSON.stringify(filtered))

// 修改后
const key = getFavoritesStorageKey()
localStorage.setItem(key, JSON.stringify(filtered))
```

**文件位置**: 
- `imates-web/src/utils/favorites.ts:158` (removeQaFavorite)
- `imates-web/src/utils/favorites.ts:178` (removeExerciseFavorite)
