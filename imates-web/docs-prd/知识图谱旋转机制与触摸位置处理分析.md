# 知识图谱旋转机制与触摸位置处理分析

## 一、旋转机制概述

知识图谱的旋转机制通过触摸滑动实现，核心原理是将**垂直滑动距离**转换为**椭圆轨迹上的旋转角度**，从而实现知识图谱在椭圆轨道上的切换。

### 1.1 核心旋转公式

```typescript
// 第1步：计算相邻知识图谱之间的角度差
const angleBetweenGraphs = 360 / total  // total为知识图谱总数

// 第2步：计算归一化参考高度（参考移动端短视频切换方式）
const normalizedReferenceHeight = screenHeight * 0.85  // 视口高度的85%

// 第3步：计算旋转角度增量
const rotationDelta = (effectiveDeltaY / normalizedReferenceHeight) * angleBetweenGraphs
```

**关键参数说明：**
- `effectiveDeltaY`：有效滑动距离（像素）
- `normalizedReferenceHeight`：归一化参考高度，默认值为屏幕高度的85%
- `angleBetweenGraphs`：相邻知识图谱之间的角度差（360度 / 知识图谱总数）
- `rotationDelta`：旋转角度增量（度）

### 1.2 旋转角度更新机制

```typescript
// 更新当前章节的旋转角度
const currentRotation = getChapterRotation(getCurrentChapter())
const newRotation = currentRotation - rotationDelta  // 向上滑动为正，向下滑动为负
setChapterRotation(getCurrentChapter(), newRotation)
```

**旋转方向说明：**
- **向上滑动**（deltaY > 0）：`rotationDelta` 为正，减去后角度减小，图谱逆时针旋转
- **向下滑动**（deltaY < 0）：`rotationDelta` 为负，减去后角度增大，图谱顺时针旋转

## 二、触摸位置处理机制

知识图谱系统需要区分不同的触摸位置，以正确处理用户交互：

### 2.1 触摸位置类型

系统识别以下几种触摸位置：

1. **圆周节点区域**（`.graph-node--circular` 或 `.node-wrapper--circular`）
2. **中心节点区域**（`.graph-node--center` 或 `.node-wrapper--center`）
3. **背景区域**（`.viewport-clipper` 或 `.circular-layout`）
4. **指示器区域**（`.right-border-indicator`）

### 2.2 圆周节点检测函数

```typescript
// 第1步：检查触摸目标是否是圆周节点（或其子元素）
const isCircularNodeTarget = (target: EventTarget | null): boolean => {
  if (!target || !(target instanceof HTMLElement)) {
    return false
  }
  
  // 检查目标元素或其父元素是否包含圆周节点的类名
  return (
    target.classList.contains('graph-node--circular') ||
    target.classList.contains('node-wrapper--circular') ||
    target.closest('.graph-node--circular') !== null ||
    target.closest('.node-wrapper--circular') !== null
  )
}
```

**检测逻辑：**
- 检查目标元素本身是否包含圆周节点类名
- 向上查找父元素，检查是否包含圆周节点类名
- 使用 `closest()` 方法递归查找
- **注意**：此函数**不检测中心节点**，只检测圆周节点

### 2.2.1 中心节点的特殊性

中心节点（`.graph-node--center`）与圆周节点在旋转机制中的处理方式不同：

1. **不参与旋转检测**：
   - 中心节点位于知识图谱的中心位置，不在椭圆轨道上
   - `isCircularNodeTarget()` 函数不检测中心节点，中心节点的触摸会被当作背景区域处理
   - 中心节点上的滑动**会触发旋转操作**（因为被当作背景区域处理）
   - 但中心节点不参与特殊的圆周节点滑动处理逻辑

2. **点击行为**：
   ```typescript
   // 中心节点的点击处理（在 GraphNode.vue 中）
   const handleClick = (event: Event) => {
     event.stopPropagation()
     
     // 如果是中心节点，只有在知识图谱展开状态下才显示气泡框
     if (props.type === 'center') {
       if (props.isExpanded) {
         emit('toggle-menu', props.node.id)
       }
     } else {
       // 圆周节点正常显示气泡框
       emit('toggle-menu', props.node.id)
     }
   }
   ```

3. **状态依赖**：
   - 中心节点只有在知识图谱展开状态（`isExpanded === true`）下才响应点击事件
   - 未展开时，点击中心节点不会显示气泡框
   - 这与圆周节点的行为不同（圆周节点始终可以点击显示气泡框）

4. **视觉变化**：
   - 中心节点会根据展开状态改变大小：
     - 默认大小：180px（可配置）
     - 展开状态：240px（可配置）
     - 收缩状态（其他图谱展开时）：140px（可配置）

### 2.3 TouchStart 触摸开始处理

```typescript
const handleTouchStart = (event: TouchEvent) => {
  // 第1步：检查触摸点是否在圆周节点上
  const isOnCircularNode = isCircularNodeTarget(event.target)
  touchStartedOnCircularNode.value = isOnCircularNode
  
  // 第2步：如果触摸点在圆周节点上，记录目标元素
  if (isOnCircularNode && event.target instanceof HTMLElement) {
    circularNodeTouchTarget.value = event.target.closest('.graph-node--circular') as HTMLElement || 
                                    event.target.closest('.node-wrapper--circular') as HTMLElement ||
                                    event.target
  } else {
    circularNodeTouchTarget.value = null
  }
  
  // 第3步：初始化拖拽状态
  isActualDragging.value = false  // 初始为false，需要超过阈值才设为true
  startY.value = event.touches[0].clientY
  lastY.value = event.touches[0].clientY
  
  // 第4步：只在拖拽容器上阻止默认滚动行为
  if (event.target === circularLayoutRef.value) {
    event.preventDefault()
  }
}
```

**处理逻辑：**
1. **位置检测**：判断触摸是否从圆周节点开始
2. **目标记录**：如果从圆周节点开始，记录目标元素（用于后续阻止点击事件）
3. **状态初始化**：初始化拖拽相关状态变量
4. **默认行为**：只在特定情况下阻止默认滚动行为

### 2.4 TouchMove 触摸移动处理（核心逻辑）

```typescript
const handleTouchMove = (event: TouchEvent) => {
  const currentY = event.touches[0].clientY
  const deltaY = currentY - lastY.value
  
  // ========== 第一步：拖拽阈值检测 ==========
  const totalDeltaY = Math.abs(currentY - startY.value)
  const isJustStartingDrag = totalDeltaY > DRAG_THRESHOLD.value && !isActualDragging.value
  
  if (isJustStartingDrag) {
    isActualDragging.value = true
    isDragging.value = true  // ✅ 只有在实际移动超过阈值时才设置 isDragging
    
    // 如果是从圆周节点开始的滑动，且超过阈值，阻止节点点击事件
    if (touchStartedOnCircularNode.value && circularNodeTouchTarget.value) {
      // 通过阻止事件传播来阻止节点点击事件
      event.stopPropagation()
      // 标记节点元素，防止后续点击事件触发
      if (circularNodeTouchTarget.value) {
        circularNodeTouchTarget.value.style.pointerEvents = 'none'
        // 在触摸结束后恢复
        setTimeout(() => {
          if (circularNodeTouchTarget.value) {
            circularNodeTouchTarget.value.style.pointerEvents = ''
          }
        }, 100)
      }
    }
    
    // 首次超过阈值时，将 lastY 重置为 startY
    // 这样可以确保首次触发旋转时也有明显的旋转效果
    lastY.value = startY.value
  }
  
  // 只有实际拖拽时才执行旋转逻辑
  if (!isActualDragging.value) {
    lastY.value = currentY
    return
  }
  
  // 如果是从圆周节点开始的滑动，阻止事件传播
  if (touchStartedOnCircularNode.value) {
    event.stopPropagation()
  }
  
  // ========== 第二步：计算旋转角度 ==========
  // 重新计算 deltaY（在首次超过阈值时，这会是从 startY 到 currentY 的总距离）
  const effectiveDeltaY = currentY - lastY.value
  
  // 计算旋转角度
  const subChapters = getSubChapters(selectedChapterDetails.value)
  const total = subChapters.length
  const angleBetweenGraphs = total > 0 ? 360 / total : 360
  
  // 使用归一化参考高度计算旋转角度
  const rotationDelta = (effectiveDeltaY / normalizedReferenceHeight.value) * angleBetweenGraphs
  
  // ========== 第三步：状态更新 ==========
  // 如果有知识图谱处于展开状态，先收缩它
  if (getCurrentChapterExpandedGraph() !== null) {
    setCurrentChapterExpandedGraph(null)
  }
  
  // 更新当前章节的旋转角度
  const currentRotation = getChapterRotation(getCurrentChapter())
  const newRotation = currentRotation - rotationDelta
  setChapterRotation(getCurrentChapter(), newRotation)
  
  // 更新上次位置和时间戳
  lastY.value = currentY
  lastRotationTime.value = currentTime
  
  // 阻止默认滚动行为
  event.preventDefault()
}
```

**关键处理逻辑：**

#### 2.4.1 拖拽阈值检测
- **阈值参数**：`DRAG_THRESHOLD`（默认3像素）
- **目的**：区分点击和拖拽操作
- **机制**：只有当移动距离超过阈值时，才判定为实际拖拽

#### 2.4.2 圆周节点滑动处理
- **检测**：如果触摸从圆周节点开始（`touchStartedOnCircularNode.value === true`）
- **阻止点击**：超过阈值后，禁用节点的 `pointer-events`，防止点击事件触发
- **事件传播**：阻止事件传播，避免干扰其他交互

#### 2.4.3 旋转角度计算
- **有效距离**：使用 `effectiveDeltaY`（当前Y坐标 - 上次Y坐标）
- **归一化**：相对于参考高度的比例
- **角度转换**：乘以相邻知识图谱之间的角度差

### 2.5 TouchEnd 触摸结束处理

```typescript
const handleTouchEnd = () => {
  
  // 保存实际拖拽状态，因为后面会重置
  const wasActuallyDragging = isActualDragging.value
  const wasOnCircularNode = touchStartedOnCircularNode.value
  
  // 计算总滑动方向
  const totalDeltaY = lastY.value - startY.value
  
  // 重置状态
  isDragging.value = false
  isActualDragging.value = false
  touchStartedOnCircularNode.value = false
  
  // 恢复圆周节点的 pointer-events（如果之前被禁用）
  if (circularNodeTouchTarget.value) {
    circularNodeTouchTarget.value.style.pointerEvents = ''
    circularNodeTouchTarget.value = null
  }
  
  // 只有在实际拖拽时才执行自动定位逻辑
  if (wasActuallyDragging) {
    // 防抖处理，避免与点击事件冲突
    if (debounceTimer.value) {
      clearTimeout(debounceTimer.value)
    }
    
    debounceTimer.value = setTimeout(() => {
      // 根据滑动方向切换到下一个或上一个知识图谱
      // 向上滑动（totalDeltaY > 0）→ 下一个（index + 1）
      // 向下滑动（totalDeltaY < 0）→ 上一个（index - 1）
      const direction = totalDeltaY > 0 ? 'next' : totalDeltaY < 0 ? 'previous' : null
      autoPositionToNearestGraph(direction)
    }, debugParams.value.debounceDelay * 1000) // 防抖延迟（转换为毫秒）
  }
}
```

**处理逻辑：**
1. **状态保存**：保存实际拖拽状态，用于后续判断
2. **方向计算**：计算总滑动方向（向上或向下）
3. **状态重置**：重置所有拖拽相关状态
4. **事件恢复**：恢复圆周节点的 `pointer-events`
5. **自动定位**：如果实际拖拽，根据方向自动定位到最近的知识图谱

## 三、各种触摸位置的处理情况

### 3.1 情况1：从圆周节点开始触摸

**处理流程：**
1. **TouchStart**：
   - 检测到触摸点在圆周节点上
   - 设置 `touchStartedOnCircularNode = true`
   - 记录目标元素 `circularNodeTouchTarget`

2. **TouchMove**：
   - 如果移动距离超过阈值：
     - 设置 `isActualDragging = true`
     - 禁用节点的 `pointer-events = 'none'`
     - 阻止事件传播 `event.stopPropagation()`
   - 执行旋转逻辑

3. **TouchEnd**：
   - 恢复节点的 `pointer-events = ''`
   - 如果实际拖拽，执行自动定位

**目的**：防止圆周节点的点击事件干扰旋转操作

### 3.2 情况2：从背景区域开始触摸

**处理流程：**
1. **TouchStart**：
   - 检测到触摸点在背景区域
   - 设置 `touchStartedOnCircularNode = false`
   - `circularNodeTouchTarget = null`

2. **TouchMove**：
   - 如果移动距离超过阈值，执行旋转逻辑
   - 不阻止事件传播（因为不在圆周节点上）

3. **TouchEnd**：
   - 如果实际拖拽，执行自动定位

**目的**：正常的旋转操作，不受节点点击影响

### 3.3 情况3：从中心节点开始触摸

**处理流程：**
1. **TouchStart**：
   - 中心节点**不被** `isCircularNodeTarget()` 检测为圆周节点
   - `touchStartedOnCircularNode = false`
   - `circularNodeTouchTarget = null`
   - 中心节点的触摸会被当作背景区域处理

2. **TouchMove**：
   - 如果移动距离超过阈值，执行旋转逻辑
   - 中心节点上的滑动会触发旋转操作（与背景区域相同）
   - 不阻止事件传播（因为不在圆周节点上）

3. **TouchEnd**：
   - 如果实际拖拽，执行自动定位

**目的**：中心节点上的滑动操作会触发知识图谱旋转，但点击行为受展开状态限制

**注意**：
- 中心节点的点击行为与旋转机制是分离的
- 即使在中心节点上滑动触发旋转，也不会影响中心节点的点击逻辑
- 中心节点只在展开状态下响应点击事件

### 3.4 情况4：从指示器区域开始触摸

**处理流程：**
指示器区域有独立的触摸处理函数：

```typescript
// 指示器触摸开始
const handleIndicatorTouchStart = (event: TouchEvent) => {
  // 阻止事件冒泡
  event.stopPropagation()
  
  // 设置指示器滑动状态
  isIndicatorDragging.value = true
  
  // 获取触摸点位置，计算当前在哪个指示器上
  const touchY = event.touches[0].clientY
  const index = getIndicatorIndexFromTouch(touchY)
  
  if (index === null) return
  
  indicatorCurrentIndex.value = index
  
  // 立即切换到对应的知识图谱
  const subChapters = getSubChapters(selectedChapterDetails.value)
  if (index >= 0 && index < subChapters.length) {
    const targetGraphId = subChapters[index].id
    if (getCurrentChapterExpandedGraph() !== targetGraphId) {
      setCurrentChapterExpandedGraph(targetGraphId)
      startExpandingRotation(targetGraphId)
    }
  }
}
```

**处理逻辑：**
- 阻止事件冒泡，避免触发背景区域的触摸事件
- 根据触摸Y坐标计算当前在哪个指示器上
- 立即切换到对应的知识图谱

### 3.5 情况5：短距离移动（未超过阈值）

**处理流程：**
1. **TouchStart**：正常初始化
2. **TouchMove**：
   - 移动距离未超过阈值
   - `isActualDragging = false`
   - 只更新 `lastY`，不执行旋转逻辑
   - 早期返回，不执行后续逻辑

3. **TouchEnd**：
   - `wasActuallyDragging = false`
   - 不执行自动定位
   - 如果是从圆周节点开始，可能触发点击事件

**目的**：区分点击和拖拽操作

## 四、旋转角度计算详解

### 4.1 角度计算公式

```typescript
// 第1步：计算相邻知识图谱之间的角度差
const angleBetweenGraphs = 360 / total  // total为知识图谱总数

// 第2步：计算归一化参考高度
const normalizedReferenceHeight = screenHeight * 0.85  // 视口高度的85%

// 第3步：计算旋转角度增量
const rotationDelta = (effectiveDeltaY / normalizedReferenceHeight) * angleBetweenGraphs
```

**示例计算：**
- 假设有5个知识图谱：`angleBetweenGraphs = 360 / 5 = 72度`
- 假设屏幕高度为800px：`normalizedReferenceHeight = 800 * 0.85 = 680px`
- 假设滑动距离为340px：`rotationDelta = (340 / 680) * 72 = 36度`

### 4.2 旋转方向判断

```typescript
// 向上滑动（totalDeltaY > 0）→ 下一个（顺时针方向，index + 1）
// 向下滑动（totalDeltaY < 0）→ 上一个（逆时针方向，index - 1）
const direction = totalDeltaY > 0 ? 'next' : totalDeltaY < 0 ? 'previous' : null
```

**旋转方向说明：**
- **向上滑动**：图谱逆时针旋转，切换到下一个（index + 1）
- **向下滑动**：图谱顺时针旋转，切换到上一个（index - 1）

### 4.3 自动定位机制

触摸结束后，系统会根据滑动方向自动定位到最近的知识图谱：

```typescript
const autoPositionToNearestGraph = (direction?: 'next' | 'previous' | null) => {
  // 如果指定了方向，根据滑动方向切换
  if (direction === 'next' || direction === 'previous') {
    // 获取当前展开的知识图谱索引
    const currentExpandedGraphId = getCurrentChapterExpandedGraph()
    let currentIndex = -1
    
    if (currentExpandedGraphId) {
      currentIndex = subChapters.findIndex(chapter => chapter.id === currentExpandedGraphId)
    }
    
    // 根据方向计算目标索引（循环处理）
    if (direction === 'next') {
      targetIndex = (currentIndex + 1) % subChapters.length
    } else {
      targetIndex = (currentIndex - 1 + subChapters.length) % subChapters.length
    }
  } else {
    // 没有指定方向，找到距离目标角度最近的知识图谱
    // ... 计算逻辑
  }
  
  // 设置展开状态并执行展开旋转动画
  setCurrentChapterExpandedGraph(subChapters[targetIndex].id)
  startExpandingRotation(subChapters[targetIndex].id)
}
```

## 五、关键参数配置

### 5.1 拖拽阈值

```typescript
dragThreshold: 3  // 拖拽阈值（像素），超过此值才开始真正的拖拽操作
```

**作用**：区分点击和拖拽操作，避免误触发旋转

### 5.2 归一化参考高度比例

```typescript
normalizedReferenceHeightRatio: 0.85  // 归一化参考高度比例
```

**作用**：参考移动端短视频切换方式，使用视口高度的85%作为参考，滑动大部分屏幕高度就能切换到下一个知识图谱

### 5.3 防抖延迟

```typescript
debounceDelay: 0.1  // 防抖延迟（秒）
```

**作用**：避免与点击事件冲突，在触摸结束后延迟执行自动定位

## 六、总结

### 6.1 旋转机制核心

1. **角度计算**：将垂直滑动距离转换为旋转角度增量
2. **实时更新**：在触摸移动过程中实时更新旋转角度
3. **自动定位**：触摸结束后自动定位到最近的知识图谱

### 6.2 触摸位置处理核心

1. **位置识别**：区分圆周节点、中心节点、背景区域、指示器区域
2. **阈值检测**：通过拖拽阈值区分点击和拖拽
3. **事件控制**：在圆周节点上滑动时，禁用节点点击事件
4. **方向判断**：根据滑动方向自动切换到下一个或上一个知识图谱
5. **中心节点特殊性**：中心节点不参与旋转检测，但可以触发旋转操作；点击行为受展开状态限制

### 6.3 关键设计点

1. **防误触**：通过拖拽阈值和防抖机制，避免误触发旋转
2. **交互优化**：在圆周节点上滑动时，禁用节点点击，避免干扰旋转操作
3. **自动定位**：触摸结束后自动定位到最近的知识图谱，提升用户体验
4. **归一化计算**：使用归一化参考高度，使旋转操作更加自然流畅
5. **中心节点设计**：
   - 中心节点不参与旋转检测逻辑，但可以触发旋转操作
   - 中心节点的点击行为与旋转机制分离，只在展开状态下响应
   - 中心节点的大小会根据展开状态动态变化，提供视觉反馈
