## 二、数据流图

### 2.1 发送消息流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant ChatInput as ChatInput
    participant ChatView as ChatView
    participant Strategy as ChatStrategy
    participant Store as ChatStore
    participant ApiService as ApiService
    participant Backend as 后端API
    participant Storage as ChatStorage

    User->>ChatInput: 输入消息
    ChatInput->>ChatView: sendMessage()
    ChatView->>Strategy: sendMessage(content)
    Strategy->>Store: 创建用户消息
    Store->>Store: addMessage(userMessage)
    Strategy->>Store: 创建临时回复
    Store->>Store: addMessage(tempReply)
    Strategy->>Store: 构建请求消息
    Store->>ApiService: sendChatMessage(request)
    ApiService->>Backend: HTTP请求
    Backend-->>ApiService: 响应数据
    ApiService-->>Store: 返回响应
    Store->>Store: 更新临时消息
    Store->>Storage: saveChatHistory()
    Storage->>Storage: 保存到IndexedDB
    Store-->>ChatView: 更新完成
    ChatView-->>User: 显示消息
```

### 2.2 接收消息流程（教师对话）

```mermaid
sequenceDiagram
    participant Teacher as 教师
    participant RabbitMQ as RabbitMQ
    participant AndroidBridge as AndroidBridge
    participant TeacherStore as teacherChatStore
    participant ChatView as ChatView
    participant Storage as ChatStorage

    Teacher->>RabbitMQ: 发送消息
    RabbitMQ->>AndroidBridge: 推送消息
    AndroidBridge->>TeacherStore: onTeacherMessageReceived()
    TeacherStore->>TeacherStore: 验证消息ID
    TeacherStore->>TeacherStore: 检查去重
    TeacherStore->>TeacherStore: addMessage(teacherMessage)
    TeacherStore->>Storage: saveChatHistory()
    Storage->>Storage: 保存到IndexedDB
    TeacherStore->>ChatView: 触发更新
    ChatView-->>User: 显示消息
```

## 七、技术栈

| 层级 | 技术/工具 |
|------|----------|
| 视图层 | Vue 3 + Quasar |
| 状态管理 | Pinia |
| 策略模式 | TypeScript Interface |
| 存储 | IndexedDB (localforage) + LocalStorage |
| HTTP请求 | Axios |
| 消息队列 | RabbitMQ (通过Android Bridge) |
| 滚动控制 | BetterScroll |

## 八、关键设计模式

1. **策略模式 (Strategy Pattern)**
   - 不同聊天场景使用不同的策略类
   - 统一接口，便于扩展和维护

2. **工厂模式 (Factory Pattern)**
   - ChatStrategyFactory 根据 type 创建对应策略

3. **单例模式 (Singleton Pattern)**
   - ApiService、ChatStorage 使用单例模式

4. **观察者模式 (Observer Pattern)**
   - Store 响应式更新，组件自动刷新

## 九、数据流向总结

```
用户输入 
  ↓
ChatInput 组件
  ↓
ChatView 组件 (策略选择)
  ↓
ChatStrategy (具体策略)
  ↓
ChatStore (状态管理)
  ↓
ApiService / AndroidBridge (服务层)
  ↓
后端API / RabbitMQ (外部接口)
  ↓
响应处理
  ↓
ChatStore 更新状态
  ↓
ChatStorage 持久化
  ↓
UI 自动更新
```
