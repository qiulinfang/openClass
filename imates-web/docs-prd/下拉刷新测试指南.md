## 控制台诊断工具

所有测试工具都会在页面加载时自动挂载到 `window` 对象，可以直接在浏览器控制台（F12）中调用。

### 1. 诊断函数（推荐）

**用法：**
```javascript
// 诊断滚动功能状态
diagnoseMyResourcesScroll()
```

**输出内容：**
- BScroll 实例状态（enabled, y, maxScrollY 等）
- scroll-wrapper 元素尺寸和样式
- scroll-content 元素尺寸
- textbooks-scroll-container 元素尺寸

**示例输出：**
```javascript
{
  timestamp: 1234567890,
  hasScrollWrapper: true,
  hasBScrollInstance: true,
  bscroll: {
    enabled: true,
    y: 0,
    maxScrollY: -500,
    hasVerticalScroll: true,
    ...
  },
  scrollWrapper: {
    clientHeight: 600,
    scrollHeight: 1100,
    ...
  }
}
```

## 常见问题排查

### 问题 1: 下拉刷新不触发

**排查步骤：**
1. 检查 BScroll 实例是否存在：
   ```javascript
   diagnoseMyResourcesScroll()
   // 查看 hasBScrollInstance 是否为 true
   ```
2. 检查 BScroll 是否启用：
   ```javascript
   // 查看 bscroll.enabled 是否为 true
   ```
3. 检查下拉距离：
   - 下拉时查看控制台的 `posY` 值
   - 确认是否超过阈值（60px）

**可能原因：**
- BScroll 实例未创建
- BScroll 被禁用
- 下拉距离不足

---

### 问题 2: 滚动事件不触发

**排查步骤：**
1. 检查 DOM 结构：
   ```javascript
   diagnoseMyResourcesScroll()
   // 查看 scrollWrapper 和 scrollContent 是否存在
   ```
2. 检查元素高度：
   - `scrollContent` 的高度应该大于 `scrollWrapper` 的高度
   - 否则无法滚动

**可能原因：**
- DOM 结构不正确
- 内容高度不足，无法滚动

---

### 问题 3: 触摸事件不触发

**排查步骤：**
1. 检查元素是否可点击：
   ```javascript
   const el = document.querySelector('.textbooks-scroll-container')
   console.log(el.style.pointerEvents)
   ```
2. 检查是否有其他元素遮挡

**可能原因：**
- `pointer-events: none`
- 其他元素覆盖

---

### 问题 4: 刷新状态不正确

**排查步骤：**
1. 查看控制台日志，确认状态变化顺序
2. 检查 `handlePullDownRefresh` 函数是否正确执行
3. 检查 `finishPullDown` 是否被调用

**可能原因：**
- 刷新逻辑出错
- 状态更新时机不对

## 测试技巧

### 1. 使用控制台监控状态

在控制台运行以下代码，实时监控状态：

```javascript
// 每 500ms 检查一次状态
setInterval(() => {
  const diag = diagnoseMyResourcesScroll()
  console.log('当前状态:', {
    y: diag.bscroll?.y,
    enabled: diag.bscroll?.enabled,
    maxScrollY: diag.bscroll?.maxScrollY
  })
}, 500)
```

### 2. 模拟下拉动作

在控制台模拟下拉：

```javascript
// 注意：这种方法可能不完全模拟真实的下拉，主要用于测试
const bscroll = window.diagnoseMyResourcesScroll()?.bscroll
if (bscroll) {
  // 手动触发滚动到正数位置（模拟下拉）
  bscroll.scrollTo(0, 60, 300)
}
```

### 3. 查看事件监听器

检查 BScroll 事件监听器是否正确注册：

```javascript
// 查看 BScroll 实例的事件列表
const bscroll = document.querySelector('.scroll-wrapper')?._bscrollInstance
console.log('事件监听器:', bscroll?.eventTypes)
```
