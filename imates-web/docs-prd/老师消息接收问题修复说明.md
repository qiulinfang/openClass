# 老师消息接收问题修复说明

## 问题描述

学生能够发送消息给老师，但老师发送消息给学生时，学生接收不到。

## 问题分析

### 根本原因

在 `ChatView.vue` 组件的 `onMounted` 生命周期钩子中，直接设置了 `window.onTeacherMessageReceived` 回调函数，覆盖了 `teacherChatStore.initMessageReceiver()` 中设置的回调函数。

### 问题流程

1. **初始化阶段**：
   - `ChatView.vue` 的 `initializeMessages()` 调用 `initializeTeacherSession()`
   - `initializeTeacherSession()` 调用 `teacherStore.initMessageReceiver()`
   - `initMessageReceiver()` 设置 `window.onTeacherMessageReceived` 回调函数（正确实现）

2. **覆盖阶段**：
   - `ChatView.vue` 的 `onMounted()` 执行
   - 第2274-2285行直接设置 `window.onTeacherMessageReceived = handleTeacherMessageReceived`
   - 这覆盖了 store 中设置的正确回调函数

3. **消息接收失败**：
   - `handleTeacherMessageReceived` 使用 `teacherSession.value` 而不是 `teacherStore.currentSession.value`
   - 两个状态可能不同步，导致 sessionId 匹配失败
   - 消息虽然被接收，但无法匹配到正确的会话，因此不显示

## 修复方案

### 1. 删除重复的回调设置

**文件**: `imates-web/src/components/ChatView.vue`

**修改前** (第2274-2285行):
```typescript
// 3.2 设置老师消息接收回调（仅在老师模式下）
if (props.type === 'teacher') {
  ;(
    window as unknown as {
      onTeacherMessageReceived: (messageData: {
        sessionId: string
        messageId: string
        content: string
      }) => void
    }
  ).onTeacherMessageReceived = handleTeacherMessageReceived
}
```

**修改后**:
```typescript
// 3.2 老师消息接收回调已由 teacherChatStore.initMessageReceiver() 统一管理
// 不需要在这里重复设置，避免覆盖 store 中的回调
```

### 2. 删除不再使用的处理函数

**文件**: `imates-web/src/components/ChatView.vue`

**删除** `handleTeacherMessageReceived` 函数（第2225-2247行），因为：
- 消息接收逻辑已统一由 `teacherChatStore` 管理
- 避免代码重复和状态不一致

### 3. 增强调试日志

**文件**: `imates-web/src/stores/teacherChatStore.ts`

在消息接收回调中添加详细的调试日志，帮助排查问题：

```typescript
console.log('[TeacherStore] 📨 收到教师消息:', messageData)
console.log('[TeacherStore] 📨 消息详情:', {
  messageId: data.messageId,
  sessionId: data.sessionId,
  contentLength: data.content?.length || 0,
  currentSessionId: currentSession.value?.sessionId,
  hasCurrentSession: !!currentSession.value
})

// 如果会话ID不匹配，输出警告
if (!匹配) {
  console.warn('[TeacherStore] ⚠️ 会话ID不匹配，忽略消息:', {
    receivedSessionId: data.sessionId,
    currentSessionId: currentSession.value?.sessionId || 'null',
    reason: !currentSession.value ? '当前会话为空' : '会话ID不一致'
  })
}
```

## 修复后的消息接收流程

1. **初始化阶段**：
   - `teacherStore.initMessageReceiver()` 被调用
   - 设置 `window.onTeacherMessageReceived` 回调函数（统一管理）

2. **消息接收**：
   - Android 端通过 RabbitMQ 接收老师消息
   - `MessagingManager` 调用 `notifyTeacherMessageReceived()`
   - WebView 执行 JavaScript：`window.onTeacherMessageReceived(data)`
   - Store 中的回调函数被调用
   - 使用 `currentSession.value?.sessionId` 匹配会话
   - 匹配成功则添加到消息列表并保存

3. **消息显示**：
   - 消息添加到 `teacherChatStore.messages`
   - Vue 组件自动响应式更新显示

## 验证方法

1. **检查日志**：
   - 打开浏览器控制台
   - 老师发送消息时，应该看到 `[TeacherStore] 📨 收到教师消息` 日志
   - 如果看到 `⚠️ 会话ID不匹配`，说明会话状态有问题

2. **检查会话状态**：
   - 确保 `teacherStore.currentSession.value` 不为空
   - 确保 `currentSession.value.sessionId` 与发送消息时使用的 sessionId 一致

3. **测试场景**：
   - 学生发送消息给老师（应该成功）
   - 老师回复消息（现在应该能收到并显示）
   - 检查消息是否正确显示在聊天界面中

## 注意事项

1. **统一使用 Store 管理**：
   - 所有消息接收逻辑都在 `teacherChatStore` 中
   - 避免在组件中直接设置全局回调函数

2. **会话状态同步**：
   - 使用 `teacherStore.currentSession.value` 而不是本地 `teacherSession.value`
   - 确保创建会话时调用 `teacherStore.setSession()` 或 `teacherStore.createTeacherSession()`

3. **初始化时机**：
   - `initMessageReceiver()` 应该在创建会话之前或创建会话时调用
   - 确保在消息可能到达之前已经初始化完成
