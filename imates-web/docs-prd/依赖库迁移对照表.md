## ⚠️ 特殊说明

### 1. MathLive
- **问题**：MathLive 是专为 Web 设计的，没有 React Native 版本
- **解决方案**：
  - 方案 A：使用 WebView 嵌入 MathLive（快速方案）
  - 方案 B：使用 `react-native-math-view`（需要适配）
  - 方案 C：自定义组件（长期方案）

### 2. TipTap
- **问题**：TipTap 是专为 Vue 设计的富文本编辑器
- **解决方案**：
  - 方案 A：使用 `react-native-rich-text-editor`
  - 方案 B：使用 `react-native-webview` 嵌入 TipTap

### 3. Fabric.js
- **问题**：Fabric.js 是 Canvas API，React Native 不支持
- **解决方案**：使用 `react-native-svg` 重写画布绘制逻辑

### 4. Better Scroll
- **问题**：Better Scroll 是专为 Web 设计的滚动库
- **解决方案**：使用 React Native 内置的 `ScrollView` 和 `FlatList`

### 5. PDF.js
- **问题**：PDF.js 是专为 Web 设计的 PDF 渲染库
- **解决方案**：使用 `react-native-pdf` 原生库
