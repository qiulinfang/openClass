# 自由框选逻辑分析

## 概述

自由框选是PDF笔记系统中的一种选择工具，允许用户通过自由绘制路径（多边形）来选择笔记对象。与矩形框选不同，自由框选可以更精确地选择不规则区域内的笔记。

## 核心功能

### 1. 选择模式

系统支持两种选择模式：
- **矩形选择**（`rectangle`）：默认模式，通过拖动创建矩形选区
- **自由框选**（`freeform`）：通过自由绘制路径创建多边形选区

选择模式通过 `store.drawingConfig.selectMode` 配置：
```typescript
const selectMode = store.drawingConfig.selectMode || 'rectangle'
```

### 2. 状态管理

自由框选使用以下状态变量：

```typescript
// 自由框选路径（多边形顶点）
const selectionPath = ref<{ x: number; y: number }[]>([])

// 矩形选择框（与自由框选互斥）
const selectionBox = ref<{ x: number; y: number; width: number; height: number } | null>(null)

// 选中的对象索引集合
const selectedObjects = ref<Set<number>>(new Set())

// 绘制状态
const isDrawing = ref(false)
const startPoint = ref<{ x: number; y: number } | null>(null)
```

## 完整流程

### 1. 鼠标按下（mousedown）

**触发条件**：
- 工具为 `select`
- 点击在空白处（未点击在任何对象上）
- 选择模式为 `freeform`

**处理逻辑**：

```typescript
const handleDrawingMouseDown = (e: MouseEvent) => {
  const coords = getCanvasCoords(e)
  if (!coords) return
  
  const tool = store.selectedTool
  
  if (tool === 'select') {
    // 检查是否点击在已选中的图形上
    let clickedOnSelected = false
    for (const index of selectedObjects.value) {
      if (isPointInObject(coords.x, coords.y, objects.value[index])) {
        clickedOnSelected = true
        break
      }
    }

    if (clickedOnSelected && selectedObjects.value.size > 0) {
      // 点击在已选中的图形上，开始拖拽
      isDraggingObjects.value = true
      dragStartPoint.value = { ...coords }
      // ... 保存原始位置
    } else {
      // 点击在空白处或未选中的图形上
      const clickedIndex = findObjectAtPoint(coords.x, coords.y)
      if (clickedIndex !== null) {
        // 点击在某个对象上，选中该对象
        selectedObjects.value.clear()
        selectedObjects.value.add(clickedIndex)
      } else {
        // 点击在空白处，根据选择模式开始框选
        const selectMode = store.drawingConfig.selectMode || 'rectangle'
        selectedObjects.value.clear()
        
        if (selectMode === 'freeform') {
          // 自由框选：初始化路径
          selectionPath.value = [coords]  // 第一个点
          selectionBox.value = null       // 清空矩形选择
        } else {
          // 矩形选择：初始化选框
          selectionBox.value = {
            x: coords.x,
            y: coords.y,
            width: 0,
            height: 0,
          }
          selectionPath.value = []        // 清空路径
        }
      }
    }
    render()
  }
}
```

**关键点**：
- 如果选择模式为 `freeform`，初始化 `selectionPath` 为包含第一个点的数组
- 清空 `selectionBox`，确保矩形选择和自由框选互斥
- 清空之前的选择

### 2. 鼠标移动（mousemove）

**处理逻辑**：

```typescript
const handleDrawingMouseMove = (e: MouseEvent) => {
  const coords = getCanvasCoords(e)
  if (!coords) return
  
  const tool = store.selectedTool
  
  if (tool === 'select') {
    if (!isDrawing.value || !startPoint.value) return
    
    if (isDraggingObjects.value && dragStartPoint.value) {
      // 拖拽选中的对象
      // ... 拖拽逻辑
    } else if (selectionBox.value && startPoint.value) {
      // 矩形选择：绘制选框
      selectionBox.value = {
        x: Math.min(startPoint.value.x, coords.x),
        y: Math.min(startPoint.value.y, coords.y),
        width: Math.abs(coords.x - startPoint.value.x),
        height: Math.abs(coords.y - startPoint.value.y),
      }
      render()
    } else if (selectionPath.value.length > 0) {
      // 自由框选：添加点到路径
      selectionPath.value.push(coords)
      render()
    }
  }
}
```

**关键点**：
- 当 `selectionPath.length > 0` 时，说明正在进行自由框选
- 每次鼠标移动都会将当前坐标添加到路径中
- 实时渲染，显示当前绘制的路径

**注意**：自由框选在鼠标移动时持续添加点，形成一条连续的路径。这与矩形选择不同，矩形选择只更新选框的尺寸。

### 3. 鼠标抬起（mouseup）

**处理逻辑**：

```typescript
const handleDrawingMouseUp = () => {
  const tool = store.selectedTool
  
  if (tool === 'select') {
    // 选择工具处理
    if (isDraggingObjects.value) {
      // 拖拽结束，保存状态
      saveAnnotations()
      isDraggingObjects.value = false
      dragStartPoint.value = null
      objectsOriginalPositions.value.clear()
    } else if (
      selectionBox.value &&
      selectionBox.value.width > 10 &&
      selectionBox.value.height > 10
    ) {
      // 矩形框选结束，选中与选框相交的所有对象
      const selectedIndices = findObjectsInRect(selectionBox.value)
      selectedObjects.value = new Set(selectedIndices)
    } else if (selectionPath.value.length > 3) {
      // 自由框选结束，选中与多边形相交的所有对象
      const selectedIndices = findObjectsInPolygon(selectionPath.value)
      selectedObjects.value = new Set(selectedIndices)
    } else if (selectionBox.value && selectionBox.value.width <= 10 && selectionBox.value.height <= 10) {
      // 点击空白处，清空选择（仅在确实没有移动时）
      // ... 清空逻辑
    }

    // 重置选择工具的状态
    selectionBox.value = null
    selectionPath.value = []
    isDrawing.value = false
    startPoint.value = null

    // 恢复光标
    if (drawingCanvas.value) {
      drawingCanvas.value.style.cursor = 'crosshair'
    }
    
    render()
  }
}
```

**关键点**：
- 只有当 `selectionPath.value.length > 3` 时，才执行自由框选的选中逻辑
- 使用 `findObjectsInPolygon` 查找与多边形相交的所有对象
- 选中后重置所有状态（`selectionPath`、`selectionBox` 等）

**为什么需要 `length > 3`**：
- 至少需要4个点才能形成一个有效的多边形（3个顶点 + 1个闭合点）
- 少于4个点的路径被认为是无效的，不会执行选中操作

## 核心算法

### 1. 射线法判断点是否在多边形内

```typescript
// 判断点是否在多边形内（使用射线法）
const isPointInPolygon = (point: { x: number; y: number }, polygon: { x: number; y: number }[]): boolean => {
  if (polygon.length < 3) return false
  
  let inside = false
  for (let i = 0, j = polygon.length - 1; i < polygon.length; j = i++) {
    const xi = polygon[i].x
    const yi = polygon[i].y
    const xj = polygon[j].x
    const yj = polygon[j].y
    
    const intersect = ((yi > point.y) !== (yj > point.y)) &&
      (point.x < (xj - xi) * (point.y - yi) / (yj - yi) + xi)
    if (intersect) inside = !inside
  }
  return inside
}
```

**算法说明**：
- **射线法（Ray Casting Algorithm）**：从点向右发射一条射线，计算与多边形边界的交点数量
- 如果交点数量为奇数，点在多边形内；如果为偶数，点在多边形外
- 时间复杂度：O(n)，其中 n 是多边形的顶点数

### 2. 判断对象是否与多边形相交

```typescript
// 判断对象是否与多边形相交或在其内部
const isPolygonIntersectObject = (polygon: { x: number; y: number }[], obj: DrawObject): boolean => {
  const bounds = getObjectBounds(obj)
  if (!bounds) return false
  
  // 检查对象的边界框是否与多边形相交
  // 简化：检查边界框的四个角点是否至少有一个在多边形内或边界上
  const corners = [
    { x: bounds.x, y: bounds.y },
    { x: bounds.x + bounds.width, y: bounds.y },
    { x: bounds.x + bounds.width, y: bounds.y + bounds.height },
    { x: bounds.x, y: bounds.y + bounds.height },
    { x: bounds.x + bounds.width / 2, y: bounds.y + bounds.height / 2 }, // 中心点
  ]
  
  // 如果至少有一个角点或多边形的至少一个顶点在对象边界内，则认为相交
  for (const corner of corners) {
    if (isPointInPolygon(corner, polygon)) {
      return true
    }
  }
  
  // 检查多边形顶点是否在对象内
  for (const point of polygon) {
    if (isPointInObject(point.x, point.y, obj)) {
      return true
    }
  }
  
  // 对于路径对象，检查路径点是否在多边形内
  if (obj.type === 'path' && obj.points) {
    for (const point of obj.points) {
      if (isPointInPolygon(point, polygon)) {
        return true
      }
    }
  }
  
  return false
}
```

**判断策略**：
1. **检查对象的边界框角点**：如果对象的任意角点（包括中心点）在多边形内，则认为相交
2. **检查多边形顶点**：如果多边形的任意顶点在对象内，则认为相交
3. **检查路径对象的点**：对于路径对象，检查路径点是否在多边形内

**为什么这样设计**：
- 这是一个**简化的相交检测**，不是精确的多边形-多边形相交
- 对于大多数使用场景，这种检测已经足够准确
- 精确的多边形-多边形相交算法复杂度较高（O(n²)），可能影响性能

### 3. 查找与多边形相交的所有对象

```typescript
// 查找与多边形相交的所有对象
const findObjectsInPolygon = (polygon: { x: number; y: number }[]): number[] => {
  const result: number[] = []
  objects.value.forEach((obj, index) => {
    if (isPolygonIntersectObject(polygon, obj)) {
      result.push(index)
    }
  })
  return result
}
```

**时间复杂度**：O(n × m)
- n：对象数量
- m：多边形顶点数量（对于路径对象，还要考虑路径点的数量）

## 视觉呈现

### 绘制自由框选路径

```typescript
// 绘制自由框选路径（如果有）
if (selectionPath.value && selectionPath.value.length > 0 && ctx) {
  ctx.save()
  ctx.strokeStyle = '#2196F3'              // 蓝色边框
  ctx.fillStyle = 'rgba(33, 150, 243, 0.1)' // 半透明蓝色填充
  ctx.lineWidth = 2
  ctx.setLineDash([5, 5])                   // 虚线
  ctx.lineCap = 'round'
  ctx.lineJoin = 'round'
  
  ctx.beginPath()
  ctx.moveTo(selectionPath.value[0].x, selectionPath.value[0].y)
  for (let i = 1; i < selectionPath.value.length; i++) {
    ctx.lineTo(selectionPath.value[i].x, selectionPath.value[i].y)
  }
  // 如果路径未闭合，连接起点和终点
  if (selectionPath.value.length > 2) {
    ctx.closePath()
  }
  
  // 使用 even-odd 规则填充，与 isPointInPolygon（射线法）保持一致
  ctx.fill('evenodd')
  ctx.stroke()
  
  ctx.restore()
}
```

**视觉特性**：
- **边框颜色**：蓝色（`#2196F3`）
- **填充颜色**：半透明蓝色（`rgba(33, 150, 243, 0.1)`）
- **线型**：虚线（`[5, 5]`）
- **线宽**：2像素
- **闭合**：如果路径长度大于2，自动闭合（连接起点和终点）
- **填充规则**：使用 `even-odd`（奇偶规则），与命中检测的射线法保持一致

**重要说明**：
- Canvas 填充使用 `even-odd` 规则，与 `isPointInPolygon` 函数使用的射线法（Ray Casting）保持一致
- 这确保了用户看到的选区高亮范围 = 实际被选中的对象范围
- 对于自相交路径（如"8"字形），交叉区域会被"挖空"，符合直觉预期

## 与矩形选择的对比

| 特性 | 矩形选择 | 自由框选 |
|------|---------|---------|
| **选择模式** | `rectangle` | `freeform` |
| **状态变量** | `selectionBox` | `selectionPath` |
| **初始化** | 设置初始点 + width/height=0 | 设置路径为第一个点 |
| **移动处理** | 更新 width/height | 添加点到路径 |
| **选中条件** | width > 10 && height > 10 | length > 3 |
| **检测算法** | `findObjectsInRect` | `findObjectsInPolygon` |
| **算法复杂度** | O(n) | O(n × m) |
| **适用场景** | 规则矩形区域 | 不规则区域 |

## 使用场景

### 1. 精确选择不规则区域
- 当需要选择的笔记分布在不规则区域时，自由框选比矩形选择更精确
- 例如：选择分散在不同位置的多个笔记，但不想选中中间的其他笔记

### 2. 选择复杂路径笔记
- 对于路径类型的笔记（如手写笔迹），自由框选可以更精确地选择部分路径
- 矩形选择可能会选中不需要的相邻笔记

### 3. 排除特定区域
- 通过精确绘制路径，可以排除某些区域，只选择需要的笔记

## 性能考虑

### 1. 路径点数量
- 自由框选在鼠标移动时持续添加点，如果移动过快，可能产生大量点
- 当前实现没有限制点的数量，可能影响性能

**优化建议**：
- 可以添加点与点之间的最小距离限制，避免过于密集的点
- 可以使用路径简化算法（如 Douglas-Peucker 算法）减少点的数量

### 2. 相交检测复杂度
- `isPolygonIntersectObject` 对于路径对象，会检查所有路径点
- 如果路径很长（点很多），检测可能较慢

**优化建议**：
- 对于路径对象，可以先检查边界框是否与多边形相交
- 只在边界框相交时，才检查路径点

### 3. 实时渲染
- 每次鼠标移动都会触发渲染，如果路径点很多，可能影响流畅度

**优化建议**：
- 可以使用 `requestAnimationFrame` 节流渲染
- 或者只在路径点数量变化时渲染

## 潜在问题与改进

### 1. 路径未闭合的视觉反馈
- 当前实现会在路径长度 > 2 时自动闭合，但用户可能不知道路径是否已闭合
- **改进建议**：在鼠标抬起前，显示闭合预览（例如：虚线连接起点和当前点）

### 2. 最小有效路径
- 当前要求路径长度 > 3，但用户可能不知道这个限制
- **改进建议**：在路径长度不足时，显示提示信息

### 3. 路径点密度
- 鼠标移动越快，路径点越稀疏，可能导致选择不准确
- **改进建议**：使用插值算法，在点之间添加中间点

### 4. 触摸设备支持
- 当前实现主要针对鼠标事件，触摸设备可能需要不同的处理
- **改进建议**：添加触摸事件支持，或使用统一的事件处理

## 总结

自由框选逻辑的核心要点：

1. **状态管理**：使用 `selectionPath` 存储多边形顶点
2. **模式切换**：通过 `selectMode` 配置在矩形选择和自由框选之间切换
3. **路径绘制**：在鼠标移动时持续添加点
4. **相交检测**：使用射线法判断点是否在多边形内，使用简化的相交检测判断对象是否与多边形相交
5. **视觉反馈**：使用蓝色虚线边框和半透明填充显示选择区域

自由框选提供了比矩形选择更灵活的选择方式，特别适合选择不规则区域内的笔记。但在性能敏感的场景下，需要注意路径点的数量和相交检测的复杂度。
