# 截图功能调试日志指南

## 🔍 重点关注的日志（按优先级排序）

### ⚠️ **优先级1：坐标映射阶段（最关键）**

**位置**：`ScreenshotInputDialog.vue` - `getCroppedImage` 方法

**日志标识**：`[截图对话框] ========== 坐标映射详细信息 ==========`

**重点检查项**：

1. **日志5：映射到原始图片的坐标**
   ```javascript
   boundsCheck: {
     xInBounds: sourceX >= 0 && sourceX < originalWidth,
     yInBounds: sourceY >= 0 && sourceY < originalHeight,
     widthInBounds: sourceX + sourceWidth <= originalWidth,
     heightInBounds: sourceY + sourceHeight <= originalHeight
   }
   ```
   - **问题定位**：如果任何一项为 `false`，说明坐标越界，会导致裁剪失败或结果异常
   - **常见问题**：裁剪框超出图片边界、缩放计算错误

2. **日志4：裁剪区域相对于图片绘制区域的坐标**
   ```javascript
   isValid: cropWidthInImage > 0 && cropHeightInImage > 0
   ```
   - **问题定位**：如果为 `false`，说明裁剪区域无效
   - **常见问题**：裁剪框完全在图片绘制区域外

3. **日志3：裁剪区域限制在图片绘制区域内**
   - **问题定位**：检查 `cropStartX/Y` 和 `cropEndX/Y` 是否在 `drawBounds` 范围内
   - **常见问题**：裁剪框包含了画布的留白区域

4. **日志2：图片绘制信息**
   - **问题定位**：检查 `scaleX` 和 `scaleY` 是否一致（应该相等）
   - **常见问题**：缩放比例计算错误导致坐标映射偏差

---

### ⚠️ **优先级2：截图捕获阶段**

**位置**：`PdfPage.vue` - `captureScreenshot` 方法

**日志标识**：`[截图工具] 开始绘制PDF内容`

**重点检查项**：

1. **边界检查**
   ```javascript
   sourceBounds: {
     xInBounds: sourceX >= 0 && sourceX < pdfCanvasWidth,
     yInBounds: sourceY >= 0 && sourceY < pdfCanvasHeight,
     widthInBounds: sourceX + sourceWidth <= pdfCanvasWidth,
     heightInBounds: sourceY + sourceHeight <= pdfCanvasHeight
   }
   ```
   - **问题定位**：如果任何一项为 `false`，说明截图区域超出 PDF Canvas
   - **常见问题**：截图选区计算错误、Canvas 尺寸获取错误

2. **尺寸信息**
   ```javascript
   pdfCanvasSize: { width, height },
   bounds: { x, y, width, height },
   tempCanvasSize: { width, height }
   ```
   - **问题定位**：检查 `bounds` 是否合理，`tempCanvas` 尺寸是否正确
   - **常见问题**：bounds 为负数或过大

3. **Blob 生成结果**
   ```javascript
   blobSize: blob.size,
   blobSizeKB: (blob.size / 1024).toFixed(2)
   ```
   - **问题定位**：如果 `blobSize` 为 0 或异常小，说明截图失败
   - **常见问题**：Canvas 为空、绘制失败

---

### ⚠️ **优先级3：图片加载阶段**

**位置**：`ScreenshotInputDialog.vue` - `initCropCanvas` 方法

**日志标识**：`[截图对话框] 图片绘制信息`

**重点检查项**：

1. **图片绘制信息**
   ```javascript
   drawInfo: { drawX, drawY, drawWidth, drawHeight },
   originalSize: { width, height },
   scale: { scaleX, scaleY },
   hasPadding: drawX > 0 || drawY > 0
   ```
   - **问题定位**：
     - `scaleX` 和 `scaleY` 应该相等（contain 模式）
     - `hasPadding` 表示图片是否有留白（正常情况）
     - `drawWidth/Height` 应该 ≤ `canvas.width/height`
   - **常见问题**：缩放计算错误、图片未正确加载

2. **图片加载成功**
   ```javascript
   originalSize: { width: img.width, height: img.height }
   ```
   - **问题定位**：如果尺寸为 0，说明图片加载失败
   - **常见问题**：DataURL 格式错误、图片损坏

---

### ⚠️ **优先级4：裁剪框操作阶段**

**位置**：`ScreenshotInputDialog.vue` - `startCrop`、`endCrop` 方法

**日志标识**：`[截图对话框] 裁剪框绘制完成`

**重点检查项**：

1. **裁剪框边界检查**
   ```javascript
   rectInImageBounds: {
     xInBounds: finalRect.x >= imageDrawInfo.value.drawX,
     yInBounds: finalRect.y >= imageDrawInfo.value.drawY,
     widthInBounds: finalRect.x + finalRect.width <= imageDrawInfo.value.drawX + imageDrawInfo.value.drawWidth,
     heightInBounds: finalRect.y + finalRect.height <= imageDrawInfo.value.drawY + imageDrawInfo.value.drawHeight
   }
   ```
   - **问题定位**：如果任何一项为 `false`，说明裁剪框超出图片区域
   - **常见问题**：裁剪框包含了画布留白、坐标计算错误

## 📐 如何判断截图Canvas尺寸 = 绘制到预览Canvas的尺寸

### 关键日志位置

#### 1. 截图Canvas尺寸（捕获阶段）

**日志标识**：`[截图工具] 创建临时Canvas`

**日志内容**：
```javascript
{
  width: tempCanvas.width,      // 截图Canvas宽度
  height: tempCanvas.height,    // 截图Canvas高度
  bounds: bounds
}
```

**说明**：这是用户框选区域的实际尺寸，也是最终发送给AI的图片尺寸。

---

#### 2. 原始图片尺寸（加载阶段）

**日志标识**：`[截图对话框] 图片加载成功`

**日志内容**：
```javascript
{
  originalSize: { 
    width: img.width,   // 原始图片宽度（应该 = 截图Canvas宽度）
    height: img.height  // 原始图片高度（应该 = 截图Canvas高度）
  },
  canvasSize: { 
    width: canvas.width,   // 预览Canvas宽度
    height: canvas.height  // 预览Canvas高度
  }
}
```

**判断点1**：验证截图是否正常
- ✅ **正常**：`img.width === tempCanvas.width` 且 `img.height === tempCanvas.height`
- ❌ **异常**：如果不相等，说明截图捕获或转换过程有问题

---

#### 3. 预览Canvas尺寸（初始化阶段）

**日志标识**：`[截图对话框] 开始初始化裁剪画布`

**日志内容**：
```javascript
{
  canvasSize: { 
    width: canvas.width,   // 预览Canvas宽度（来自容器尺寸）
    height: canvas.height  // 预览Canvas高度（来自容器尺寸）
  }
}
```

**说明**：这是对话框预览区域的Canvas尺寸，通常比截图Canvas小（因为需要适配对话框大小）。

---

#### 4. 图片绘制尺寸（绘制阶段）

**日志标识**：`[截图对话框] 图片绘制信息`

**日志内容**：
```javascript
{
  drawInfo: { 
    drawX,        // 绘制起始X坐标（可能有留白）
    drawY,        // 绘制起始Y坐标（可能有留白）
    drawWidth,    // 绘制宽度（contain模式，可能有缩放）
    drawHeight    // 绘制高度（contain模式，可能有缩放）
  },
  originalSize: { 
    width: img.width, 
    height: img.height 
  },
  scale: { 
    scaleX,  // X方向缩放比例 = img.width / drawWidth
    scaleY   // Y方向缩放比例 = img.height / drawHeight
  },
  canvasSize: { 
    width: canvas.width, 
    height: canvas.height 
  },
  hasPadding: drawX > 0 || drawY > 0  // 是否有留白
}
```

**判断点2**：验证绘制尺寸关系
- `drawWidth` ≤ `canvas.width`（contain模式，图片可能不会填满Canvas）
- `drawHeight` ≤ `canvas.height`（contain模式，图片可能不会填满Canvas）
- `scaleX === scaleY`（contain模式，保持宽高比）

---

### 📊 尺寸关系判断流程

#### 步骤1：验证截图Canvas = 原始图片尺寸

**查找日志**：
1. `[截图工具] 创建临时Canvas` → 获取 `tempCanvas.width` 和 `tempCanvas.height`
2. `[截图对话框] 图片加载成功` → 获取 `img.width` 和 `img.height`

**判断公式**：
```javascript
截图Canvas尺寸 === 原始图片尺寸
tempCanvas.width === img.width && tempCanvas.height === img.height
```

**结果**：
- ✅ **相等**：截图捕获正常，图片尺寸正确
- ❌ **不相等**：截图捕获或转换过程有问题，需要检查截图捕获逻辑

---

#### 步骤2：判断截图Canvas尺寸 = 绘制尺寸（特殊情况）

**查找日志**：
1. `[截图工具] 创建临时Canvas` → 获取 `tempCanvas.width` 和 `tempCanvas.height`
2. `[截图对话框] 图片绘制信息` → 获取 `drawWidth` 和 `drawHeight`

**判断公式**：
```javascript
截图Canvas尺寸 === 绘制尺寸
tempCanvas.width === drawWidth && tempCanvas.height === drawHeight
```

**结果**：
- ✅ **相等**：说明预览Canvas足够大，图片以1:1比例显示（无缩放）
- ❌ **不相等**：这是**正常情况**，因为预览Canvas通常比截图Canvas小，图片会按contain模式缩放显示

**注意**：大多数情况下，`drawWidth < tempCanvas.width` 或 `drawHeight < tempCanvas.height`，这是正常的，因为：
- 预览Canvas尺寸受对话框容器限制（通常520x300左右）
- 截图Canvas尺寸是用户框选的实际区域（可能很大）
- 图片以contain模式显示，会等比例缩放以适应预览Canvas

---

#### 步骤3：验证绘制尺寸关系（正常情况）

**查找日志**：
- `[截图对话框] 图片绘制信息`

**判断公式**：
```javascript
// 1. 绘制尺寸应该 ≤ 预览Canvas尺寸
drawWidth <= canvas.width && drawHeight <= canvas.height

// 2. 缩放比例应该一致（contain模式）
scaleX === scaleY

// 3. 如果有留白，说明图片宽高比与Canvas不同
hasPadding === true  // 这是正常的
```

**结果**：
- ✅ **全部满足**：图片绘制正常，缩放计算正确
- ❌ **不满足**：需要检查缩放计算逻辑

---

### 🎯 实际判断示例

#### 示例1：截图Canvas尺寸 = 原始图片尺寸（正常）

```
[截图工具] 创建临时Canvas
  width: 800, height: 600

[截图对话框] 图片加载成功
  originalSize: { width: 800, height: 600 }
  canvasSize: { width: 520, height: 300 }
```

**判断**：✅ `800 === 800 && 600 === 600` → 截图正常

---

#### 示例2：截图Canvas尺寸 ≠ 绘制尺寸（正常情况）

```
[截图工具] 创建临时Canvas
  width: 800, height: 600

[截图对话框] 图片绘制信息
  drawInfo: { drawWidth: 400, drawHeight: 300 }
  originalSize: { width: 800, height: 600 }
  canvasSize: { width: 520, height: 300 }
  scale: { scaleX: 2, scaleY: 2 }
```

**判断**：
- ✅ `800 !== 400` → 这是正常的，因为预览Canvas较小，图片被缩放显示
- ✅ `scaleX === scaleY === 2` → 缩放比例一致，保持宽高比
- ✅ `drawWidth(400) <= canvas.width(520)` → 绘制尺寸在Canvas范围内

---

#### 示例3：截图Canvas尺寸 = 绘制尺寸（特殊情况）

```
[截图工具] 创建临时Canvas
  width: 400, height: 300

[截图对话框] 图片绘制信息
  drawInfo: { drawWidth: 400, drawHeight: 300 }
  originalSize: { width: 400, height: 300 }
  canvasSize: { width: 520, height: 300 }
  scale: { scaleX: 1, scaleY: 1 }
```

**判断**：
- ✅ `400 === 400 && 300 === 300` → 截图尺寸 = 绘制尺寸（1:1显示）
- ✅ `scaleX === scaleY === 1` → 无缩放，原尺寸显示
- ✅ `drawWidth(400) <= canvas.width(520)` → 有留白，正常
