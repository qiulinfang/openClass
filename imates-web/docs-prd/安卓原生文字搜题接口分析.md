# 安卓原生拍照搜题的文字搜题接口分析

## 一、接口概述

文字搜题功能允许用户通过输入题目关键字文本，直接搜索匹配的题目，是拍照搜题功能的补充方式。当用户无法拍照或图片识别失败时，可以通过文字输入进行搜索。

```145:188:app/src/main/java/com/cosinetech/imates/coreapiservice/ApiGateWayService.java
public static void searchQuestionByKeyText(String baseUrl, String keyText, String token, ExerciseRecognitionCallback callback) {
    Runnable task = () -> {
        try {
            OkHttpClient client = createClient();

//                Uri.Builder builder = Uri.parse(baseUrl).buildUpon()
//                        .appendPath(URLEncoder.encode(keyText, "UTF-8")); // 对路径参数进行编码

//                String url = builder.build().toString();

            // 创建请求
            Request request = new Request.Builder()
                    .url(baseUrl + "/" + keyText)
                    .get()
                    .addHeader("token", token)
                    .build();

            // 发送请求
            try (Response response = client. newCall(request).execute()) {
                if (response.isSuccessful()) {
                    if (callback != null && response.body() != null) {
                        QuestionImageResponse q = QuestionImageResponse.fromJson(response.body().string());
                        if(!q.data.item.questionsConfirm.isEmpty()) {
                            callback.onSuccess(q.data.item.questionsConfirm.get(0));
                        } else {
                            callback.onFailure(response.message(), response.code());
                        }
                    }
                } else {
                    if (callback != null) {
                        callback.onFailure(response.message(), response.code());
                    }
                    fileterFailedResponse(response);
                }
            }
        } catch (Exception e) {
            if(callback != null) {
                callback.onFailure(e.getMessage(), 1);
            }
        }
    };

    executor.submit(task);
}
```

## 五、错误处理机制

### 5.1 错误类型

1. **输入验证错误**
   - 关键字为空：提示"输入题目关键字再搜索"

2. **网络请求错误**
   - HTTP错误：显示错误消息和状态码
   - 异常错误：显示异常信息

3. **响应解析错误**
   - 列表为空：视为搜索失败
   - JSON解析异常：捕获异常并回调失败

4. **认证错误**
   - 401/403状态码：自动登出并重启应用

## 七、接口特点分析

### 7.1 优点

1. **异步执行**: 使用线程池，不阻塞UI
2. **科目区分**: 支持生物和数学两个科目
3. **统一响应格式**: 与图片识别接口使用相同的响应结构
4. **错误处理**: 完整的错误处理机制，包括认证错误自动处理

### 7.2 潜在问题

1. **URL编码问题**: 
   - 当前实现直接将关键字拼接到URL路径中，如果关键字包含特殊字符（如空格、中文、特殊符号）可能导致请求失败
   - 代码中有注释掉的URL编码逻辑，但未启用

2. **只返回第一个结果**:
   - 接口返回列表，但只取第一个结果
   - 如果存在多个匹配结果，用户无法选择

3. **超时时间过长**:
   - 120秒超时时间可能过长，影响用户体验

4. **错误提示不够详细**:
   - 失败时只显示"没有搜索到题目"，没有区分网络错误、认证错误等不同情况

## 八、使用场景

### 8.1 适用场景

1. 用户无法拍照时，直接输入题目关键字搜索
2. 图片识别失败后，提供文字搜索作为备选方案
3. 用户已知题目部分内容，想快速搜索

### 8.2 与拍照搜题的关系

- 文字搜题和图片识别共用相同的响应结构
- 两者返回的题目数据格式一致
- 都可以添加到题目列表
- 都支持生物和数学两个科目

## 十一、总结

文字搜题接口是拍照搜题功能的重要补充，提供了通过文本关键字搜索题目的能力。接口实现采用异步方式，支持生物和数学两个科目，使用统一的响应数据格式。主要需要注意URL编码问题，以及错误处理的用户友好性。

接口设计合理，与图片识别接口保持一致的数据结构，便于统一处理。建议修复URL编码问题，优化错误提示，提升用户体验。
