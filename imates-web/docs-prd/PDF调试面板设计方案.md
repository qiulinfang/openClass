# PDF调试面板设计方案

## 一、需求分析

### 1.1 需求背景
开发过程中需要调试PDF查看器的各种参数，特别是缩放、布局、渲染等关键参数，以便快速定位和解决问题。

### 1.2 功能目标
创建一个可实时调整的调试面板，允许开发者：
- 实时调整PDF缩放比例
- 查看和调整页面布局参数
- 查看渲染相关参数
- 查看设备像素比等系统参数
- 实时查看当前页面的viewport信息

## 二、技术分析

### 2.1 当前PDF相关参数梳理

#### 2.1.1 缩放参数
- **scale**: 当前缩放比例，范围 0.5 - 3.0，存储在 `pdfViewerStore.scale`
- **scalePercentage**: 缩放百分比，计算属性 `Math.round(state.scale * 100)`
- **devicePixelRatio**: 设备像素比，用于高DPI支持

#### 2.1.2 布局参数
- **pageLayouts**: 页面布局数组，每页包含：
  - `pageNum`: 页码
  - `top`: 顶部位置
  - `height`: 页面高度
  - `width`: 页面宽度
- **PAGE_GAP**: 页面间距，固定值 20px

#### 2.1.3 渲染参数
- **viewport**: PDF页面的视口信息
  - `width`: 视口宽度
  - `height`: 视口高度
- **canvas实际尺寸**: `viewport.width * devicePixelRatio`
- **canvas显示尺寸**: `viewport.width` (CSS像素)

#### 2.1.4 当前页面信息
- **currentPage**: 当前页码
- **totalPages**: 总页数

### 2.2 参数调整影响分析

#### 2.2.1 scale调整
- 直接影响PDF页面的渲染尺寸
- 触发 `pageLayouts` 重新计算
- 触发所有页面的重新渲染
- 影响DrawingBoard Canvas的尺寸

#### 2.2.2 页面布局参数调整
- `PAGE_GAP` 调整会影响页面间距
- 需要重新计算所有页面的 `top` 位置

### 2.3 实现位置
- 调试面板应该放在 `PdfViewerView.vue` 中
- 可以通过快捷键或按钮触发显示/隐藏
- 使用 Quasar 的 `q-dialog` 或固定在页面一侧的浮动面板

## 三、设计方案

### 3.1 UI设计

#### 3.1.1 面板布局
- 使用固定定位，位于页面右上角
- 可折叠/展开
- 使用半透明背景，不影响正常使用
- 面板宽度约 300-350px
- 最大高度为视口高度，超出可滚动

#### 3.1.2 参数分组
1. **缩放控制**
   - 缩放比例滑块 (0.5 - 3.0)
   - 缩放百分比输入框
   - 快速缩放按钮（25%, 50%, 100%, 150%, 200%）

2. **布局参数**
   - 页面间距 (PAGE_GAP) 输入框
   - 当前页面布局信息显示（只读）
   - 重新计算布局按钮

3. **渲染信息**（只读）
   - 设备像素比 (devicePixelRatio)
   - 当前页面viewport尺寸
   - Canvas实际尺寸
   - Canvas显示尺寸

4. **页面信息**（只读）
   - 当前页码 / 总页数
   - 当前页面高度
   - 当前页面宽度

### 3.2 功能设计

#### 3.2.1 缩放调整
- 滑块实时调整 `store.scale`
- 输入框支持直接输入百分比
- 快速按钮一键设置常用缩放比例
- 调整后自动触发重新渲染

#### 3.2.2 布局调整
- 页面间距可调整，调整后重新计算所有页面布局
- 显示当前选中页面的布局信息
- 提供"重新计算布局"按钮，手动触发

#### 3.2.3 实时信息显示
- 实时显示当前页面的viewport信息
- 实时显示Canvas尺寸信息
- 实时显示设备像素比

#### 3.2.4 面板控制
- 显示/隐藏切换（快捷键 Ctrl+Shift+D 或固定按钮）
- 重置所有参数到默认值
- 导出当前参数配置

### 3.3 技术实现

#### 3.3.1 组件结构
```
PdfDebugPanel.vue (新建组件)
├── 缩放控制区域
├── 布局参数区域
├── 渲染信息区域
├── 页面信息区域
└── 控制按钮区域
```

#### 3.3.2 数据流
- 读取：从 `pdfViewerStore` 读取当前参数
- 写入：通过 `pdfViewerStore` 的 actions 修改参数
- 监听：使用 `watch` 监听参数变化，实时更新显示

#### 3.3.3 关键方法
1. **调整缩放**
   ```typescript
   handleScaleChange(newScale: number) {
     store.setScale(newScale)
     // 触发重新计算布局和渲染
   }
   ```

2. **调整页面间距**
   ```typescript
   handlePageGapChange(newGap: number) {
     // 需要扩展store，添加setPageGap方法
     // 重新计算所有页面布局
   }
   ```

3. **获取当前页面信息**
   ```typescript
   const currentPageInfo = computed(() => {
     const layout = store.pageLayouts.find(
       p => p.pageNum === store.currentPage
     )
     return layout
   })
   ```

#### 3.3.4 集成位置
在 `PdfViewerView.vue` 中：
- 添加调试面板显示/隐藏的状态
- 添加快捷键监听
- 在工具栏添加调试按钮（可选，或使用快捷键）

## 五、注意事项

### 5.1 性能考虑
- 参数调整时使用防抖，避免频繁更新
- 布局重新计算时，考虑只重新计算可见页面
- 信息显示使用计算属性，避免不必要的计算

### 5.2 开发体验
- 面板默认隐藏，只在开发环境显示
- 可以通过环境变量控制是否启用
- 快捷键只在PDF查看器页面生效

### 5.3 扩展性
- 预留接口，方便后续添加更多调试参数
- 参数分组清晰，便于维护
- 使用Quasar组件，保持UI一致性

## 七、使用说明

### 7.1 打开调试面板
- 快捷键：`Ctrl+Shift+D`（Windows/Linux）或 `Cmd+Shift+D`（Mac）
- 或点击工具栏的调试按钮（如果添加）

### 7.2 调整参数
- 缩放：拖动滑块或输入百分比
- 页面间距：直接输入数值，按回车确认
- 信息：自动更新，无需操作

### 7.3 关闭调试面板
- 再次按快捷键
- 点击面板的关闭按钮
- 点击面板外部区域（可选）
