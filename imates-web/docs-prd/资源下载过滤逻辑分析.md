# 资源下载过滤逻辑分析

## 概述

资源下载的过滤逻辑分为两个层面：
1. **UI层面过滤**：在资源列表界面筛选显示的教材
2. **下载层面过滤**：在下载过程中筛选需要下载的文件


**筛选逻辑**：

1. **未下载（notDownloaded）**：
   - `!textbook.isDownloaded` 或 `textbook.downloadStatus === 0`
   - 表示从未下载或下载状态为未下载

2. **已下载（downloaded）**：
   - `textbook.isDownloaded === true` 且 `textbook.downloadStatus === 2` 且 `!textbook.hasUpdatesAvailable`
   - 表示已完整下载且无更新

3. **待更新（pendingUpdate）**：
   - `textbook.hasUpdatesAvailable === true` 或（`textbook.isDownloaded === true` 且 `textbook.downloadStatus !== 2`）
   - 表示有更新可用或已下载但状态异常

4. **全部（all）**：
   - 不进行额外筛选，显示所有教材

**筛选字段**：
- `textbook.isDownloaded`：是否已下载
- `textbook.downloadStatus`：下载状态（0=未下载，1=下载中，2=下载完成，3=已暂停）
- `textbook.hasUpdatesAvailable`：是否有更新可用

3. 提取本地文件列表（`localFiles`）

- **目的**：兼容旧版本数据库或索引创建失败的情况

```1756:1826:imates-web/src/services/api-service.ts

    let packagesWithResourceList = 0
    let packagesWithoutResourceList = 0
    let packagesWithEmptyResourceList = 0
    
    for (const serverPackage of serverPackages) {
      // 检查包的结构
      const hasResourceList = 'resourceList' in serverPackage
      const resourceListLength = serverPackage.resourceList?.length || 0
      
      if (!hasResourceList) {
        packagesWithoutResourceList++
        console.log('[ApiService.collectFilesToUpdate] 包没有 resourceList 属性', {
          packageId: serverPackage.packageId,
          packageKeys: Object.keys(serverPackage),
        })
      } else if (resourceListLength === 0) {
        packagesWithEmptyResourceList++
        console.log('[ApiService.collectFilesToUpdate] 包的 resourceList 为空', {
          packageId: serverPackage.packageId,
        })
      } else {
        packagesWithResourceList++
      }
      
      if (serverPackage.resourceList && serverPackage.resourceList.length > 0) {
        totalServerFiles += serverPackage.resourceList.length
        
        // 查找对应的本地包
        const localLearningPackage = localLearningPackages.find(p => p.packageId === serverPackage.packageId)
        if (!localLearningPackage) {
          // 新包：下载所有文件
          for (const resource of serverPackage.resourceList) {
            filesToUpdate.push({ resource, pkg: serverPackage })
          }
        } else {
          // 已存在的包：检查文件更新和fileData存在性
          for (const serverFile of serverPackage.resourceList) {
            const localFile = localFileMap.get(serverFile.id)
            
            // 检查文件是否需要下载：
            // 1. localFiles中没有记录（新文件）
            // 2. 校验和不匹配（文件已更新）
            // 3. textbook_files表中不存在实际数据（暂停后继续下载）
            let needsDownload = false
            if (!localFile) {
              needsDownload = true
            } else if (serverFile.checksum !== localFile.checksum) {
              needsDownload = true
            } else {
              // 检查textbook_files表中是否存在文件数据
              // 注意：hasFileData 方法实际上只需要 fileId，但为了保持接口一致性，传入 textbook id
              const textbookId = latestTextbook.id || latestTextbook.textbookId || ''
              if (textbookId) {
                const hasFileData = await resourceManager.hasFileData(textbookId, serverFile.id)
                if (!hasFileData) {
                  needsDownload = true
                }
              } else {
                // 如果连 textbookId 都没有，视为新文件，需要下载
                needsDownload = true
              }
            }
            
            if (needsDownload) {
              filesToUpdate.push({ resource: serverFile, pkg: serverPackage })
            }
          }
        }
      }
    }
```

## 三、过滤逻辑总结

### 3.1 UI层面过滤

| 维度 | 筛选字段 | 匹配方式 | 可选值 |
|------|---------|---------|--------|
| 年级 | `textbookGradeLabel` | 精确匹配 | 全部、高一、高二、高三、初一、初二、初三 |
| 版本 | `textbookPublisher` | 精确匹配 | 全部、人教版、苏教版、北师大版、华师大版 |
| 学科 | `textbookSubjectLabel` | 精确匹配 | 全部、数学、语文、英语、物理、化学、生物、历史、地理、政治 |
| 进度 | `textbookSemesterLabel`<br/>`textbookName` | 模糊匹配 | 根据年级动态生成（初中：上册/下册；高中：必修/选修） |
| 标签页 | `isDownloaded`<br/>`downloadStatus`<br/>`hasUpdatesAvailable` | 组合条件 | 全部、未下载、已下载、待更新 |

**筛选特点**：
- 多维度组合筛选（AND关系）
- 排序规则：学科 → 年级 → 教材名称
- 空值表示不筛选该维度

### 3.2 下载层面过滤

| 场景 | 筛选条件 | 处理方式 |
|------|---------|---------|
| 新包 | 本地不存在对应的包 | 下载包内所有文件 |
| 已存在包 | 新文件 | 下载文件 |
| 已存在包 | 校验和不匹配 | 下载文件（增量更新） |
| 已存在包 | 文件数据不存在 | 下载文件（恢复下载） |

**筛选特点**：
- 增量下载：只下载需要更新的文件
- 校验和比较：通过 `checksum` 判断文件是否更新
- 数据完整性检查：检查 `textbook_files` 表中的实际文件数据
- 性能优化：使用 `Map` 数据结构优化查找性能

## 四、性能优化点

### 4.1 UI层面优化

1. **计算属性缓存**：使用 Vue 的 `computed` 属性，只在依赖数据变化时重新计算
2. **排序稳定性**：使用 `localeCompare` 确保排序结果稳定

### 4.2 下载层面优化

1. **一次性查询**：从 IndexedDB 一次性获取最新教材数据，避免循环中多次查询
2. **Map数据结构**：使用 `Map` 构建文件ID映射，查找时间复杂度 O(1)
3. **三层降级策略**：优先使用索引查询，性能更好
4. **增量下载**：只下载需要更新的文件，减少网络流量

## 五、潜在问题和改进建议

### 5.1 UI层面问题

1. **进度筛选模糊匹配问题**
   - **问题**：使用 `includes` 进行模糊匹配，可能误匹配
   - **示例**：教材名包含"上册"，可能被误匹配为"下册"
   - **建议**：改为精确匹配 `textbookSemesterLabel`，或使用正则表达式

2. **标签页筛选逻辑问题**
   - **问题**：`pendingUpdate` 标签页的筛选条件可能包含已下载但状态异常的情况
   - **建议**：明确区分"有更新"和"状态异常"两种情况

### 5.2 下载层面问题

1. **异步查询性能问题**
   - **问题**：在循环中调用 `hasFileData` 异步方法，可能影响性能
   - **建议**：批量查询文件数据存在性，或使用缓存机制

2. **校验和比较问题**
   - **问题**：如果服务器端校验和计算方式改变，可能导致误判
   - **建议**：添加校验和算法版本标识，或使用更可靠的比较方式

## 七、总结

资源下载的过滤逻辑分为两个层面：

1. **UI层面**：用于在界面上筛选显示的教材，支持多维度组合筛选和排序
2. **下载层面**：用于在下载过程中筛选需要下载的文件，实现增量下载和性能优化

两个层面的过滤逻辑相互独立，UI层面过滤不影响下载逻辑，下载层面过滤只影响实际下载的文件，不影响UI显示。
