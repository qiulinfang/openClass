# 撤销重做功能实现分析

## 一、架构设计

撤销重做功能采用**分页历史记录管理**架构，每个PDF页面独立维护自己的历史记录：

```
PdfViewerView.vue (主视图)
  ├─ 页面组件注册管理 (pageComponents Map)
  ├─ 工具栏状态计算 (toolStates computed)
  ├─ 撤销处理函数 (handleUndo)
  └─ 重做处理函数 (handleRedo)
  
PdfPage.vue (单页组件)
  ├─ 历史记录数组 (history ref)
  ├─ 历史索引 (historyIndex ref)
  ├─ 撤销函数 (undo)
  ├─ 重做函数 (redo)
  ├─ 可撤销状态 (canUndo computed)
  ├─ 可重做状态 (canRedo computed)
  └─ 保存状态函数 (saveState)
```

## 二、核心实现

### 2.1 历史记录管理 (PdfPage.vue)

#### 数据结构
```typescript
// 历史记录数组，存储每个状态的深拷贝
const history = ref<DrawObject[][]>([])

// 当前历史记录索引
const historyIndex = ref(0)

// 最大历史记录数量限制
const maxHistorySize = 50
```

#### 保存状态函数
```typescript
const saveState = () => {
  // 如果当前不在历史记录末尾，删除后面的记录
  if (historyIndex.value < history.value.length - 1) {
    history.value = history.value.slice(0, historyIndex.value + 1)
  }

  // 保存当前状态（深拷贝）
  const currentState = JSON.parse(JSON.stringify(objects.value))
  history.value.push(currentState)
  historyIndex.value = history.value.length - 1

  // 限制历史记录数量
  if (history.value.length > maxHistorySize) {
    history.value.shift()
    historyIndex.value--
  }
}
```

#### 撤销函数
```typescript
const undo = () => {
  if (historyIndex.value <= 0) {
    return false // 无法撤销
  }

  historyIndex.value--
  objects.value = JSON.parse(JSON.stringify(history.value[historyIndex.value]))
  render()
  
  // 保存到Store
  const normalizedObjects = objects.value.map(obj => normalizeCoordinates(obj, store.scale))
  const serializedObjects = IndexedDBService.deepSerialize(normalizedObjects) as object[]
  store.updateAnnotations(props.layout.pageNum, serializedObjects)
  
  return true
}
```

#### 重做函数
```typescript
const redo = () => {
  if (historyIndex.value >= history.value.length - 1) {
    return false // 无法重做
  }

  historyIndex.value++
  objects.value = JSON.parse(JSON.stringify(history.value[historyIndex.value]))
  render()
  
  // 保存到Store
  const normalizedObjects = objects.value.map(obj => normalizeCoordinates(obj, store.scale))
  const serializedObjects = IndexedDBService.deepSerialize(normalizedObjects) as object[]
  store.updateAnnotations(props.layout.pageNum, serializedObjects)
  
  return true
}
```

#### 状态检查
```typescript
// 检查是否可以撤销
const canUndo = computed(() => historyIndex.value > 0)

// 检查是否可以重做
const canRedo = computed(() => historyIndex.value < history.value.length - 1)
```

### 2.2 页面组件注册 (PdfViewerView.vue)

#### 组件注册管理
```typescript
// PDF页面组件引用管理（用于undo/redo）
const pageComponents = ref<
  Map<number, { undo: () => boolean; redo: () => boolean; canUndo: boolean; canRedo: boolean }>
>(new Map())

// 注册页面组件
const registerPageComponent = (
  pageNum: number,
  component: { undo: () => boolean; redo: () => boolean; canUndo: boolean; canRedo: boolean },
) => {
  pageComponents.value.set(pageNum, component)
}

// 注销页面组件
const unregisterPageComponent = (pageNum: number) => {
  pageComponents.value.delete(pageNum)
}

// 提供注册函数给子组件
provide('registerPageComponent', registerPageComponent)
provide('unregisterPageComponent', unregisterPageComponent)
```

#### 页面组件注册 (PdfPage.vue)
```typescript
// 注册到父组件
onMounted(() => {
  if (registerPageComponent) {
    registerPageComponent(props.layout.pageNum, {
      undo,
      redo,
      get canUndo() { return canUndo.value },
      get canRedo() { return canRedo.value }
    })
  }
})

// 注销组件
onUnmounted(() => {
  if (unregisterPageComponent) {
    unregisterPageComponent(props.layout.pageNum)
  }
})
```

### 2.3 工具栏状态计算 (PdfViewerView.vue)

#### 智能页面选择
```typescript
const toolStates = computed(() => {
  const lastModifiedPage = store.lastModifiedPage
  
  // 如果没有最后修改的页面，尝试使用第一个有历史记录的页面
  let targetPage = lastModifiedPage
  if (targetPage === null) {
    // 获取第一个有历史记录的页面
    for (const [pageNum, component] of pageComponents.value.entries()) {
      if (component.canUndo || component.canRedo) {
        targetPage = pageNum
        break
      }
    }
    
    // 如果还是没有，使用第一个页面
    if (targetPage === null && pageComponents.value.size > 0) {
      targetPage = Array.from(pageComponents.value.keys())[0]
    }
  }
  
  if (targetPage === null) {
    return {
      undo: false,
      redo: false,
    }
  }

  const pageComponent = pageComponents.value.get(targetPage)
  if (pageComponent) {
    return {
      undo: pageComponent.canUndo,
      redo: pageComponent.canRedo,
    }
  }

  return {
    undo: false,
    redo: false,
  }
})
```

### 2.4 撤销重做处理 (PdfViewerView.vue)

#### 撤销处理
```typescript
const handleUndo = () => {
  const lastModifiedPage = store.lastModifiedPage
  if (lastModifiedPage === null) {
    console.log('没有可撤销的操作')
    return
  }

  const pageComponent = pageComponents.value.get(lastModifiedPage)
  if (pageComponent && pageComponent.canUndo) {
    const success = pageComponent.undo()
    if (success) {
      console.log(`撤销第 ${lastModifiedPage} 页的操作`)
    }
  } else {
    console.log(`第 ${lastModifiedPage} 页无法撤销`)
  }
}
```

#### 重做处理

```typescript
const handleRedo = () => {

  if (pageComponent && pageComponent.canRedo) {
    const success = pageComponent.redo()

      console.log(`重做第 ${lastModifiedPage} 页的操作`)
    }
  } else {
    console.log(`第 ${lastModifiedPage} 页无法重做`)

```

## 三、工作流程

### 3.1 撤销流程
1. 用户点击撤销按钮
2. `PdfViewerView.vue`调用`handleUndo()`
3. 获取最后修改的页面`lastModifiedPage`
4. 从`pageComponents`中找到对应的页面组件
5. 调用页面组件的`undo()`方法
6. 页面组件更新历史索引，恢复之前的状态
7. 重新渲染画布
8. 更新Store中的批注数据

### 3.2 重做流程
1. 用户点击重做按钮
2. `PdfViewerView.vue`调用`handleRedo()`
3. 获取最后修改的页面`lastModifiedPage`
4. 从`pageComponents`中找到对应的页面组件
5. 调用页面组件的`redo()`方法
6. 页面组件更新历史索引，恢复之后的状态
7. 重新渲染画布
8. 更新Store中的批注数据

### 3.3 状态保存流程
1. 用户进行绘制操作
2. 页面组件调用`saveState()`保存当前状态
3. 状态被深拷贝并添加到历史记录数组
4. 历史索引指向最新状态
5. 如果超过最大历史记录数量，删除最早的状态

## 四、技术特点

### 4.1 优点
- **分页管理**：每个页面独立历史记录，互不干扰
- **深拷贝安全**：使用`JSON.parse(JSON.stringify())`确保状态隔离
- **数量限制**：最大50条历史记录，防止内存溢出
- **智能状态计算**：自动选择有历史记录的页面
- **实时同步**：撤销重做后立即更新Store和界面

### 4.2 限制
- **内存占用**：深拷贝操作可能消耗较多内存
- **性能影响**：大量历史记录可能影响性能
- **状态一致性**：需要确保历史记录与Store数据同步
