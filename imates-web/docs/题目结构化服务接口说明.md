# 题目结构化服务接口说明

该服务利用大模型（DeepSeek-V3）将非结构化的题目文本解析为标准化的题库 JSON 数据。

## 1. 服务信息
- **后端地址**: `http://49.232.39.212:8055`
- **前端代理前缀**: `/structure`
- **模型版本**: 火山引擎 Ark `deepseek-v3-2-251201`
- **支持题型**: 单选题、多选题、判断题、填空题、主观题、复合材料题。

## 2. 接口列表

### 2.1 单道题结构化
- **路径**: `POST /structure_question` (前端调用: `/structure/structure_question`)
- **描述**: 将单题文本解析为结构化数据。
- **请求参数**:
| 参数名 | 类型 | 必选 | 说明 |
| :--- | :--- | :--- | :--- |
| id | string | 是 | 题目唯一标识 |
| subject | string | 是 | 科目 (如 math, physics, english) |
| question | string | 是 | 题目题干原文（包含选项） |
| answer | string | 是 | 题目答案原文 |
| type_hint | string | 否 | 题型建议 (如 single_choice, fill, material) |
| score | number | 否 | 分值 |

- **请求示例**:
```json
{
  "id": "q_test_001",
  "subject": "math",
  "question": "已知二次函数 y=x^2+2x+3，则其图像的对称轴为（ ）。A.x=-1 B.x=1 C.x=-2 D.x=2",
  "answer": "A",
  "type_hint": "single_choice"
}
```

### 2.2 批量题目结构化
- **路径**: `POST /structure_question_batch` (前端调用: `/structure/structure_question_batch`)
- **请求参数**: `{"questions": [StructureQuestionReq]}`

### 2.3 系统接口
- **健康检查**: `GET /health`
- **服务信息**: `GET /service_info` (查看服务配置和可用接口)

## 3. 返回数据结构说明

返回结果统一封装在 `data` 字段中，根据 `type` 不同，结构会有所差异：

### 3.1 选择题 (single_choice/multiple_choice)
包含 `options` 数组，每个选项包含 `label` (A, B, C...) 和 `content`。

### 3.2 填空题 (fill)
包含 `blanks` 数组，对应题目中的填空位。

### 3.3 复合材料题 (material)
包含 `material` (材料内容) 和 `subQuestions` (子题目数组，子题目结构同普通题)。

## 4. 前端调用示例 (TypeScript)

```typescript
import { apiService } from '@/services/http/api-service';

const result = await apiService.structureQuestion({
  id: 'test_001',
  subject: 'math',
  question: '...',
  answer: '...'
});

if (result.success) {
  console.log('结构化数据:', result.data);
}
```
