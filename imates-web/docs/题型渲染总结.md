# 研伴作业系统题型渲染技术文档

本文档总结了研伴 Web 端对不同在线作业题型的渲染策略与实现机制。

## 1. 核心架构概述

系统采用 **“结构化优先 + 白板兜底”** 的原则：
- **结构化渲染**：针对客观题（选择、判断）使用特定的交互组件。
- **白板渲染**：针对主观题（填空、问答、综合）使用 `DrawingBoardNew` 组件，结合 HTML 预览层实现手写交互。

---

## 2. 题型渲染矩阵

| 题型标识 (type) | 对应组件 | 渲染模式 | 作答保存格式 |
| :--- | :--- | :--- | :--- |
| `single_choice` | `ChoiceQuestion.vue` | 交互式选项点击 | 字符串数组 (如 `["A"]`) |
| `multiple_choice`| `ChoiceQuestion.vue` | 交互式选项点击 | 字符串数组 (如 `["A", "B"]`) |
| `true_false` | `JudgmentQuestion.vue`| 交互式 [正确/错误] 按钮 | 字符串 (`"对"` 或 `"错"`) |
| `fill_in_blank` | `FillBlankQuestion.vue`| 题干嵌入输入框 | 字符串数组 |
| `subjective` | `DrawingBoardNew.vue` | 透明白板 + HTML 背景 | 笔迹 JSON + 合成图片 |
| `composite` | `DrawingBoardNew.vue` | 结构化拆解 + 白板手写 | 笔迹 JSON + 合成图片 |

---

## 3. 具体题型渲染详情

### 3.1 选择题 (`single_choice` / `multiple_choice`)
- **组件**：`ChoiceQuestion.vue`
- **渲染逻辑**：解析 `structuredContent.options`。
- **判题映射**：后端 `answer` 字段支持 `"A"` 或 `"A,B"` 格式，前端在展示解析时会自动比对。

### 3.2 判断题 (`true_false`)
- **组件**：`JudgmentQuestion.vue`
- **标识符**：后端使用 `true_false`。
- **展示值**：界面显示“正确”和“错误”按钮。
- **传递值**：用户点击后，`v-model` 传递给后端的始终是 **`"对"`** 或 **`"错"`**。
- **答案格式**：后端 `answer` 为布尔值 (`true`/`false`)。前端通过判定 `"对" === true` 进行校验。

### 3.3 填空题 (`fill_in_blank`)
- **组件**：`FillBlankQuestion.vue`
- **标识符**：后端使用 `fill_in_blank`。
- **渲染方式**：
  1. **交互模式**：解析题干中的 `[blank_1]` 等占位符，动态替换为 `input` 输入框。
  2. **答案匹配**：支持 `blanks` 数组中的多同义词匹配（如 `"32"` 和 `"32.0"`）。

### 3.4 主观解答题 (`subjective`)
- **组件**：`DrawingBoardNew.vue`
- **标识符**：后端使用 `subjective`。
- **渲染策略**：渲染题干文字，下方提供白板区域供学生书写证明过程、作文等。

### 3.5 复合材料题 (`composite`)
- **组件**：`DrawingBoardNew.vue` / 结构化组件
- **标识符**：后端使用 `composite`。
- **数据结构**：包含公共 `material` 区域和 `subQuestions` 子题数组。
- **渲染策略**：
  - **公共材料**：渲染在最上方。
  - **子题迭代**：循环渲染 `subQuestions`，根据每个子题的 `type`（如 `single_choice`, `subjective`）递归调用对应的渲染逻辑。
- **交互方案**：在作业系统中，通常整体作为白板背景，学生直接在题目图片上进行批注。

---

## 4. 关键技术点

### 4.1 数学公式渲染
所有题型（不论是组件渲染还是 HTML 渲染）统一通过 `MathJaxUtils` 进行异步渲染。
- **流程**：内容加载 -> 调用 `renderMessageContent` (Markdown 转 HTML) -> 执行 `MathJax.typeset()`。

### 4.2 作答内容截图 (Capture)
为了在作业列表展示缩略图，系统会在隐藏容器中预渲染题目组件，并利用 `html-to-image` 插件生成 PNG 截图。对于白板题，则直接导出 Canvas 像素数据。

### 4.3 object-fit: contain 适配
在渲染图片背景时，系统会自动计算容器与图片的比例，确保在裁剪或标注时，坐标映射能精确对应到原始图片的像素点。

---

## 5. 开发建议
- **新增题型**：需在 `exercise-utils.ts` 的 `mapBackendTypeToFrontend` 函数中增加映射。
- **修改样式**：全局题目样式定义在 `BaseQuestion.vue` 中，确保所有题型视觉统一。
