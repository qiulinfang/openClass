# 教师解答模块接口文档

教师解答模块允许学生将问题转发给真实的教师，通过 WebSocket 进行实时图文沟通。

## 1. WebSocket 实时通信
- **连接路径**: `/teacher-ws-release/blw-edu-yb/ws`
- **功能**: 
  - 消息实时推送
  - 在线状态同步
  - 会话创建通知
- **消息结构示例 (前端发送)**:
  ```json
  {
    "type": "chat",
    "sessionId": "sess_123",
    "content": "老师，这题我还是不太明白",
    "msgType": "0" 
  }
  ```
- **消息结构示例 (后端推送)**:
  ```json
  {
    "messageId": "msg_999",
    "msgContent": "好的，我们来看一下这部分的定义...",
    "msgType": "0",
    "senderType": "teacher",
    "createTime": "05-14 12:00"
  }
  ```

## 2. 获取教师聊天历史
- **接口路径**: `/yb-teacher-release/blw-edu-yb/api/question/historyList`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "sessionId": "sess_123",
    "page": 1,
    "pageSize": 20
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "data": [
        {
          "messageId": "msg_888",
          "msgContent": "历史消息内容",
          "msgType": "0",
          "senderType": "user",
          "createTime": "05-14 11:30"
        }
      ]
    }
  }
  ```

## 3. 上传图片到研伴系统
- **接口路径**: `/yb-release/blw-edu-yb/api/system/uploadImg`
- **请求方法**: POST (FormData)
- **请求参数**: `file` (File 对象)
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "path": "/img/teacher/2024/05/14/abc.jpg"
    }
  }
  ```
- **说明**: 专门用于向教师发送图片前的文件上传，返回的 `path` 需拼接 Base URL 后使用。
