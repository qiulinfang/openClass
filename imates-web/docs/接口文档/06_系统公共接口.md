# 系统公共接口文档

包含用户鉴权、通用文件上传、系统配置等基础接口。

## 1. 学生登录
- **接口路径**: `/yb-release/blw-edu-yb/auth/login-student`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "username": "student_01",
    "password": "hashed_password"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "token": "auth_token_string",
      "userInfo": {
        "id": "u_001",
        "name": "张三",
        "avatar": "/img/avatar.png"
      }
    }
  }
  ```

## 2. 通用图片上传 (IM 服务器)
- **接口路径**: `/api/images/upload` (Base: IMATES_HTTP)
- **请求方法**: POST (FormData)
- **请求参数**: `file` (File 对象)
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "path": "/uploads/images/20240514/abc.jpg"
    }
  }
  ```
- **功能**: 上传图片并获取完整的可访问 URL，前端通常会将其拼接为 `https://www.imates.com.cn/uploads/...`。

## 3. 题目结构化服务
- **Base URL**: `http://49.232.39.212:8055`
- **接口 1: 单题结构化**
  - **路径**: `/structure_question`
  - **方法**: POST
  - **请求示例**:
    ```json
    {
      "id": "q_001",
      "subject": "math",
      "question": "题干文本...",
      "answer": "A"
    }
    ```
- **接口 2: 批量结构化**
  - **路径**: `/structure_question_batch`
  - **方法**: POST
  - **请求示例**:
    ```json
    {
      "questions": [
        { "id": "q_001", "subject": "math", "question": "...", "answer": "A" },
        { "id": "q_002", "subject": "math", "question": "...", "answer": "B" }
      ]
    }
    ```
- **返回示例 (通用)**:
  ```json
  {
    "success": true,
    "data": {
      "id": "q_001",
      "type": "single_choice",
      "stem": "题干...",
      "options": [
        { "label": "A", "text": "选项A内容" }
      ],
      "answer": "A"
    }
  }
  ```
