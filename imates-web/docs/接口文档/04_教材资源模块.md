# 教材资源模块接口文档

教材资源模块负责教材的在线检索、章节目录加载、学习资源包（HTML/PDF/视频）的获取与下载。

## 1. 获取用户所有在线教材
- **接口路径**: `/yb-release/blw-edu-yb/api/app/teacher-textbook`
- **请求方法**: POST
- **请求示例**:
  ```json
  {}
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "id": "tb_001",
        "textbookId": "T123",
        "textbookName": "初中数学七年级上册",
        "textbookCover": "/img/cover_math.jpg",
        "textbookVersion": "2024-V1",
        "textbookUpdateTime": "2024-05-01 12:00:00"
      }
    ]
  }
  ```

## 2. 获取教材章节目录
- **接口路径**: `/yb-release/blw-edu-yb/api/app/teacher-textbook-section-tree`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "id": "tb_001"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "id": "node_0",
        "label": "根节点",
        "children": [
          {
            "id": "sec_001",
            "label": "第一章 有理数",
            "children": [
              { "id": "sec_001_01", "label": "1.1 正数和负数" }
            ]
          }
        ]
      }
    ]
  }
  ```

## 3. 获取学习资源包
- **接口路径**: `/yb-release/blw-edu-yb/api/app/teacher-textbook-learning-package`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "id": "sec_001_01"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "id": "pkg_456",
        "packageName": "1.1 课件包",
        "resourceList": [
          {
            "id": "file_789",
            "fileName": "正数和负数.pdf",
            "fileType": "pdf",
            "fileUrl": "/resource/path/to/file.pdf",
            "checksum": "abc123hash"
          }
        ]
      }
    ]
  }
  ```

## 4. 提交资源内题目答案
- **接口路径**: `/yb-release/blw-edu-yb/api/app/topic-package-answer`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "id": "pkg_456",
    "answerContent": ["A", "B", "对"]
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "message": "提交成功"
  }
  ```

## 5. 检查教材更新
- **功能**: 前端自动通过比较 `textbookUpdateTime` 和本地存储的 `checksum` 实现。
- **流程**:
  1. 获取服务器端教材版本列表。
  2. 对比本地已下载教材的时间戳。
  3. 若不一致，进一步检查学习包及文件的 `checksum`。
