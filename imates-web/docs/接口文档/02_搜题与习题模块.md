# 搜题与习题模块接口文档

搜题与习题模块负责题目的检索（图片搜题、文本搜题）、错题/习题的管理、相似题查找以及知识点关联。

## 1. 获取习题列表
- **接口路径**: `/xb-release/permission/exercises` (根据学科切换 Endpoint)
- **请求方法**: GET
- **请求示例**: 直接调用
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questionsList": [
        {
          "id": "q_789",
          "bmNo": "BM_001",
          "title": "题目内容...",
          "answer": "B",
          "explanation": "解析内容..."
        }
      ]
    }
  }
  ```

## 2. 添加题目到习题列表
- **接口路径**: `/xb-release/permission/exercises`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "bmNo": "BM_001",
    "type": "math",
    "exercisesId": "",
    "title": "题干内容",
    "answer": "B",
    "explanation": "解析内容",
    "analysisData": "详细分析数据"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "code": 200,
    "message": "添加成功"
  }
  ```

## 3. 删除习题
- **接口路径**: `/xb-release/permission/deleteExercises/{exerciseId}/{subject}`
- **请求方法**: DELETE
- **请求示例**: `/xb-release/permission/deleteExercises/q_789/math`
- **返回示例**:
  ```json
  { "success": true }
  ```

## 4. 图片识别搜题
- **接口路径**: `/xb-release/permission/img` (生物) 或 `/xb-release/permission/imgMath` (数学)
- **请求方法**: POST (FormData)
- **参数**: `imgFile` (File/Blob)
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "item": {
        "questionsConfirm": [
          {
            "id": "q_789",
            "bmNo": "BM_001",
            "title": "识别出的题目内容",
            "answer": "A",
            "explanation": "解析..."
          }
        ]
      }
    }
  }
  ```

## 5. 文本搜题
- **接口路径**: `/xb-release/permission/textSearch/{query}`
- **请求方法**: GET
- **请求示例**: `/xb-release/permission/textSearch/二次函数`
- **返回示例**: 同“图片识别搜题”返回结构。

## 6. 查找相似题目
- **接口路径**: `/xb-release/permission/topicAndAck`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "bmNo": "BM_001",
    "title": "题干内容",
    "type": "math"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questions": [
        { "id": "q_790", "title": "相似题目1...", "answer": "C" }
      ]
    }
  }
  ```

## 7. 根据章节查询知识点
- **接口路径**: `/knowledge` (Base: KNOWLEDGE_API)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "subject": "math",
    "param": [
      { "textbook_id": "tb_001", "section_id": "sec_002" }
    ]
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "knowledge": "KN_001,KN_002",
    "count": 2
  }
  ```

## 8. 根据知识点查找题目
- **接口路径**: `/xb-release/biologyTopicKnowledge/knowledgeTopicAndAck`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "knowledgeNo": "KN_001",
    "current": 1,
    "size": 5
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "totalCount": "10",
    "data": {
      "questions": [...]
    }
  }
  ```
