# 研伴答疑模块接口调用手册 (学生端 & 教师端)

本文档详细说明了研伴系统中答疑模块的完整通讯逻辑，涵盖学生提问、教师回复、实时通知及会话管理。

---

### 1.2 通用规范
*   **认证**: 所有 HTTP 请求需在 Header 携带 `token`。
*   **消息类型 (`msgType`)**: `0`-文本, `1`-图片, `2`-语音。
*   **实时性**: 基于 WebSocket 的双向实时推送。

## 2. 学生端 (Student) 接口逻辑

### 2.1 [WS] 发送提问消息
学生建立 WS 连接后，直接发送 JSON 字符串发起提问。
*   **消息类型**: `STUDENT_QUESTION`
*   **格式**:
    ```json
    {
      "type": "STUDENT_QUESTION",
      "userId": "学生账号",
      "sessionId": "会话ID (由前端生成UUID或由后端返回)",
      "content": "老师，这道题怎么做？",
      "msgType": "0",
      "subject": "1" // 科目ID
    }
    ```

### 2.2 [WS] 接收老师回复
学生需监听 WebSocket 的 `TEACHER_RESPONSE` 类型消息。
*   **收到格式**:
    ```json
    {
      "type": "TEACHER_RESPONSE",
      "data": {
        "sessionId": "xxx",
        "content": "老师的解答内容...",
        "timestamp": 1714286569000
      }
    }
    ```

### 2.3 [HTTP] 获取历史记录 (historyList)
*   **URL**: `[学生端路径前缀]/api/question/historyList`
*   **参数**: `{"sessionId": "xxx", "page": 1, "pageSize": 50}`

## 3. 教师端 (Teacher) 接口逻辑

### 3.1 [HTTP] 获取会话列表 (sessionList)
*   **URL**: `[教师端路径前缀]/api/question/sessionList`
*   **参数**: `{"teacherId": "xxx", "page": 1, "pageSize": 50}`
*   **说明**: 返回 `data.records` 列表。`hasUnRead` 为 `true` 时前端显示红点。

### 3.2 [HTTP] 教师回复消息 (replyMessage)
*   **URL**: `[教师端路径前缀]/api/question/replyMessage`
*   **参数**: 
    ```json
    {
      "sessionId": "xxx",
      "teacherId": "yyy",
      "msgType": "0",
      "msgContent": "解答内容"
    }
    ```

### 3.3 [HTTP] 标记已读 (readMessage)
*   **URL**: `[教师端路径前缀]/api/question/readMessage`
*   **场景**: 教师点击进入具体学生会话时调用。

### 3.4 [WS] 教师端监听事件

#### 3.4.1 收到新提问通知 (`TYPE_NEW_QUESTION`)
当负责的学生有新消息时，教师端 WS 会收到推送：
```json
{
  "type": "TYPE_NEW_QUESTION",
  "data": {
    "payload": {
      "sessionId": "xxx",
      "content": "提问内容...",
      "timestamp": 1714286569000
    }
  }
}
```
