# 作业模块接口文档

作业模块主要处理学生作业的列表获取、详情查询、答案提交以及 AI 辅助判题等功能。

## 1. 获取未完成作业列表
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-undo-list`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "pageNumber": 0,
    "pageSize": 20,
    "subject": "math",
    "date": "2024-05-14"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "id": "hw_123",
        "title": "初中数学一次函数练习",
        "subject": "数学",
        "totalScore": "100",
        "releaseTime": "2024-05-14 10:00:00",
        "deadline": "2024-05-20 23:59:59",
        "resubmit": "1",
        "status": "1"
      }
    ]
  }
  ```

## 2. 获取作业详情（题目列表）
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-detail-list`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "id": "hw_123"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "questionId": "q_001",
        "questionContent": "<p>已知函数 f(x) = 2x + 1...</p>",
        "questionAnswer": "A",
        "questionAnalysis": "解析内容...",
        "questionStructureData": "{\"type\":\"single_choice\",\"options\":[...]}"
      }
    ]
  }
  ```

## 3. 提交作业答案
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-submit-save`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "homeworkId": "hw_123",
    "questionAnswerList": [
      {
        "questionId": "q_001",
        "answerList": ["https://www.imates.com.cn/img/user_answer_1.jpg"],
        "chooseList": ["A"]
      }
    ]
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": { "success": true },
    "message": "提交成功"
  }
  ```

## 4. 高考AI接口 - 题型识别
- **接口路径**: `/v1/question/type` (Base: GAOKAO_AGENT_LLM)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "question": "题干内容...",
    "answer": "标准答案",
    "analysis": "解析内容"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questionType": "single_choice"
    }
  }
  ```

## 5. 高考AI接口 - 选择题拆分
- **接口路径**: `/v1/question/choice/parse` (Base: GAOKAO_AGENT_LLM)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "question": "1. 题目 A.选项1 B.选项2...",
    "answer": "A"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questionType": "single_choice",
      "questionContent": "1. 题目",
      "options": [
        { "optionId": "A", "optionContent": "选项1" },
        { "optionId": "B", "optionContent": "选项2" }
      ]
    }
  }
  ```

## 6. 手写公式识别
- **接口路径**: `/api/recognize-handwritten-formula-image/json` (Base: HW_FORMULA_RECOGNIZE)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "file": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8/5+hEgAHggJ/PchI7wAAAABJRU5ErkJggg==",
    "filename": "formula.png"
  }
  ```
- **返回示例**:
  ```json
  {
    "latex": "x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}",
    "candidates": ["x = ...", "x = ..."],
    "formula_count": 1,
    "message": "识别成功"
  }
  ```

# 附录：题目结构化数据定义 (questionStructureData)

作业详情接口中的 `questionStructureData` 字段应遵循以下 JSON 结构规范。

## 1. 单项与多项选择题
适用于所有学科的选择题。

### 单项选择题
```json
{
  "id": "q_1001",
  "subject": "math", 
  "score": 5,
  "type": "single_choice",
  "stem": "下列关于细胞膜的叙述，正确的是（ ）。",
  "options": [
    { "id": "A", "content": "主要由脂质和蛋白质组成" },
    { "id": "B", "content": "具有完全的通透性" },
    { "id": "C", "content": "参与细胞间的信息交流" },
    { "id": "D", "content": "其结构特点是具有选择透过性" }
  ],
  "answer": ["A"],
  "analysis": "根据二次函数对称轴公式 $x = -\\frac{b}{2a}$，代入可得 $x = -1$。"
}
```

### 多项选择题
```json
{
  "id": "q_1002",
  "subject": "math", 
  "score": 5,
  "type": "multiple_choice",
  "stem": "下列关于细胞膜的叙述，正确的是（ ）。",
  "options": [
    { "id": "A", "content": "主要由脂质和蛋白质组成" },
    { "id": "B", "content": "具有完全的通透性" },
    { "id": "C", "content": "参与细胞间的信息交流" },
    { "id": "D", "content": "其结构特点是具有选择透过性" }
  ],
  "answer": ["A", "C"]
}
```

## 2. 判断题
```json
{
  "id": "q_1003",
  "subject": "math", 
  "score": 5,
  "type": "true_false",
  "stem": "无论在任何惯性参考系中，真空中的光速都是不变的。",
  "answer": true
}
```

## 3. 填空题
适用于数学、物理的计算结果填空，语文的古诗词默写，英语的单词拼写等。核心在于支持多个空，并处理每个空可能存在多个同义正确答案（如化学方程式的等价写法）。

```json
{
  "id": "q_1004",
  "subject": "math", 
  "score": 5,
  "type": "fill_in_blank",
  "stem": "在标况下，$22.4L$ 的 $O_2$ 所含的分子数约为 [blank_1]；其质量为 [blank_2] 克。",
  "blanks": [
    {
      "id": "blank_1",
      "answers": ["$6.02 \\times 10^{23}$", "$N_A$"]
    },
    {
      "id": "blank_2",
      "answers": ["32", "32.0"]
    }
  ]
}
```

## 4. 主观解答题
适用于语文作文、数学证明、理综大题、文综论述。这类题目通常只需渲染题干和解析，并在界面上留出作答区域（或上传图片的入口）。如果题目分多个小问，推荐使用嵌套结构。

```json
{
  "id": "q_1005",
  "subject": "math", 
  "score": 5,
  "type": "subjective",
  "stem": "阅读下列材料，简述辛亥革命的历史意义。",
  "answer": "推翻了清朝统治，结束了中国两千多年的封建君主专制制度，建立了亚洲第一个资产阶级民主共和国。"
}
```

## 5. 复合材料题
适用于英语的阅读理解、完形填空，语文的现代文阅读，以及文科综合的大型材料题。结构特征是“一个公共材料区域 + 多个不同类型的子题目”。

```json
{
  "id": "q_1006",
  "subject": "math", 
  "score": 5,
  "type": "composite",
  "material": "Here is a long passage about global warming... (公共阅读文本或图表)",
  "subQuestions": [
    {
      "id": "cq_1",
      "type": "single_choice",
      "stem": "What is the main idea of paragraph 1?",
      "options": [
        { "id": "A", "content": "The definition of global warming." },
        { "id": "B", "content": "The causes of climate change." }
      ],
      "answer": "A"
    },
    {
      "id": "cq_2",
      "type": "subjective",
      "stem": "Translate the underlined sentence into Chinese.",
      "answer": "这是文章中划线句子的中文翻译。"
    }
  ]
}
