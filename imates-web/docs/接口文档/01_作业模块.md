# 作业模块接口文档

作业模块主要处理学生作业的列表获取、详情查询、答案提交以及 AI 辅助判题等功能。

## 1. 获取未完成作业列表
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-undo-list`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "pageNumber": 0,
    "pageSize": 20,
    "subject": "math",
    "date": "2024-05-14"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "id": "hw_123",
        "title": "初中数学一次函数练习",
        "subject": "数学",
        "totalScore": "100",
        "releaseTime": "2024-05-14 10:00:00",
        "deadline": "2024-05-20 23:59:59",
        "resubmit": "1",
        "status": "1"
      }
    ]
  }
  ```

## 2. 获取作业详情（题目列表）
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-detail-list`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "id": "hw_123"
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": [
      {
        "questionId": "q_001",
        "questionContent": "<p>已知函数 f(x) = 2x + 1...</p>",
        "questionAnswer": "A",
        "questionAnalysis": "解析内容...",
        "questionStructureData": "{\"type\":\"single_choice\",\"options\":[...]}"
      }
    ]
  }
  ```

## 3. 提交作业答案
- **接口路径**: `/yb-release/blw-edu-yb/api/app/homework-submit-save`
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "homeworkId": "hw_123",
    "questionAnswerList": [
      {
        "questionId": "q_001",
        "answerList": ["https://www.imates.com.cn/img/user_answer_1.jpg"],
        "chooseList": ["A"]
      }
    ]
  }
  ```
- **返回示例**:
  ```json
  {
    "code": 200,
    "success": true,
    "data": { "success": true },
    "message": "提交成功"
  }
  ```

## 4. 高考AI接口 - 题型识别
- **接口路径**: `/v1/question/type` (Base: GAOKAO_AGENT_LLM)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "question": "题干内容...",
    "answer": "标准答案",
    "analysis": "解析内容"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questionType": "single_choice"
    }
  }
  ```

## 5. 高考AI接口 - 选择题拆分
- **接口路径**: `/v1/question/choice/parse` (Base: GAOKAO_AGENT_LLM)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "question": "1. 题目 A.选项1 B.选项2...",
    "answer": "A"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "data": {
      "questionType": "single_choice",
      "questionContent": "1. 题目",
      "options": [
        { "optionId": "A", "optionContent": "选项1" },
        { "optionId": "B", "optionContent": "选项2" }
      ]
    }
  }
  ```

## 6. 手写公式识别
- **接口路径**: `/api/recognize-handwritten-formula-image/json` (Base: HW_FORMULA_RECOGNIZE)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "file": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8/5+hEgAHggJ/PchI7wAAAABJRU5ErkJggg==",
    "filename": "formula.png"
  }
  ```
- **返回示例**:
  ```json
  {
    "latex": "x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}",
    "candidates": ["x = ...", "x = ..."],
    "formula_count": 1,
    "message": "识别成功"
  }
  ```
