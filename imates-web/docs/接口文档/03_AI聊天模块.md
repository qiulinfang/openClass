# AI 聊天模块接口文档

AI 聊天模块提供了学生与学伴（AI）之间的对话能力，支持文字、图片输入，并具备上下文记忆管理功能。

## 1. 发送聊天消息
- **接口路径**: `/xb-release/ai/2.0/chat` (通用) 或 `/xb-release/ai/2.0/chatMath` (数学/公式)
- **请求方法**: POST
- **请求示例**:
  ```json
  {
    "sessionId": "session_456",
    "newValue": "这道题怎么做？",
    "coversation": "你好",
    "question": "题干内容...",
    "answer": "标准答案",
    "role": "user",
    "subject": "math",
    "category": "ai-general",
    "dstUrl": "https://www.imates.com.cn/xb-release/ai/2.0/chat",
    "imageList": [
      { "base64DataUrl": "data:image/png;base64,..." }
    ]
  }
  ```
- **返回示例 (流式轮询模式)**:
  后端会多次返回包含新内容的帧。
  ```json
  {
    "success": true,
    "message": "AI 返回的内容片段...",
    "data": {
      "sessionId": "session_456"
    }
  }
  ```
  最后一帧通常返回 `"message": "end"`。

## 2. 管理对话记忆
- **接口路径**: `/history_manage` (Base: HISTORY_MANAGE)
- **请求方法**: POST
- **请求示例 (删除消息)**:
  ```json
  {
    "command": "delete_messages",
    "thread_id": "session_456",
    "message_id": "msg_789",
    "agent_name": "solvingbot"
  }
  ```
- **请求示例 (清空会话)**:
  ```json
  {
    "command": "delete_thread",
    "thread_id": "session_456",
    "agent_name": "chatbot"
  }
  ```
- **返回示例**:
  ```json
  {
    "success": true,
    "message": "Operation successful"
  }
  ```
