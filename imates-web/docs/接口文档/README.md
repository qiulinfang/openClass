# 接口文档说明

本文件夹汇总了研伴学生端 WebView 应用的所有核心 API 接口，按功能模块划分为以下几个部分：

## 模块导览

1.  **[01_作业模块](./01_作业模块.md)**: 作业列表、详情、答案提交及高考AI判题接口。
2.  **[02_搜题与习题模块](./02_搜题与习题模块.md)**: 搜题识别、习题收藏管理、知识点查询及相似题检索。
3.  **[03_AI聊天模块](./03_AI聊天模块.md)**: 与学伴 AI 对话、历史记忆管理等。
4.  **[04_教材资源模块](./04_教材资源模块.md)**: 教材目录、资源包下载、教材更新检查等。
5.  **[05_教师解答模块](./05_教师解答模块.md)**: 教师在线答疑 WebSocket 通信及历史记录。
6.  **[06_系统公共接口](./06_系统公共接口.md)**: 登录鉴权、通用图片上传、题目结构化服务。

## 基础配置
- **Base URL**: 动态获取，详见 `src/config/env-config.ts`。
- **环境切换**: 支持 RELEASE (正式) 和 INTERNAL_TEST (内测) 环境。
- **认证方式**: 大多数接口需要在 Header 中携带 `x-auth-token`。
