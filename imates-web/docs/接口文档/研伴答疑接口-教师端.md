# 研伴答疑模块 - 教师端接口调用手册

本文档详细说明了研伴系统中教师端（Teacher）的会话管理与实时通讯逻辑。

## 1. 基础信息

### 1.1 完整请求路径预览

#### 生产环境 (RELEASE)
- **路径前缀**: `/yb-teacher-release/blw-edu-yb`
- 基础 URL: `http://www.imates.com.cn/yb-teacher-release/blw-edu-yb`
- WebSocket 地址: `wss://www.imates.com.cn/teacher-ws-release/blw-edu-yb/ws`
- 会话列表接口: `http://www.imates.com.cn/yb-teacher-release/blw-edu-yb/api/question/sessionList`
- 回复消息接口: `http://www.imates.com.cn/yb-teacher-release/blw-edu-yb/api/question/replyMessage`
- 历史记录接口: `http://www.imates.com.cn/yb-teacher-release/blw-edu-yb/api/question/historyList`
- 标记已读接口: `http://www.imates.com.cn/yb-teacher-release/blw-edu-yb/api/question/readMessage`

#### 测试环境 (INTERNAL)
- **路径前缀**: `/yb-teacher-test/yb-teacher`

## 2. 业务接口 (HTTP)

### 2.1 获取学生会话列表
获取该教师负责的所有学生咨询会话。
- **接口**: `POST [路径前缀]/api/question/sessionList`
- **请求载荷**:
```json
{
  "teacherId": "教师ID",
  "page": 1,
  "pageSize": 50
}
```
- **响应格式**:
```json
{
  "code": 200,
  "success": true,
  "message": "成功",
  "data": {
    "records": [
      {
        "id": "会话ID",
        "studentId": "学生ID",
        "studentName": "学生姓名",
        "studentAvatar": null,
        "msgType": "0",
        "msgContent": "最新消息内容",
        "msgTime": "04-28 14:53",
        "hasUnRead": false
      }
    ],
    "pageNumber": 1,
    "pageSize": 50,
    "totalPage": 1,
    "totalRow": 22
  }
}
```

### 2.2 教师回复消息
教师通过 HTTP 接口回复学生。
- **接口**: `POST [路径前缀]/api/question/replyMessage`
- **格式**:
```json
{
  "sessionId": "会话ID",
  "teacherId": "教师ID",
  "msgType": "0", // 0-文本, 1-图片
  "msgContent": "解答的具体内容"
}
```
- **响应格式**:
```json
{
  "code": 200,
  "success": true,
  "message": "成功",
  "data": true
}
```

### 2.3 获取历史记录
用于拉取指定会话的历史对话内容。
- **接口**: `POST [路径前缀]/api/question/historyList`
- **参数**: `{"sessionId": "xxx", "page": 1, "pageSize": 50}`
- **响应格式**:
```json
{
    "code": 200,
    "success": true,
    "message": "成功",
    "data": [
        {
            "id": "消息流水ID",
            "sessionId": "会话ID",
            "senderType": "ai | user | teacher",
            "msgSendId": "发送者ID",
            "msgType": "0",
            "msgContent": "消息内容",
            "msgReadFlag": "1", // 0-未读, 1-已读
            "msgReadTime": "2026-04-28 16:19:24",
            "createTime": "04-17 14:00",
            "msgSendName": "发送者姓名",
            "msgSendAvatar": "头像URL",
            "account": "账号名"
        }
    ]
}
```

### 2.4 标记已读
- **接口**: `POST [路径前缀]/api/question/readMessage`
- **场景**: 教师点击进入具体学生聊天窗口时调用，清除未读标记。
- **请求载荷**:
```json
{
  "sessionId": "会话ID",
  "teacherId": "教师ID"
}
```
- **响应格式**:
```json
{
  "code": 200,
  "success": true,
  "message": "成功",
  "data": true
}
```

## 3. 实时通知 (WebSocket)

教师建立 WS 连接后，URL 需带上教师账号：`[WebSocket地址]?userId={teacherId}`

### 3.1 收到新提问通知
当负责的学生发送消息时，后端会向教师端推送此事件。
- **类型**: `TYPE_NEW_QUESTION`
- **收到格式**:
```json
{
    "type": "TYPE_NEW_QUESTION",
    "data": {
        "notice": "有新的问题,请尽快回复",
        "payload": {
            "sessionId": "会话ID",
            "messageId": "消息唯一ID",
            "clientMessageId": "客户端生成的临时ID",
            "senderType": "STUDENT",
            "msgType": "0", // 0-文本, 1-图片, 2-语音
            "content": "消息内容",
            "timestamp": 1777364523203
        }
    }
}
```
