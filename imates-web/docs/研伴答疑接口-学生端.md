# 研伴答疑模块 - 学生端接口调用手册

本文档详细说明了研伴系统中学生端（Student）的答疑通讯逻辑。

## 1. 基础信息

### 1.1 完整请求路径预览

#### 生产环境 (RELEASE)
- **路径前缀**: `/yb-release/blw-edu-yb`
- 基础 URL: `http://www.imates.com.cn/yb-release/blw-edu-yb`
- WebSocket 地址: `wss://www.imates.com.cn/yb-release/blw-edu-yb/ws`
- 历史记录接口: `http://www.imates.com.cn/yb-release/blw-edu-yb/api/question/historyList`

#### 测试环境 (INTERNAL)
- **路径前缀**: `/yb-test/blw-edu-yb`
- 基础 URL: `https://www.imates.com.cn/yb-test/blw-edu-yb`
- WebSocket 地址: `wss://www.imates.com.cn/yb-test/blw-edu-yb/ws`
- 历史记录接口: `https://www.imates.com.cn/yb-test/blw-edu-yb/api/question/historyList`

### 1.2 通用规范
- **认证**: 请求 Header 需携带 `token`。
- **消息类型 (`msgType`)**: `0`-文本, `1`-图片, `2`-语音。

---

## 2. 实时通讯 (WebSocket)

学生端建立 WS 连接后，URL 需带上用户账号：`[WebSocket地址]?userId={account}`

### 2.1 发送提问消息
直接向 WebSocket 发送以下格式的 JSON 字符串。
- **类型**: `STUDENT_QUESTION`
- **格式**:
```json
{
  "type": "STUDENT_QUESTION",
  "userId": "学生账号",
  "sessionId": "会话ID (由前端生成UUID或历史会话ID)",
  "content": "老师，这道题怎么做？",
  "msgType": "0",
  "subject": "1" // 科目ID
}
```

### 2.2 接收老师回复
需持续监听 WebSocket 消息，捕获类型为 `TEACHER_RESPONSE` 的下行数据。
- **收到格式**:
```json
{
  "type": "TEACHER_RESPONSE",
  "data": {
    "sessionId": "会话ID",
    "content": "老师的解答内容...",
    "timestamp": 1714286569000
  }
}
```

---

## 3. 业务接口 (HTTP)

### 3.1 获取历史聊天记录
用于加载或翻页查看之前的对话。
- **接口**: `POST [路径前缀]/api/question/historyList`
- **请求载荷**:
```json
{
  "sessionId": "会话ID",
  "page": 1,
  "pageSize": 50
}
```
- **返回数据**: `data.data` (消息列表数组)
