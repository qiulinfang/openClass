# 题目结构化服务接口文档

## 1. 概述
题目结构化服务是一个独立的 AI 算法服务，旨在将非结构化的题目原文（题干、答案等）解析为机器可识别的结构化数据（如题干、选项列表、填空位等），以便前端进行精细化渲染。

## 2. 基础信息
- **服务名称**: Question Structurer Service
- **基础 URL**: 通过 `getQuestionStructurerBaseUrl()` 获取
- **请求格式**: `Content-Type: application/json`
- **响应格式**: `ApiResponse<T>` (统一响应格式)

## 3. 接口列表

### 3.1 单道题结构化
将单道题目的原文进行结构化解析。

- **URL**: `/structure_question`
- **Method**: `POST`
- **请求参数 (`StructureQuestionReq`)**:

| 参数名 | 类型 | 必选 | 说明 |
| :--- | :--- | :--- | :--- |
| id | string | 是 | 题目唯一标识 |
| subject | string | 是 | 科目（如 math, physics 等） |
| question | string | 是 | 题目题干原文 |
| answer | string | 是 | 题目答案原文 |
| score | number | 否 | 题目分值 |
| type_hint | string | 否 | 题目类型提示（如 choice, fill, judgment 等） |

- **示例响应**:
```json
{
  "success": true,
  "data": {
    "id": "q123",
    "type": "choice",
    "structuredContent": {
      "stem": "已知 $x+y=5$，求 $x^2+y^2$ 的值。",
      "options": [
        { "label": "A", "text": "10" },
        { "label": "B", "text": "15" }
      ]
    }
  }
}
```

### 3.2 批量题目结构化
一次性结构化解析多道题目。

- **URL**: `/structure_question_batch`
- **Method**: `POST`
- **请求参数 (`StructureQuestionBatchReq`)**:

| 参数名 | 类型 | 必选 | 说明 |
| :--- | :--- | :--- | :--- |
| questions | array | 是 | `StructureQuestionReq` 对象的列表 |

### 3.3 健康检查
检查服务是否在线。

- **URL**: `/health`
- **Method**: `GET`

### 3.4 获取服务信息
查看服务配置和可用接口列表。

- **URL**: `/service_info`
- **Method**: `GET`

## 4. 前端调用示例

```typescript
import { apiService } from '@/services/http/api-service'

const res = await apiService.structureQuestion({
  id: "test_01",
  subject: "math",
  question: "这是一道选择题原文...",
  answer: "A"
});

if (res.success) {
  const structuredData = res.data;
  // 处理返回的结构化数据
}
```

## 5. 数据结构定义 (`ExerciseItem`)
结构化后的结果通常存储在 `ExerciseItem` 的 `structuredContent` 字段中：

```typescript
interface StructuredContent {
  stem: string;         // 结构化题干
  options?: Array<{     // 选项（仅限选择题）
    label: string;
    text: string;
  }>;
  blanks?: string[];    // 填空位（仅限填空题）
}
```
