# 教材资源与下载

## 1. 业务逻辑
- **全量在线检索**: 学生可查看全国范围内的数字化教材版本。
- **三级下载体系**: 
  1.  **教材级**: 书本基本信息（封面、名称）。
  2.  **包级 (Learning Package)**: 教材章节关联的学习资源包。
  3.  **文件级**: 具体的 HTML 课件、PDF、音视频。
- **增量更新**: 当老师或系统更新了课件内容时，前端能通过版本对比实现“只下载变更文件”，节省流量。
- **离线查阅**: 所有的 HTML 课件和 PDF 下载后均可离线查阅，保证学习不中断。

## 2. 技术实现

### 2.1 增量对账算法
- **标识符**: 使用 `checksum` (MD5/Hash) 判断文件是否有变动，而非仅依赖文件名或日期。
- **流程**: 
  1.  请求最新清单。
  2.  遍历清单中的文件 ID，与本地 IndexedDB 中的 `ResourceStore` 进行匹配。
  3.  找出 `checksum` 不一致或本地缺失的文件。
  4.  后台并发执行下载。

### 2.2 离线存储体系 (`ResourceManager`)
- **IndexedDB 存储**: 
  *   `textbooks`: 存储教材的元数据及层级树。
  *   `textbook_files`: 以 Blob/Uint8Array 格式存储海量的课件二进制数据。
- **访问控制**: 通过 `AndroidBridge` 处理文件路径映射，确保 WebView 能直接通过 `file://` 或特定的 DataURL 访问已下载资源。

### 2.3 下载管理器
- **并发控制**: 限制同时进行的下载任务数（通常为 6），防止撑爆浏览器线程。
- **可中断机制**: 使用 `AbortController` 实现下载的实时暂停与取消。
- **完整性校验**: 下载完成后，再次计算本地文件的 `checksum` 与服务端对比。
