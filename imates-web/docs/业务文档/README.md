# 业务与技术文档说明

本文件夹旨在详细阐述研伴学生端 WebView 应用的核心业务逻辑与技术实现方案，帮助开发者理解各模块的运行机制。

## 目录索引

1.  **[00_项目概览](./00_项目概览.md)**: 项目定位、核心价值与整体功能地图。
2.  **[01_作业与作答模块](./01_作业与作答模块.md)**: 业务流转（发布-作答-提交-解析）及白板/截图技术实现。
3.  **[02_错题本模块](./02_错题本模块.md)**: 错题收集、原卷复现、对比学习及“再练习”闭环逻辑。
4.  **[03_AI学伴聊天模块](./03_AI学伴聊天模块.md)**: 多模式 AI 引导逻辑、流式轮询技术及对话上下文管理。
5.  **[04_教材资源与下载](./04_教材资源与下载.md)**: 离线化资源管理、增量更新逻辑及 IndexedDB 存储方案。
6.  **[05_教师在线答疑](./05_教师在线答疑.md)**: 师生实时图文交互、WebSocket 服务及会话状态同步。
7.  **[06_技术架构说明](./06_技术架构说明.md)**: 技术栈选型、核心设计模式（策略模式等）与 Android 桥接机制。
8.  **[07_项目架构全景](./07_项目架构全景.md)**: 整个项目的宏观技术架构、分层设计及核心运行机制。
