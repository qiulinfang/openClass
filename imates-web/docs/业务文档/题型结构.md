options的content需要结合题干适配一下，不能写死

1. 语义提取优先规则
AI 必须优先扫描 stem（题干）中括号内的提示。
规则： 如果题干包含 (填“X”或“Y”) 或 判断...是否...，则 options.content 必须直接取自这些关键词。
示例： 题干有“填‘是’或‘不是’”，则 content 必为 ["是", "不是"]。
2. 学科语境对仗规则
若题干无显式提示，则根据 subject 字段和关键词选择最贴切的对仗词组：
场景 / 关键词id: "true" (content)id: "false" (content)适用学科
命题/结论性描述 正确 错误 物理、化学、生物、地理 
逻辑命题/定理 真 假 数学 
定义/归属判断 是 不是 全学科 (尤其是概念辨析) 
操作/规范判断 符合 不符合 化学实验、通用技术 
变化趋势判断 增大 / 升高 减小 / 降低 物理、化学、生物 
存在性判断 存在 不存在 数学、物理 
法律/原则判断 合理 / 合法 不合理 / 违法 政治、历史 
口语/基础校验 对 错 英语、语文、通用 



填空题（题型4）
适用于数学、物理的计算结果填空，语文的古诗词默写，英语的单词拼写等。核心在于支持多个空，并处理每个空可能存在多个同义正确答案（如化学方程式的等价写法）。

适用于语文作文、数学证明、理综大题、文综论述。这类题目通常只需渲染题干和解析，并在界面上留出作答区域（或上传图片的入口）。如果题目分多个小问，推荐使用嵌套结构。

复合材料题（题型6）
这是最复杂的结构，适用于英语的阅读理解、完形填空，语文的现代文阅读，以及文科综合的大型材料题。结构特征是“一个公共材料区域 + 多个不同类型的子题目”。
