# 技术架构说明

## 1. 核心技术栈
- **框架**: Vue 3 (Composition API)
- **工程化**: Vite
- **状态管理**: Pinia (持久化配合插件)
- **UI 组件库**: Quasar Framework (核心) + TailwindCSS (辅助布局)
- **本地存储**: IndexedDB (存储大型资源/离线数据)
- **渲染引擎**: MathJax (数学公式渲染)
- **通信**: Axios (HTTP) + WebSocket (实时)

## 2. 核心架构设计

### 2.1 Android-Web 桥接层 (`AndroidBridge`)
- **定位**: 项目运行在原生 WebView 中，桥接层负责屏蔽环境差异。
- **功能**: 调用原生拍照、获取课堂状态、控制原生悬浮球显示/隐藏、路径转换。
- **健壮性**: 在 Web 浏览器测试环境下，提供完善的 Mock 数据兜底。

### 2.2 策略模式的应用 (`QuestionList Strategy`)
- **场景**: 题目列表在“我的习题”、“我的作业”、“错题本”三个场景下高度相似但操作逻辑不同（如删除权限、置顶规则）。
- **实现**: 
  1.  定义 `QuestionListStrategy` 接口。
  2.  实现 `ExerciseStrategy`, `HomeworkStrategy`, `MistakeStrategy` 三个类。
  3.  通过工厂方法动态注入，实现 UI 的高度解耦与复用。

### 2.3 异常处理与监控
- **全局拦截**: Axios 响应拦截器统一处理 401 (登录过期) 和服务端 500。
- **埋点日志**: 系统日志通过桥接层回传给 Android 原生 Logcat，方便在生产环境调试。

### 2.4 性能优化方案
- **Virtual List**: 针对数百道题目的列表，采用虚拟滚动渲染。
- **Lazy Loading**: 路由组件懒加载 + MathJax 公式按需渲染。
- **Worker 线程**: 大型资源的 `checksum` 计算考虑放在 Web Worker 中进行（规划中）。
