# 项目概览

## 1. 业务定位
研伴学生端 WebView 应用是一款专为 Android 平板/移动端设计的辅助学习工具。它作为原生 App 的深度集成部分，主要负责提供**沉浸式的题目作答、AI 智能辅导、数字化教材查阅及师生互动**体验。

## 2. 核心业务价值
- **数字化作业**: 摆脱纸质作业，支持手写、选择、判断等多种交互形式，实现即时提交与自动批改。
- **AI 赋能**: 通过“学伴”角色，为学生提供针对性的启发式引导，而非直接给答案。
- **闭环学习**: 构建“练习-错题收集-再练习”的科学复习路径。
- **离线能力**: 教材资源及作答进度支持离线缓存，保障在弱网环境下的连续使用。

## 3. 功能地图 (Module Map)
- **作答系统**: 交互式题目（选择/判断）、白板手写系统（填空/问答）。
- **辅导系统**: AI 聊天面板、历史会话管理、高考 AI 题型分析。
- **复习系统**: 错题本（原卷快照对比）、收藏夹、相似题推荐（举一反三）。
- **资源中心**: 数字化教材、章节树导航、微课视频预览、PDF/HTML 课件。
- **互动中心**: 老师在线答疑（实时图文消息）。

## 4. 技术演进
项目从早期的简单 WebView 页面，逐步演化为具备**强交互（手写板）、大规模本地存储（IndexedDB）、实时通信（WebSocket）及复杂组件状态管理（Pinia）**的重客户端 Web 应用。
