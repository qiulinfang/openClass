# 教师在线答疑

## 1. 业务逻辑
- **人工协同**: AI 学伴无法解决的问题，支持一键转发给真人教师。
- **实时性**: 建立师生 1 对 1 的实时对话空间。
- **图文混排**: 支持发送题干、手写笔迹截图、公式及普通文字消息。
- **状态感知**: 提供“老师在线/忙碌/离线”的状态提示，优化学生心理预期。

## 2. 技术实现

### 2.1 WebSocket 长连接管理
- **全局单例**: 整个应用共用一个 `webSocketService`。
- **心跳保活**: 每隔 30s 发送 Ping 包，检测连接活性。
- **断线重连**: 具备指数退避算法的自动重连机制。
- **消息分发**: 接收到后端推送后，通过 `EventEmitter` 或 Pinia Actions 将消息精准分发到对应的会话窗口。

### 2.2 消息同步策略
- **历史拉取**: 进入会话时，先通过 HTTP 接口拉取最近 20 条历史记录，确保上下文连贯。
- **增量接收**: 建立连接后，新消息全量走 WebSocket 推送。
- **状态同步**: 通过特殊的 `control_frame` 消息类型，同步老师端的“正在输入”、“已读未读”状态。

### 2.3 媒体资源上传
- **特殊通道**: 为了提高效率，转发给老师的图片会优先上传到专门的研伴后端文件服务器 (`uploadImg`)。
- **预缩略**: 前端在发送前会对 Base64 图片进行二次压缩，减少带宽压力。
