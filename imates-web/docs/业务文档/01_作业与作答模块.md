# 作业与作答模块

## 1. 业务流程
1.  **作业加载**: 学生进入“我的作业”，系统从云端获取未完成列表。
2.  **多态作答**: 
    *   **客观题**: 点击选项，即时反馈选择状态。
    *   **主观题/填空题**: 激活内置白板，学生使用电容笔或手指进行手写答题。
3.  **进度保存**: 切换题目或退出页面时，系统会自动将当前的画板笔迹、已选选项异步持久化。
4.  **作业提交**: 
    *   **自动截图**: 提交时，系统会背景静默渲染所有手写题目并截图。
    *   **确认机制**: 漏题提醒，确保学生完整作答。
5.  **结果回顾**: 提交后，页面转为“解析模式”，显示标准答案及 AI 生成的详细解析。

## 2. 技术实现

### 2.1 交互式白板系统 (`DrawingBoardNew.vue`)
- **核心库**: 基于原生 Canvas 封装。
- **功能**: 支持画笔（粗细/颜色）、橡皮擦、清空、撤销/重做、缩放、背景图注入。
- **数据结构**: 笔迹数据存储为 JSON 格式（`objects` 数组），便于后续二次编辑。

### 2.2 作答快照技术
- **难点**: 如何将动态渲染的 HTML（含 MathJax 公式）转为图片上传。
- **方案**: 使用 `html-to-image` 库。
- **优化**: 
  *   使用隐藏的离屏容器进行渲染，避免 UI 抖动。
  *   等待 `MathJax` 渲染完成及所有图片加载后再截图。
  *   采用 `cacheBust` 防止缓存导致的资源加载失败。

### 2.3 状态持久化策略
- **内存缓存**: `answerDataCache` (Pinia Store)。
- **持久化**: `HomeworkStorageDB` (IndexedDB)。
- **同步时机**: 监听路由离开、页面关闭（beforeunload）、手动切换题目。
