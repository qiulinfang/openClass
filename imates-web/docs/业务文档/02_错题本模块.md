# 错题本模块

## 1. 业务流程
1.  **自动/手动收集**: 学生在作业解析页点击“加入错题本”。
2.  **原卷快照记录**: 系统捕获学生当时的原始作答状态（笔迹截图、已选错误项）及来源作业信息。
3.  **对比分析**: 在错题本中，采用左右分栏展示“我的作答”与“标准答案”，强制学生进行反思。
4.  **再练习闭环**: 点击“加入习题列表”，将错题转化为待练习题目，并在列表 UI 中通过“往日错题”标签进行视觉强化。

## 2. 技术实现

### 2.1 错题本地数据库 (`MistakeStorageDB`)
- **存储对象**: `MistakeItem`
- **关键字段**: 
  *   `originalAnswer`: 包含选择题选项、判断值或画板生成的 Base64 截图。
  *   `questionData`: 完整的题目内容元数据。
  *   `homeworkName`: 来源信息，增强记忆关联。
- **管理逻辑**: 提供 `addMistake`, `getAllMistakes`, `deleteMistake` 等封装方法。

### 2.2 UI 标记机制
- **技术点**: 全局题目列表 (`QuestionList`) 的自动化增强。
- **实现**: 
  *   在题目列表加载时，并发查询 `MistakeStorageDB`。
  *   利用 `Map` 对象建立 `bmNo -> isMistake` 的快速索引映射。
  *   Vue 监听题目列表变化，自动更新“往日错题”徽章。

### 2.3 “加入习题列表”同步
- **云端同步**: 调用 `apiService.addQuestionToList` 将错题信息同步至服务器个人习题库。
- **本地联动**: 成功后，学生在“我的习题”模块即可看到该题目，实现多端/多模块数据同步。
