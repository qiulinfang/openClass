# Web 面试题 - 图形与交互 (Canvas)

> 本面试题基于项目实际代码，深入探讨技术实现细节与业务难点。

## 1. Canvas 核心原理

### Q1: 项目中 PDF 标注系统使用双层 Canvas 架构，请解释各层的职责和通信方式。
- **底层 (PDF Canvas)**: 负责渲染 PDF 页面内容，使用 MuPDF 库。
- **上层 (Ink Canvas)**: 负责渲染用户手写笔迹、荧光笔、矩形选框等。
- **坐标对齐**: 两层 Canvas 使用相同的 `scale` 和 `offset`，通过 `renderDprRef` 处理设备像素比。
- **优势**: PDF 只需渲染一次，笔迹变更时只需重绘上层，极大降低渲染开销。

### Q2: Canvas 的 `devicePixelRatio` 是如何处理的？为什么高清屏上 Canvas 会模糊？
- **模糊原因**: Canvas 默认使用 CSS 像素作为分辨率，在高清屏上 1 CSS 像素对应多个物理像素。
- **解决方案**: 
  ```typescript
  const dpr = window.devicePixelRatio || 1
  canvas.width = rect.width * dpr
  canvas.height = rect.height * dpr
  ctx.scale(dpr, dpr)
  ```
- **项目实践**: 本项目中通过 `renderDprRef` 统一管理，确保笔迹与 PDF 底图对齐。

### Q3: Canvas 的 `requestAnimationFrame` 动画循环是如何工作的？如何实现高效的帧率控制？
- **原理**: `requestAnimationFrame` 会在浏览器下一次重绘前调用回调，通常是 60fps。
- **帧率控制**: 
  - 使用时间戳判断是否需要渲染。
  - 避免在每一帧都执行重绘，合并多次变更。
- **项目实践**: 本项目使用 `highlighterRafId`, `penRafId`, `eraserRafId` 分别管理不同工具的渲染请求。

## 2. 图形算法与交互

### Q4: 项目中手写笔迹的平滑算法是什么？如何处理触控采样不均匀的问题？
- **算法**: 使用二次贝塞尔曲线（Quadratic Bezier）进行插值。
- **原理**: 将相邻的采样点作为控制点，中点作为锚点，生成平滑曲线。
- **代码实现**:
  ```typescript
  ctx.quadraticCurveTo(p0.x, p0.y, midX, midY)
  ```

### Q5: 什么是空间索引（Spatial Index）？项目中如何用它优化图形拾取？
- **原理**: 将画布划分为网格（如 100x100 px），记录每个图形所在的网格。
- **应用**: 
  - 橡皮擦擦除时，只需检测相交网格内的笔迹。
  - 选区选中时，快速筛选可能选中的图形。
- **项目实现**: 使用 `spatialGrid` Map 存储 `pageIndex|gridX|gridY` -> `Set<Stroke>` 的映射。

### Q6: 矩形选区和自由选区是如何实现的？选区变换（移动、缩放）如何处理？
- **矩形选区**: 计算选中框与笔迹边界框的相交关系。
- **自由选区**: 使用点与多边形的包含关系判断（射线法）。
- **变换**: 记录选中笔迹的原始状态，变换后更新所有相关点的坐标。

## 3. 性能优化

### Q7: 大量笔迹渲染时如何优化性能？离屏渲染（Offscreen Canvas）是什么？
- **分页渲染**: 只渲染当前可视区域内的页面。
- **增量渲染**: 笔迹变更时只重绘变化的页面。
- **离屏渲染**: 
  - 在内存中创建离屏 Canvas 进行绘制。
  - 完成后一次性绘制到主 Canvas。
  - 适合复杂图形或需要复用的场景。

### Q8: 什么是脏矩形渲染（Dirty Rectangle）？项目中如何应用？
- **原理**: 只重绘发生变化的区域，而不是整个 Canvas。
- **应用**: 
  - 橡皮擦擦除时，计算擦除区域，只重绘该区域。
  - 选区移动时，只重绘选区覆盖的区域。

### Q9: Canvas 的内存泄漏有哪些常见场景？如何避免？
- **常见场景**:
  - 未清理的 `requestAnimationFrame` 回调。
  - 未关闭的字体加载。
  - 未清理的事件监听器。
- **避免方法**: 
  - 在组件卸载时清理所有 RAF 和监听器。
  - 使用 `ctx.clearRect()` 清理画布。
  - 及时释放大型对象引用。

## 4. 图形库对比

### Q10: Fabric.js 和 Konva 有什么区别？项目中为什么选择其中一个（或两者都用）？
- **Fabric.js**: 
  - 对象模型完善，适合编辑器场景。
  - 内置选择、变换、序列化功能。
- **Konva**: 
  - 场景树结构，层级管理清晰。
  - 性能更好，适合动画和游戏。
- **项目实践**: 
  - PDF 标注使用原生 Canvas（精细控制）。
  - 图片标注可能使用 Fabric.js（对象操作更方便）。

### Q11: 电子签名功能是如何实现的？`signature_pad` 库的核心原理是什么？
- **原理**: 
  - 监听 `pointerdown`, `pointermove`, `pointerup` 事件。
  - 使用贝塞尔曲线平滑笔迹。
  - 支持导出为 PNG/SVG。
- **项目集成**: 通过 `toDataURL` 获取签名图片，存入本地或上传服务器。
