## 1. 教师端 (Teacher) 业务接口
**基础路径**: `/api/question`
**请求方式**: 全部为 `POST`
**认证方式**: Header 需携带 Token

### 1.1 获取会话列表 (带未读标记)
*   **接口**: `sessionList`
*   **请求参数**:
```json
{
  "teacherId": "1869298067815227393", // 教师ID
  "studentName": "",                  // 可选：学生姓名搜索
  "page": 1,                          // 页码
  "pageSize": 10                      // 每页条数
}
```
*   **说明**: 返回分页数据。`hasUnRead` 字段为 `true` 时，前端应在列表显示红点。

## 2. 学生端 (Student) 通讯逻辑

学生端目前主要通过 **WebSocket** 进行实时交互。

### 2.1 发送提问
通过 WebSocket 发送 JSON 字符串：
```json
{
  "type": "STUDENT_QUESTION",
  "userId": "学生账号",
  "sessionId": "会话ID",
  "content": "提问内容",
  "msgType": "0",
  "subject": "1" // 科目ID
}
```

---

## 3. WebSocket 实时通知协议 (教师端监听)

教师端建立连接后，需处理以下下行消息：

### 3.1 收到新提问通知 (`NEW_QUESTION`)
当学生发送消息，且该学生属于教师管理的班级时，教师端会收到：
```json
{
  "type": "NEW_QUESTION",
  "data": {
    "notice": "有新的问题,请尽快回复",
    "payload": {
      "sessionId": "会话ID",
      "content": "...",
      "msgType": "0",
      "senderType": "STUDENT",
      "timestamp": 1714286569000
    }
  }
}
```

### 3.2 心跳回复 (`PONG`)
*   **客户端发**: `{"type": "PING"}`
*   **服务端回**: `{"type": "PONG", "timestamp": 1714286569000}`
*   **建议间隔**: 30秒

---

## 4. 关键枚举定义

| 消息类型 (`msgType`) | 说明 |
| :--- | :--- |
| **0** | 纯文本消息 |
| **1** | 图片消息 (Content 为 URL) |
| **2** | 语音消息 (Content 为 URL) |
