# “选中并问学伴”功能逻辑总结

## 1. 概述
“选中并问学伴”是应用中跨多个模块（PDF 查看、习题作答、草稿本）的核心交互功能。它通过在聊天面板触发截图请求，在内容区进行框选截图，并最终将截图回填至对话框，实现了一种“所见即所得”的 AI 问答体验。

## 2. 核心角色与职责

功能实现依赖于三层组件的解耦与协作：

*   **左侧：内容/画布区** (`PdfPage` 或 `DrawingBoardNew`)
    *   **职责**：呈现业务内容，提供矩形/自由形状的划选技术，生成图片数据。
*   **右侧：聊天面板** (`PdfChatPanel` / `ExerciseChatPanelNew` / `DraftNoteChatPanel`)
    *   **职责**：管理 AI 会话，提供截图触发入口，显示“探索遮罩”提示。
*   **协调者：页面视图** (`PdfViewerView` / `ExerciseSolveView` / `DraftNotebookView`)
    *   **职责**：作为中转站，协调左右组件的状态同步（如开启/关闭截图模式）和数据传输。

## 3. 标准交互流程

### 阶段一：触发截图模式（由右向左）
1.  **点击入口**：用户在聊天面板点击“截图图标”。
2.  **发出请求**：聊天面板通过 `emit('request-screenshot')` 通知父组件。
3.  **开启遮罩**：父组件修改状态（如 `isBoardCapturing = true`），并传给聊天面板显示**浅紫色遮罩** (`explore-overlay`)。
4.  **画布变身**：父组件调用左侧组件方法（如 `handleToolbarToolChange('askAi')`），将画笔变为**框选工具**。

### 阶段二：划选与捕获（内容区进行）
1.  **用户划选**：用户在左侧内容区划出想要提问的范围。
2.  **生成数据**：左侧组件自动提取划选区域，生成 **Base64 图片**。
3.  **上报结果**：左侧组件通过 `emit('ask-ai-image-selected')` 将图片信息传给父组件。

### 阶段三：数据回填与复位（由左向右）
1.  **关闭模式**：父组件将 `isBoardCapturing` 设为 `false`，遮罩消失，画布恢复普通画笔模式。
2.  **注入图片**：父组件调用聊天面板暴露的 `attachImageToAiGeneral` 方法。
3.  **即时预览**：图片出现在对话输入框中，用户点击发送即可。

## 4. 场景实现差异

| 场景 | 内容载体 | 截图实现方式 | 布局/头部组件 |
| :--- | :--- | :--- | :--- |
| **PDF 查看** | `PdfPage` | 原生 DOM 截图 (htmlToImage) | `q-splitter` + `DrawingHeader` |
| **习题作答** | `DrawingBoardNew` | Canvas 内部导出 | `SplitPanel` + 传统 Header |
| **草稿本** | `DrawingBoardNew` | Canvas 内部导出 | `q-splitter` + `DrawingHeader` |

## 5. 设计优势
1.  **高度解耦**：右侧聊天面板无需关心左侧是 PDF 还是画板，只需按标准协议发送请求。
2.  **视觉统一**：通过统一的紫色遮罩和覆盖按钮，引导用户关注当前的划选操作。
3.  **逻辑复用**：新场景（如草稿本）可以快速通过复用现有的组件通信模式实现相同的高级功能。

## 6. 关键代码模式 (View 层示例)

```typescript
// 响应聊天面板的截图请求
const handleChatPanelScreenshotRequest = () => {
  isBoardCapturing.value = true; 
  drawingBoardRef.value.handleToolbarToolChange('askAi'); 
}

// 响应画板的图片选择完成
const handleAskAiImageSelected = async (imageInfo) => {
  isBoardCapturing.value = false;
  drawingBoardRef.value?.handleToolbarToolChange('draw'); 
  chatPanelRef.value?.attachImageToAiGeneral?.(imageInfo); 
}
```
