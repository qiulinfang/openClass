# 项目架构全景文档

## 1. 整体技术架构

本项目是一个基于 **Vue 3 + TypeScript** 开发的重型客户端 Web 应用，深度集成在 Android 原生系统的 WebView 中。

### 1.1 技术栈选型
-   **核心框架**: Vue 3 (Composition API)
-   **构建工具**: Vite
-   **状态管理**: Pinia (用于跨组件状态共享及持久化)
-   **UI 体系**: Quasar Framework (提供 Material Design 组件) + TailwindCSS (用于原子化样式布局)
-   **本地存储**: IndexedDB (存储大型资源文件、离线作答进度、错题本)
-   **通信协议**: Axios (HTTP) + WebSocket (老师实时答疑)
-   **渲染引擎**: MathJax (处理海量数学公式渲染)

---

## 2. 分层架构设计

应用遵循经典的分层设计原则，确保逻辑解耦与高度可维护性。

### 2.1 视图层 (Views & Components)
-   **`src/views/`**: 页面级组件，负责路由配置对应的完整业务场景。
-   **`src/components/`**: 
    -   `base/`: 基础原子组件（Button, Dialog, Modal 等）。
    -   `exercise/`: 业务专项题目渲染组件（选择、判断、填空）。
    -   `dialog/`: 业务对话框。
    -   `question/`: 题目列表相关的策略实现与 UI。

### 2.2 逻辑层 (Services & Stores)
-   **`src/stores/`**: Pinia 状态中心，划分模块存储 UI 状态（uiStore）、作业数据（homeworkStore）、AI 会话（aiChatStore）等。
-   **`src/services/`**: 
    -   `http/`: 封装所有后端接口调用。
    -   `storage/`: IndexedDB 存储管理（资源下载、作业持久化、错题本）。
    -   `business/`: 核心业务逻辑封装，如 AndroidBridge 桥接。
    -   `websocket/`: 管理长连接的生命周期与消息分发。

### 2.3 适配与工具层 (Utils & Composables)
-   **`src/composables/`**: 提取可复用的组合式逻辑，如消息渲染（useMessageRenderer）、屏幕截图（useScreenSnapshot）。
-   **`src/utils/`**: 纯函数工具库，涵盖数学处理、格式化、防抖节流等。
-   **`src/adapters/`**: 针对不同环境或不同数据源的适配器。

## 3. 核心机制详解

### 3.1 Android-Web 桥接机制 (`AndroidBridge`)
项目通过 `window.WebAppInterface` 与 Android 原生进行交互。桥接层负责：
-   **原生能力调用**: 拍照、控制状态栏、打开原生 Activity、回传日志。
-   **环境屏蔽**: 在开发环境下提供 Mock 实现，确保 Web 端可独立运行调试。
-   **事件中转**: 接收原生的物理返回键监听、课堂状态变更推送。

### 3.2 离线资源管理体系
为了支持在弱网环境下的流畅体验，系统构建了复杂的离线管理逻辑：
-   **三级缓存**: 内存 (Pinia) -> 持久化数据库 (IndexedDB) -> 云端备份。
-   **增量对账**: 基于 `checksum` 的版本对比算法，实现课件的静默差分下载。
-   **流式下载**: 使用 `fetch` 流式读取并实时写入数据库，降低大文件内存占用。

### 3.3 题目渲染与交互架构
-   **高度复用**: 题目列表 (`QuestionList`) 采用**策略模式**，动态切换“我的作业”、“我的习题”、“错题本”三种不同的业务逻辑。
-   **混合渲染**: 题干使用 MathJax 渲染 HTML，作答区根据题型动态加载交互组件或白板系统。

## 4. 目录结构规范

```text
src/
├── adapters/          # 数据/接口适配器
├── components/        # UI 组件库
│   ├── base/          # 基础组件
│   ├── exercise/      # 题目渲染
│   └── question/      # 列表策略
├── composables/       # 组合式业务逻辑
├── config/            # 环境与全局配置
├── constants/         # 常量与枚举
├── services/          # 服务层 (HTTP/WS/Storage)
├── stores/            # Pinia 状态管理
├── types/             # 全局 TypeScript 定义
├── utils/             # 工具函数
└── views/             # 路由页面组件
```

## 5. 开发与部署
-   **WebView 构建**: 提供 `scripts/build-webview-pages.js` 支持单个页面的快速构建与测试。
-   **环境切换**: 支持 `RELEASE` 与 `INTERNAL_TEST` 动态切换，自动重定向 Base URL。
