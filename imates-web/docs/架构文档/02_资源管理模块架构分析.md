# 资源管理模块架构文档 (MyResourcesView)

## 1. 模块概述
资源管理模块（`MyResourcesView`）是系统的核心功能之一，负责教材资源的在线预览、下载管理、版本同步以及离线学习支持。该模块采用了**离线优先 (Offline-First)** 的设计思路，确保用户在弱网或断网环境下仍能正常使用已下载的教学资源。

## 2. 核心架构设计

### 2.1 数据流转模型 (MVVM + Persistence)
模块通过 Vue 3 Composition API 构建，数据流转遵循以下路径：
- **Server API**: 提供教材元数据、学习包下载地址、版本对比接口。
- **IndexedDB (resourceManager)**: 作为本地持久化层，存储教材状态、下载进度、本地文件索引。
- **Pinia Stores**: 
  - `resourceStore`: 管理全局资源通知状态。
  - `KnowledgeGraphStore`: 管理当前选中的教材与学科上下文。
- **UI State**: 通过 `computed` 属性实现多维度（年级、版本、学科、状态）的响应式过滤。

### 2.2 离线优先策略
1. **快读路径 (Fast Path)**: 初始化时优先从 IndexedDB 读取本地教材数据并渲染，实现零延迟启动。
2. **异步同步**: 在展示本地数据的同时，后台发起服务端请求，对比教材版本，标记“有更新”状态。
3. **状态自愈**: 通过 `fixInconsistentDownloadStatus` 自动修复因程序异常关闭导致的下载状态残留。

## 3. 关键功能实现

### 3.1 资源同步机制 (Merge Logic)
`mergeServerAndLocalData` 函数实现了服务端与本地数据的深度合并：
- 保留本地的 `downloadStatus`、`downloadedFiles` 等运行态数据。
- 更新服务端下发的最新教材名称、封面、版本号等元数据。
- 自动处理已下架资源的清理逻辑。

### 3.2 下载状态机
模块维护了一个严格的状态机以保证任务安全：
| 状态值 | 描述 | 后续操作 |
| :--- | :--- | :--- |
| `0` | 未下载 | 开启下载任务 |
| `1` | 下载中 | 更新进度、暂停任务 |
| `2` | 已下载 | 进入学习、检查更新、清除资料 |
| `3` | 已暂停 | 恢复下载 |

### 3.3 性能优化全面总结
模块在处理大规模资源列表和频繁 I/O 操作时，采用了以下多层次优化方案：

- **渲染性能优化**：
    - **虚拟滚动 (Virtual Scrolling)**：通过 `RubberBandList` 组件实现，仅渲染可视区域内的教材卡片，极大降低了在教材数量较多（100+）时的 DOM 节点开销。
    - **图片懒加载 (Lazy Loading)**：封面图片使用 `loading="lazy"` 属性，配合浏览器原生支持，减少首屏流量消耗。
    - **属性细粒度更新**：使用 `Object.assign(textbook, fullTextbook)` 进行局部属性更新，而非替换整个数组对象，避免 Vue 触发不必要的全列表重新渲染。

- **数据处理优化**：
    - **快速加载路径 (Fast Path)**：优先读取 IndexedDB 本地缓存。在本地数据存在时，先完成 UI 渲染再进行服务端静默同步，消除用户感知的加载白屏。
    - **去重算法优化**：在 `mergeServerAndLocalData` 中使用 `reduce` 和 `Set` 进行高性能去重，并基于 ID 排序保留最新记录。
    - **权重排序系统**：通过 `getStatusRank` 算法在计算属性 `filteredTextbooks` 中实现实时排序，确保用户最高频操作（更新、下载）的项始终处于列表顶部，减少用户滚动操作。

- **异步与 I/O 优化**：
    - **批量持久化**：在 `fixInconsistentDownloadStatus` 等场景下，收集所有变更后使用 `Promise.all` 批量写入 IndexedDB，减少数据库事务开销。
    - **并发控制**：下载引擎内部限制了同时下载的文件并发数，防止因过高并发导致的网络拥塞或浏览器崩溃。
    - **空闲检查**：利用 `setTimeout` 将非核心的“检查更新”任务推迟 3 秒执行，避开启动时的 CPU 密集期。

- **交互体验优化**：
    - **状态自愈机制**：挂载时自动检测并修正异常下载状态，减少了因状态不一致导致的用户手动重试频率。
    - **防抖与防重复执行**：在下载和筛选操作中内置状态锁（如 `downloadStatus === 1` 拦截），防止用户误触导致的重复请求。

## 4. 依赖项说明
- **Storage**: `@/services/storage/resource-storage` (基于 IndexedDB)
- **Networking**: `@/services/http/api-service` (封装了下载与并发控制)
- **UI Components**: 
  - `Select.vue`: 统一的筛选器组件
  - `VirtualList.vue`: 现代回弹效果列表
  - `ResourceDebugPanel.vue`: 开发环境调试工具

## 5. 扩展建议
- **断点续传**: 目前已支持基础的暂停/恢复，未来可优化分片下载的校验机制。
- **预下载策略**: 基于用户学习行为预测，自动预下载下一章节资源。
