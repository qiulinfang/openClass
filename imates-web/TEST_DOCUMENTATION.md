# imates-web 项目测试文档

## 项目概述

imates-web 是一个基于 Vue 3 + TypeScript + Quasar 的教育学习平台前端应用，主要功能包括：
- 知识图谱学习
- AI 辅助练习解答
- 作业管理系统
- 拍照搜题功能
- 实时聊天（AI 老师和真人老师）
- 资源管理和文件查看
- 跨平台支持（Web/Android）

## 测试策略

### 测试类型
1. **单元测试**：组件、工具函数、状态管理
2. **集成测试**：API 调用、组件间交互
3. **端到端测试**：完整用户流程
4. **性能测试**：加载时间、内存使用
5. **兼容性测试**：浏览器、设备兼容性
6. **安全性测试**：数据保护、权限控制

### 测试环境
- **开发环境**：本地开发测试
- **测试环境**：staging 服务器
- **生产环境**：生产服务器
- **移动端**：Android 设备测试

### 测试工具
- **单元测试**：Vitest + Vue Test Utils
- **E2E 测试**：Playwright
- **API 测试**：Postman/Insomnia
- **性能测试**：Lighthouse + WebPageTest
- **覆盖率**：Vitest coverage

### 1. 用户认证模块

#### 1.1 登录功能测试

**测试场景：用户登录**
- **ID**: AUTH_001
- **优先级**: 高
- **前置条件**:
  - 用户未登录状态
  - 有效的用户名和密码
- **测试步骤**:
  1. 打开应用首页
  2. 应用自动跳转到登录页面
  3. 输入有效的用户名和密码
  4. 点击登录按钮
- **预期结果**:
  - 登录API调用成功 (HTTP 200)
  - 返回有效的用户信息和token
  - 跳转到应用主界面 (`/app/knowledge-graph`)
  - 用户信息正确显示在导航栏 (头像、用户名)

  - token存储到本地存储
- **异常情况**:
  - 无效用户名/密码: 显示"用户名或密码错误"提示
  - 网络错误: 显示"网络连接失败，请检查网络"提示
  - 服务器错误: 显示"服务器错误，请稍后重试"提示

  - 自动跳转到主界面，无需重新登录

**测试场景：登录过期处理**

- **测试步骤**:

### 10. 安全性测试用例

#### 10.1 数据传输安全

**测试场景：HTTPS 传输验证**
- **ID**: SEC_001
- **优先级**: 高
- **测试步骤**:
  1. 使用网络抓包工具 (Wireshark/Fiddler) 监控所有HTTP/HTTPS请求
  2. 执行登录、聊天、文件上传等操作
  3. 检查所有敏感数据传输
- **预期结果**:
  - 所有API请求使用HTTPS协议
  - 无HTTP明文传输
  - 敏感数据 (密码、token、用户个人信息) 正确加密传输
  - SSL证书有效且可信

**测试场景：WebSocket 安全连接**
- **ID**: SEC_002
- **优先级**: 高
- **测试步骤**:
  1. 建立WebSocket连接
  2. 使用网络工具检查连接协议
- **预期结果**:
  - 使用WSS (WebSocket Secure) 协议
  - 连接通过HTTPS升级建立

#### 10.2 本地存储安全

**测试场景：本地数据保护**
- **ID**: SEC_003
- **优先级**: 高
- **测试步骤**:
  1. 打开浏览器开发者工具
  2. 检查 IndexedDB 存储内容
  3. 检查 LocalStorage/SessionStorage 内容
  4. 检查本地文件存储
- **预期结果**:
  - 用户token和敏感信息正确加密存储
  - 聊天记录等隐私数据在IndexedDB中安全存储
  - 无明文存储的密码或其他敏感信息
  - 使用适当的加密算法 (AES等)

**测试场景：数据持久化安全**
- **ID**: SEC_004
- **优先级**: 中
- **测试步骤**:
  1. 登录应用并进行一些操作
  2. 关闭浏览器后重新打开
  3. 检查数据是否正确恢复
- **预期结果**:
  - 本地数据正确保存和恢复
  - 敏感数据在设备重启后仍然安全
  - 支持数据清理功能

#### 10.3 权限控制

**测试场景：API 访问控制**
- **ID**: SEC_005
- **优先级**: 高
- **测试步骤**:
  1. 使用未登录状态尝试访问需要认证的API
  2. 使用过期token尝试访问API
  3. 使用其他用户的token尝试访问私人数据
- **预期结果**:
  - 未认证请求返回401 Unauthorized
  - 过期token返回401 Unauthorized
  - 越权访问返回403 Forbidden
  - 前端正确处理认证错误并跳转到登录页面

**测试场景：功能权限控制**
- **ID**: SEC_006
- **优先级**: 高
- **测试步骤**:
  1. 使用不同角色的用户账号登录
  2. 尝试访问各自权限范围外的功能
- **预期结果**:
  - 学生用户无法访问教师专用功能
  - 权限不足时显示适当的错误提示
  - UI元素根据用户权限正确显示/隐藏

**测试场景：XSS 防护**
- **ID**: SEC_007
- **优先级**: 高
- **测试步骤**:
  1. 在聊天输入框输入XSS测试代码
  2. 在题目搜索框输入XSS代码
  3. 提交包含恶意脚本的内容
- **预期结果**:
  - 所有用户输入正确转义
  - 恶意脚本不被执行
  - 内容以文本形式安全显示

**测试场景：CSRF 防护**
- **ID**: SEC_008
- **优先级**: 中
- **测试步骤**:
  1. 构造跨站请求伪造攻击
  2. 尝试在其他站点执行API调用
- **预期结果**:
  - CSRF token正确验证
  - 跨站请求被拒绝
  - 敏感操作需要有效的CSRF token

**测试场景：文件上传安全**
- **ID**: SEC_009
- **优先级**: 高
- **测试步骤**:
  1. 上传不同类型的文件 (正常图片、恶意脚本伪装的图片、大文件)

  - 文件大小限制正确执行
  - 恶意文件被拒绝上传
  - 服务器端二次验证文件安全性

## 自动化测试建议

### 单元测试
```bash
# 运行所有单元测试
npm run test:unit

# 运行特定组件测试
npm run test:unit -- --grep "ChatView"

# 生成覆盖率报告
npm run test:unit -- --coverage
```

### E2E 测试
```bash
# 运行 E2E 测试
npm run test:e2e

# 运行特定测试文件
npx playwright test login.spec.ts

# 调试模式运行
npx playwright test --debug
```

### 性能测试
```bash
# 使用 Lighthouse 进行性能测试
npx lighthouse http://localhost:8080 --output html --output-path ./reports/lighthouse.html

# 运行自定义性能测试
npm run test:performance
```

### API 测试
```bash
# 使用 Postman Collection 运行API测试
newman run imates-web-api-tests.postman_collection.json

# 或使用自定义API测试脚本
npm run test:api
```
