# 题目数据结构技术文档

## 1. 通用基础结构

| 字段 | 类型 | 描述 |
| :--- | :--- | :--- |
| `id` | `string` | 内部唯一 ID |
| `bmNo` | `string` | 业务编号 (题库唯一标识) |
| `title` | `string` | 题目展示标题 |
| `type` | `string` | 题型标识：`choice`, `fill`, `judgment`, `essay` |
| `answer` | `string` | 标准答案 (校验与展示的核心) |
| `explanation`| `string` | 题目详解 / AI 解析内容 |
| `structuredContent` | `object` | 存放题干及题型特定数据 |

---

## 2. 选择题 (Choice Questions)

选择题组件通过 `structuredContent.options` 渲染，并根据 `answer` 的长度或业务配置区分单选与多选。

### 2.1 单选题
*   **标识**: `type: "single_choice"`
*   **结构特征**: `answer` 为单个选项字符（如 `"A"`）。
*   **数据示例**:
    ```json
    {
      "type": "single_choice",
      "structuredContent": {
        "stem": "1 + 1 等于几？",
        "options": [
          { "label": "A", "text": "1" },
          { "label": "B", "text": "2" }
        ]
      },
      "answer": "B"
    }
    ```
*   **交互数据**: `string[]` (数组长度恒为 1，如 `['B']`)。

### 2.2 多选题
*   **标识**: `type: "multi_choice"`
*   **结构特征**: `answer` 通常包含多个字符（如 `"A,B"` 或由数组转换的字符串）。
*   **数据示例**:
    ```json
    {
      "type": "multi_choice",
      "structuredContent": {
        "stem": "哪些是偶数？",
        "options": [
          { "label": "A", "text": "2" },
          { "label": "B", "text": "4" },
          { "label": "C", "text": "5" }
        ]
      },
      "answer": "A,B"
    }
    ```
*   **交互数据**: `string[]` (包含所有选中的 label，如 `['A', 'B']`)。

---

## 3. 判断题 (Judgment Questions)
*   **标识**: `type: "judgment"`
*   **结构特征**: `structuredContent` 中包含布尔值 `judgmentResult`。
*   **数据示例**:
    ```json
    {
      "type": "judgment",
      "structuredContent": {
        "stem": "0 是正数",
        "judgmentResult": false
      },
      "answer": "错" 
    }
    ```
*   **交互数据**: `string` (固定为 `'对'` 或 `'错'`)。

---

## 4. 填空题 (Fill-in-the-Blank)
*   **标识**: `type: "fill"`
*   **结构特征**: 组件会自动解析 `stem` 中的括号 `( )` 或 `（ ）`，将其动态替换为行内输入框。
*   **数据示例**:
    ```json
    {
      "type": "fill",
      "structuredContent": {
        "stem": "三角形内角和是 (  ) 度，正方形内角和是 (  ) 度。",
        "blanks": 2 
      },
      "answer": "180、360"
    }
    ```
*   **交互数据**: `string[]` (按括号出现顺序存储输入内容，如 `['180', '360']`)。

---

## 5. 解答题 (Essay Questions)
*   **标识**: `type: "essay"`
*   **结构特征**: 通常仅包含题干，不限制输入形式。
*   **数据示例**:
    ```json
    {
      "type": "essay",
      "structuredContent": {
        "stem": "请简述光合作用的反应过程。"
      },
      "answer": "参考答案文本..."
    }
    ```
*   **交互逻辑**: 渲染题干后，配合 `DrawingBoard` (画板) 或多行文本域进行作答。

---

## 6. 技术规范要点
1.  **公式渲染**: 题干 (`stem`)、选项内容 (`text`)、题目解析 (`explanation`) 均支持标准的 **LaTeX** 公式，由 `MathJax` 插件在 DOM 挂载后自动渲染。
2.  **批改模式**: 
    *   通过 `disabled` 属性锁定交互。
    *   在 `disabled` 为 `true` 时，组件会根据 `v-model` 数据与 `answer` 进行比对，自动标记绿色（正确）或红色（错误）状态。
3.  **数据流**: 题目组件均支持 `v-model` 双向绑定，作答数据由 `ExerciseSolveViewNewJK` 统一拦截并缓存至 `answerDataCache` Store。
