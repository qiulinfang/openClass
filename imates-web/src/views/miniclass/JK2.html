等待回答
1. 先找平行线

同一组平行线截两条直线，交点按照平行线的顺序对应。

2. 再看对应线段

直线 m 上看 AB、BC；直线 n 上看 DE、EF。

3. 最后比较比例

不等距时相邻段不一定相等，但 AB:BC 与 DE:EF 保持一致。

变式练习

不等距平行线中，AB:BC 与 DE:EF 是否保持相同？

等待作答
等距平行线

相邻平行线间高相等，同一截线上的相邻截段相等。

不等距平行线

高不相等时，相邻截段也随之变化。

共同规律

两条截线上的对应截段保持相同的比例关系。
