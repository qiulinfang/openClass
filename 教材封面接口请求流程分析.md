#### 步骤2：资源管理器发起请求
**文件**：`LearnResourceManager.java`

**方法**：`getTextbookVersions(TextbookVersionsCallback callback)`

```java
public void getTextbookVersions(TextbookVersionsCallback callback) {
    if (!isLoggedIn()) {
        callback.onError("Not logged in");
        return;
    }
    
    Request request = new Request.Builder()
        .url(BASE_URL + "/blw-edu-yb/api/app/teacher-textbook")
        .post(RequestBody.create("", MediaType.get("application/json")))
        .addHeader("sa-token", currentToken)
        .build();

    UnsafeOkHttpClient.getUnsafeOkHttpClient()
        .newCall(request)
        .enqueue(new Callback() {
            @Override
            public void onResponse(@NonNull Call call, @NonNull Response response) {
                if (response.code() == 401) {
                    currentToken = "";
                    mainHandler.post(callback::onUnauthorized);
                    return;
                }
                
                String responseBody = response.body().string();
                ApiResponse<List<TextbookVersion>> apiResponse = gson.fromJson(
                    responseBody,
                    new TypeToken<ApiResponse<List<TextbookVersion>>>(){}.getType()
                );
                
                if (apiResponse.success && apiResponse.data != null) {
                    mainHandler.post(() -> callback.onSuccess(apiResponse.data));
                } else {
                    mainHandler.post(() -> callback.onError(apiResponse.message));
                }
            }
        });
}
```

#### 步骤3：处理响应并拼接URL
**文件**：`LearnResourceManager.java`

**方法**：`fetchUserAllOnlineTextbooks(AllTextbooksCallback callback)`

**关键代码**（第342行）：
```java
localInfo.textbookCover = BASE_URL + serverTextbook.textbookCover;
```

**完整处理逻辑**：
```java
public void fetchUserAllOnlineTextbooks(AllTextbooksCallback callback) {
    UserLearnData data = loadUserLearnData();
    if (data == null) {
        data = new UserLearnData();
    }
    
    getTextbookVersions(new TextbookVersionsCallback() {
        @Override
        public void onSuccess(List<TextbookVersion> serverTextbooks) {
            executorService.execute(() -> {
                try {
                    for (TextbookVersion serverTextbook : serverTextbooks) {
                        UserTextbookInfo localInfo = finalData.findTextbook(
                            serverTextbook.textbookId
                        );
                        
                        if (localInfo == null) {
                            // 新建教材信息
                            localInfo = new UserTextbookInfo(serverTextbook);
                            finalData.updateOrAddTextbook(localInfo);
                        } else {
                            // 更新现有教材信息
                            localInfo.id = serverTextbook.id;
                            localInfo.textbookIsbn = serverTextbook.textbookIsbn;
                            localInfo.textbookEditionYear = serverTextbook.textbookEditionYear;
                            localInfo.textbookPublisher = serverTextbook.textbookPublisher;
                            
                            // ⭐ 关键：拼接封面完整URL
                            localInfo.textbookCover = BASE_URL + serverTextbook.textbookCover;
                            
                            localInfo.newlyUpdateTime = serverTextbook.textbookUpdateTime;
                            localInfo.textbookName = serverTextbook.textbookName;
                            localInfo.textbookSubjectLabel = serverTextbook.textbookSubjectLabel;
                            localInfo.textbookGradeLabel = serverTextbook.textbookGradeLabel;
                            localInfo.textbookSemesterLabel = serverTextbook.textbookSemesterLabel;
                        }
                    }
                    
                    saveUserLearnData(finalData);
                    mainHandler.post(() -> callback.onSuccess(finalData.textbooks));
                } catch (Exception e) {
                    mainHandler.post(() -> 
                        callback.onError("Error processing textbooks: " + e.getMessage())
                    );
                }
            });
        }
    });
}
```

#### 步骤4：Adapter 中加载封面
**文件**：`TextbookAdapter.java`

**方法**：`TextbookViewHolder.bind(UserTextbookInfo textbook)`

```java
public void bind(UserTextbookInfo textbook) {
    Context context = itemView.getContext();
    
    // 加载教材封面
    if (textbook.textbookCover != null && !textbook.textbookCover.isEmpty()) {
        Glide.with(context)
            .load(textbook.textbookCover)
            .apply(new RequestOptions()
                .transform(new RoundedCorners(8))
                .placeholder(R.drawable.placeholder_book)
                .error(R.drawable.placeholder_book))
            .into(imgTextbookCover);
    } else {
        // 封面URL为空时显示占位图
        imgTextbookCover.setImageResource(R.drawable.placeholder_book);
    }
    
    // 设置其他教材信息
    txtTextbookName.setText(textbook.textbookName);
    txtGradeInfo.setText(textbook.textbookGradeLabel + textbook.textbookSemesterLabel);
    txtSubject.setText(textbook.textbookSubjectLabel);
    txtPublisher.setText(textbook.textbookPublisher != null ? 
        textbook.textbookPublisher : "未知出版社");
}
```

## 5. 潜在问题与建议

### 问题1：URL拼接逻辑
**当前实现**：
```java
localInfo.textbookCover = BASE_URL + serverTextbook.textbookCover;
```

**潜在问题**：
- 如果服务器返回的 `textbookCover` 已经是完整URL（以 `http://` 或 `https://` 开头），会导致重复拼接
- 例如：`BASE_URL + "https://example.com/cover.jpg"` 会产生错误URL

**建议改进**：
```java
// 判断是否为完整URL
if (serverTextbook.textbookCover != null && 
    !serverTextbook.textbookCover.startsWith("http")) {
    localInfo.textbookCover = BASE_URL + serverTextbook.textbookCover;
} else {
    localInfo.textbookCover = serverTextbook.textbookCover;
}
```

### 问题2：新建教材时封面URL处理
**当前实现**：
在 `UserTextbookInfo` 构造函数中，直接使用 `textbook.textbookCover`，但此时可能还是相对路径。

**建议**：
在构造函数中同样处理URL拼接，或在创建后统一处理。

### 问题3：网络错误处理
**当前实现**：
```java
@Override
public void onError(String error) {
    mainHandler.post(() -> callback.onSuccess(finalData.textbooks));
}
```

**潜在问题**：
网络错误时仍然返回本地数据，可能导致封面URL不完整。

**建议**：
- 网络错误时，如果本地已有完整URL，则使用本地数据
- 如果本地数据不完整，则明确提示用户网络错误

## 7. 总结

教材封面接口请求流程主要包括以下几个步骤：

1. **接口请求**：通过 `getTextbookVersions()` 方法请求教材列表接口
2. **数据解析**：解析服务器返回的 `TextbookVersion` 列表，其中包含 `textbookCover` 字段
3. **URL拼接**：将相对路径的封面URL拼接为完整URL（`BASE_URL + textbookCover`）
4. **数据存储**：将完整URL保存到 `UserTextbookInfo.textbookCover` 字段
5. **图片加载**：在 `TextbookAdapter` 中使用 Glide 加载封面图片
6. **错误处理**：URL为空或加载失败时显示占位图

**关键点**：
- 封面URL在 `LearnResourceManager.fetchUserAllOnlineTextbooks()` 方法中拼接（第342行）
- 使用 Glide 库进行图片加载，支持圆角、占位图等功能
- 需要确保服务器返回的 `textbookCover` 是相对路径，否则需要调整拼接逻辑
