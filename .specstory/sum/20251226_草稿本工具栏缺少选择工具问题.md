问题序号：05 草稿本工具栏缺少选择工具问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`低`
- **影响范围**：`imates-web 草稿本(DrawingBoardView)使用 DrawingBoard 时无法直接使用选择(select)工具`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
- 草稿本页面希望在工具栏中提供“选择工具”（select icon / selecticon）。
- 但页面默认未显式传入工具列表，依赖 DrawingBoard 默认工具配置，导致 UI 上缺少或不可控。

## 复现步骤
1. 打开 `imates-web/src/views/DrawingBoardView.vue` 草稿本页面。
2. 查看顶部/侧边工具栏。
3. 发现缺少选择工具按钮，无法执行框选/移动对象等选择操作。

## 用户体验
- 无法在草稿本场景进行对象选择/移动/删除等操作。
- 工具栏能力不完整，学习成本增加。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/DrawingBoardView.vue`：草稿本页面。
  - `imates-web/src/components/DrawingBoard.vue`：接收 `drawingBoardTools` 并传入 `UnifiedToolbar`。
  - `imates-web/src/components/UnifiedToolbar.vue`：内部已有 `select` 图标资源映射（`select.svg`），选中态通过颜色高亮。
- **涉及模块**：
  - 工具栏工具配置透传（props）

## 技术原因 (❌)
1. 草稿本页面未对 `DrawingBoard` 的工具列表进行显式配置。
2. 对“selecticon”的理解可能是“选中态图标”，但实际 `UnifiedToolbar` 通过 mask + 高亮色实现选中态，并不依赖 `*_select.svg`。

错误示例（概念示意）：
```vue
<!-- ❌ 不传工具列表，页面不可控 -->
<DrawingBoard />
```

## 正确实现方案 (✅)
1. 在 `DrawingBoardView.vue` 显式传入工具列表，包含 `select`。
```vue
<!-- ✅ 传入 drawingBoardTools -->
<DrawingBoard :drawing-board-tools="drawingBoardTools" />
```

```ts
// ✅ tools 列表包含 select
const drawingBoardTools = [
  'undo',
  'redo',
  'clear',
  'select',
  'hand',
  'draw',
  'eraser-draw',
  'shape',
]
```

## 关键代码/公式
- 关键点：通过 props 让上层页面控制工具栏能力范围。

## 测试验证
- **测试场景**：
  - 场景1：草稿本页面工具栏出现选择工具按钮。
  - 场景2：点击 select 后可框选对象，切换工具正常。
- **验证方法**：
  - 方法1：UI 观察。
  - 方法2：实际框选/移动对象操作。

## 预防措施
- 约定：视图层（View）明确传入工具列表，避免依赖组件默认值导致差异。
- 对“icon vs selectedIcon”做统一约定：是否用换图，还是用颜色高亮。
