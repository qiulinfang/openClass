# 问题序号：清空画布后工具重置问题

## 问题元信息
- **问题分类**：前端/逻辑
- **严重程度**：中
- **影响范围**：画布清空功能，影响所有使用DrawingBoardNew组件的页面
- **发现日期**：2025-12-26
- **解决状态**：已解决

## 问题现象
点击清空画布后，工具状态没有重置为默认的笔工具，而是保持在之前的工具状态（如形状工具）。

## 复现步骤
1. 步骤1：切换到形状工具（如矩形工具）
2. 步骤2：在画布上绘制一些内容
3. 步骤3：点击清空画布，观察工具状态没有重置为笔工具

## 用户体验
- 影响点1：清空后工具状态混乱，用户需要手动切换工具
- 影响点2：不符合用户预期，清空应该是重置到初始状态
- 影响点3：影响连续操作的流畅性

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/drawingBoardNew.vue`：画布清空逻辑
  - `imates-web/src/views/HomeworkAnswerView.vue`：清空操作调用
- **涉及模块**：
  - 工具状态管理系统：负责工具状态的维护和重置

## 技术原因 (❌)
清空逻辑缺少工具状态重置：

1. **清空只处理数据**：`clearAll()`只清空画布数据，不重置工具状态
2. **缺少状态重置调用**：没有调用`setMode('draw')`重置工具
3. **状态管理不完整**：清空操作没有考虑完整的状态重置

❌ **错误代码示例：**
```typescript
// ❌ 清空只处理数据，不重置工具状态
const clearAll = () => {
  strokes = []
  history = []
  historyStep.value = -1
  selectedIndices.clear()
  groupBounds = null
  renderAll() // ❌ 缺少 setMode('draw')
}
```

## 正确实现方案 (✅)
在清空画布时同时重置工具状态：

1. **完整状态重置**：清空数据的同时重置工具为笔
2. **统一的重置逻辑**：所有清空操作都调用`setMode('draw')`
3. **状态一致性保证**：确保清空后的状态与初始状态一致

✅ **正确代码示例：**
```typescript
// ✅ 清空时重置工具状态
const clearAll = () => {
  strokes = []
  history = []
  historyStep.value = -1
  selectedIndices.clear()
  groupBounds = null
  // 清空画布后重置工具为笔
  setMode('draw')
  renderAll()
}

// 在所有使用DrawingBoardNew的地方确保调用clearAll
const confirmClearCanvas = () => {
  board.loadData({
    objects: [],
    history: [[]],
    historyIndex: 0,
  })
  // 再调用clearAll来重置工具状态
  board.clearAll()
}
```

## 关键代码/公式
**工具重置函数：**
```typescript
function setMode(mode) {
  currentMode.value = mode
  if (mode !== 'select') {
    selectedIndices.clear()
    groupBounds = null
    renderAll()
  } else {
    updateActionsMenuPosition()
  }
}

// 清空画布的完整流程
const clearAll = () => {
  // 1. 清空数据
  strokes = []
  history = []
  historyStep.value = -1
  selectedIndices.clear()
  groupBounds = null

  // 2. 重置工具状态
  setMode('draw')

  // 3. 重新渲染
  renderAll()
}
```

- 措施3：在设计清空功能时要明确状态重置的范围
- 措施4：多组件协作时要确保状态一致性
