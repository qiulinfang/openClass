# Pdf 手势模式触摸行为设计

## 背景

- **涉及组件**：
  - `imates-web/src/components/PdfPage.vue`
- **相关功能**：
  - PDF 手写高亮 / 画笔 / 橡皮擦
  - 单指滚动、双指捏合缩放
  - 单指/触控笔在页面上书写笔迹

在实现手写批注功能时，需要明确：

- 不同交互模式（手势、高亮、画笔、橡皮擦、笔记）下，用同一套触摸/Pointer 事件；
- 明确“什么时候让浏览器处理滚动/缩放”，“什么时候我们截获事件做绘制”。

---

## 模式与触摸行为对应

统一的交互模式枚举：

```ts
// PdfPage 内部使用
type PdfInteractionMode = 'hand' | 'note' | 'highlighter' | 'pen' | 'eraser-draw'
const currentMode = ref<PdfInteractionMode>('hand')
```

### 1. 手势模式（hand）

- **行为目标**：
  - 单指：滚动页面
  - 双指：捏合缩放
- **事件处理策略**：
  - Touch：
    - `handleTouchStart` / `handleTouchMove` **不调用** `event.preventDefault()`；
    - 将滚动和捏合缩放交给浏览器/滚动容器处理。
  - Pointer：
    - 在 `handleHighlightPointerDown/Move/Up` 中，直接 return：

      ```ts
      if (!['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) {
        return
      }
      ```

  - 效果：
    - 手势模式下不会绘制任何笔迹，只负责浏览和缩放。

### 2. 高亮/画笔/橡皮擦模式

模式值：`'highlighter' | 'pen' | 'eraser-draw'`

- **行为目标**：
  - 单指或触控笔：用于绘制（高亮/画笔）或擦除（橡皮擦）；
  - 避免被浏览器误识别为滚动/缩放，保证 PointerMove 事件持续触发；
  - 可选：双指仍然用于捏合缩放（具体 UX 再评估）。

- **事件处理策略**：

  **触摸层（TouchEvent）**：

  ```ts
  const handleTouchStart = (event: TouchEvent) => {
    // 高亮、画笔或橡皮擦模式下，优先将触摸事件用于绘制，避免触发浏览器滚动/缩放手势
    if (['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) {
      event.preventDefault()
    }
    // 手势模式下不阻止，保持默认滚动/缩放行为
    ...
  }

  const handleTouchMove = (event: TouchEvent) => {
    // 高亮、画笔或橡皮擦模式下阻止默认滚动行为，保证 PointerMove 持续触发用于手写预览
    if (['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) {
      event.preventDefault()
    }

    // 双指捏合缩放逻辑（可选保留）
    if (event.touches.length === 2 && lastTouchDistance > 0 && isPinching) {
      event.preventDefault()
      // 处理捏合缩放
      ...
    }
  }
  ```

  **Pointer 层（PointerEvent）**：

  ```ts
  const handleHighlightPointerDown = (event: PointerEvent, pageIndex: number, layout: { width: number; height: number }) => {
    // 仅在高亮/画笔/橡皮擦模式下处理 Pointer 事件，其他模式（包括手势）直接放行
    if (!['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) {
      return
    }
    ... // 创建 currentStroke，记录起点
  }

  const handleHighlightPointerMove = (event: PointerEvent, pageIndex: number, layout: { width: number; height: number }) => {
    // 同样只在绘图模式下处理移动
    if (!['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) return
    if (!currentStroke.value || currentStroke.value.pageIndex !== pageIndex) return

    const point = screenPointToPdfPoint(event.clientX, event.clientY, pageIndex, layout)
    if (!point) return

    currentStroke.value.points.push(point)

    // 按一定频率绘制预览
    const now = performance.now()
    if (now - lastHighlightPreviewTime > HIGHLIGHT_PREVIEW_INTERVAL) {
      lastHighlightPreviewTime = now
      drawStrokePreview(pageIndex, layout, currentStroke.value)
    }
  }
  ```

- **模式与 StrokeMode 映射**：

  ```ts
  const mode: StrokeMode =
    currentMode.value === 'highlighter'
      ? 'highlight'
      : currentMode.value === 'pen'
      ? 'pen'
      : currentMode.value === 'eraser-draw'
      ? 'eraser'
      : 'highlight'
  ```

  - UI 层模式枚举：`'highlighter' | 'pen' | 'eraser-draw'`；
  - MuPDF Ink 注释类型：`'highlight' | 'pen' | 'eraser'`。

### 3. 笔记模式（note）

- **行为目标**：
  - 点击页面添加笔记锚点；
  - 不干扰滚动；
  - 不处理绘图 Pointer 逻辑。

- **事件处理策略**：

  ```ts
  const handlePageClick = (event: MouseEvent, pageIndex: number, layout: { width: number; height: number }) => {
    // 绘图模式下不处理点击添加笔记
    if (['highlighter', 'pen', 'eraser-draw'].includes(currentMode.value)) return
    // 仅在 note 模式下处理
    if (currentMode.value !== 'note') return

    const norm = screenPointToNormalized(event.clientX, event.clientY, pageIndex, layout)
    if (!norm) return

    pendingNotePosition.value = { pageIndex, x: norm.x, y: norm.y }
    noteDialogMode.value = 'add'
    noteDialogText.value = ''
    isNoteDialogOpen.value = true
  }
  ```

## 模式切换设计

通过 `defineExpose` 暴露给父组件的模式切换方法：

```ts
defineExpose({
  // 调试面板
  toggleDebugPanel: () => {
    showDebugPanel.value = !showDebugPanel.value
  },
  // 笔记模式：再次点击切回手势
  toggleNoteMode: () => {
    currentMode.value = currentMode.value === 'note' ? 'hand' : 'note'
  },
  // 高亮模式：再次点击切回手势
  toggleHighlightMode: () => {
    currentMode.value = currentMode.value === 'highlighter' ? 'hand' : 'highlighter'
  },
  // 画笔模式：再次点击切回手势
  togglePenMode: () => {
    currentMode.value = currentMode.value === 'pen' ? 'hand' : 'pen'
  },
  // 橡皮擦模式：再次点击切回手势
  toggleEraserMode: () => {
    currentMode.value = currentMode.value === 'eraser-draw' ? 'hand' : 'eraser-draw'
  },
  // 手势模式：强制切回 hand
  toggleGestureMode: () => {
    currentMode.value = 'hand'
  },
})
```

- 通过 PdfViewerView 的工具栏（UnifiedToolbar）调用上述方法，实现：
  - 点击 tool → 设置对应模式；
  - 再次点击相同 tool → 退回 `hand`，恢复滚动/缩放行为。

---

## 总结

- **核心设计原则**：
  1. 模式枚举在所有组件中统一为 `'hand' | 'note' | 'highlighter' | 'pen' | 'eraser-draw'`；
  2. 手势模式（`hand`）完全交给浏览器处理滚动/缩放，不截获 touch/pointer 用于绘图；
  3. 高亮/画笔/橡皮擦模式在 Touch 层阻止默认行为，确保 PointerMove 可持续触发，用于手写预览；
  4. 笔记模式仅处理点击事件，不干扰滚动和绘图；
  5. 所有模式切换都通过 `currentMode` 控制，避免多布尔状态混乱。

- 通过上述设计，可以在同一个 PdfPage 组件中：
  - 同时支持“专业的触摸手写体验”和“自然的滚动/缩放体验”；
  - 保证工具栏状态、内部模式状态和 Pointer/Touch 处理逻辑完全一致。
