# 20251212_题目公式渲染HTML实体未反转义问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`题目题干中的公式渲染`
- **发现日期**：`2025-12-12`
- **解决状态**：`已解决`

## 问题现象
题干中的公式如 `$\\scriptstyle x &gt; 0$` 被渲染为普通文本而非数学符号，显示为：
```
\scriptstyle x &gt; 0
```

## 技术原因 (❌)
1. `markdown-it-mathjax3` 渲染前未处理 HTML 实体编码
2. `useMessageRenderer.ts` 的渲染流程中缺少反转义步骤

## 正确实现方案 (✅)
1. 在 `renderMessageContent` 中增加反转义步骤：
```typescript
// 4. 先反转义常见 HTML 实体
const unescaped = contentStr
  .replace(/&lt;/g, '<')
  .replace(/&gt;/g, '>')
  .replace(/&amp;/g, '&')
```
2. 调整后续处理步骤序号

## 测试验证
- **场景1**：渲染含 `&gt;` 的公式
  - 输入：`已知定义在 $\\mathbf{R}$ 上的奇函数 $f(x)$，当 $\\scriptstyle x &gt; 0$ 时，f(x)=3x+1`
  - 预期：`&gt;` 正确渲染为 `>` 符号
- **场景2**：普通文本中的 `&lt;` 不被影响
  - 输入：`比较大小: a &lt; b`
  - 预期：保持 `&lt;` 原样显示

## 预防措施
1. 新增渲染流程必须包含 HTML 实体检查
2. 公式预处理函数增加类型检查：`(content: string) => string`
