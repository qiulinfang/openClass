## 技术架构

### 1. 整体架构设计

参数配置化系统采用**分层架构**，从参数定义到样式应用共分为四层：

```
┌─────────────────────────────────────────┐
│  第1层：调试面板 UI（参数输入）          │
│  KnowledgeGraphDebugPanel.vue          │
└──────────────┬──────────────────────────┘
               │ 参数更新事件
               ▼
┌─────────────────────────────────────────┐
│  第2层：参数管理（状态管理）              │
│  KnowledgeGraphView.vue                 │
│  - debugParams (ref)                    │
│  - provide('knowledgeGraphDebugParams') │
└──────────────┬──────────────────────────┘
               │ Vue Provide/Inject
               ▼
┌─────────────────────────────────────────┐
│  第3层：CSS 变量转换（样式桥接）         │
│  GraphNode.vue                          │
│  - nodeStyleVariables (computed)        │
│  - inject('knowledgeGraphDebugParams')  │
└──────────────┬──────────────────────────┘
               │ CSS 变量绑定
               ▼
┌─────────────────────────────────────────┐
│  第4层：样式应用（CSS 使用）             │
│  GraphNode.vue <style>                  │
│  - var(--circular-node-font-size)      │
└─────────────────────────────────────────┘
```

### 2. 数据流设计

**数据流向**：`调试面板 → 参数对象 → CSS 变量 → 样式应用`

```typescript
// 第1步：调试面板定义参数类型和默认值
export interface KnowledgeGraphDebugParams {
  circularNodeContentFontSize: number // 圆周节点内容字体大小（rem）
  // ... 其他参数
}

// 第2步：参数对象在父组件中管理
const debugParams = ref<KnowledgeGraphDebugParams>({
  circularNodeContentFontSize: 0.875, // 默认值
  // ... 其他参数
})

// 第3步：通过 Provide 注入到子组件
provide('knowledgeGraphDebugParams', debugParams)

// 第4步：子组件通过 Inject 获取参数
const debugParams = inject<Ref<KnowledgeGraphDebugParams>>('knowledgeGraphDebugParams')

// 第5步：转换为 CSS 变量
const nodeStyleVariables = computed(() => {
  const params = debugParams?.value
  return {
    '--circular-node-content-font-size': `${params?.circularNodeContentFontSize ?? 0.875}rem`
  }
})

// 第6步：CSS 中使用变量
.node-content--circular {
  font-size: var(--circular-node-content-font-size, 0.875rem);
}
```

## 关键技术点

### 1. TypeScript 类型定义

**作用**：确保参数类型安全，提供 IDE 自动补全和类型检查

```typescript
export interface KnowledgeGraphDebugParams {
  // ========== 一级分类：轨迹与位置 ==========
  // 二级分类：椭圆轨迹
  radiusX: number // X轴半径（像素），控制椭圆轨迹的水平半径
  radiusY: number // Y轴半径（像素），控制椭圆轨迹的垂直半径
  
  // ========== 一级分类：圆周节点样式 ==========
  circularNodeContentFontSize: number // 圆周节点内容字体大小（rem）
  // ... 其他参数
}
```

**设计要点**：
- 使用注释清晰标注参数用途和单位
- 按功能分类组织参数，便于维护
- 使用明确的类型定义（number、string、boolean）

### 2. Vue 3 响应式状态管理

**使用技术**：`ref` + `provide/inject` + `computed`

```typescript
// 父组件：定义响应式参数对象
const debugParams = ref<KnowledgeGraphDebugParams>({
  circularNodeContentFontSize: 0.875,
  // ... 其他参数
})

// 通过 provide 注入
provide('knowledgeGraphDebugParams', debugParams)

// 子组件：通过 inject 获取
const debugParams = inject<Ref<KnowledgeGraphDebugParams>>('knowledgeGraphDebugParams')

// 使用 computed 转换为 CSS 变量（自动响应参数变化）
const nodeStyleVariables = computed(() => {
  const params = debugParams?.value
  return {
    '--circular-node-content-font-size': `${params?.circularNodeContentFontSize ?? 0.875}rem`
  }
})
```

**优势**：
- **响应式更新**：参数变化自动触发 CSS 变量更新
- **解耦设计**：父组件管理状态，子组件通过 inject 获取，避免 prop drilling
- **类型安全**：TypeScript 确保类型正确性

### 3. CSS 变量桥接技术

**核心思路**：将 JavaScript 参数值转换为 CSS 变量，实现 JS 与 CSS 的解耦

```typescript
// JavaScript 层：动态生成 CSS 变量
const nodeStyleVariables = computed(() => {
  const params = debugParams?.value
  return {
    '--circular-node-content-font-size': `${params?.circularNodeContentFontSize ?? 0.875}rem`,
    '--circular-node-font-size': `${params?.circularNodeFontSize ?? 1.2}rem`,
    '--circular-node-radius': `${params?.circularNodeRadius ?? 100}px`,
    '--node-animation-duration': `${params?.nodeEnterExitDuration ?? 0.6}s`,
  }
})
```

```vue
<!-- 模板层：绑定 CSS 变量到元素 -->
<div 
  :style="{
    ...nodeStyle,
    ...nodeStyleVariables
  }"
>
```

```css
/* CSS 层：使用 CSS 变量 */
.node-content--circular {
  font-size: var(--circular-node-content-font-size, 0.875rem);
}
```

**设计要点**：
- **单位转换**：在 JS 层完成单位转换（rem、px、s 等）
- **默认值处理**：CSS 变量提供默认值作为后备
- **集中管理**：所有 CSS 变量定义集中在 `nodeStyleVariables` computed 中

### 4. 参数持久化机制

**实现方式**：使用 `localStorage` + 用户隔离

```typescript
// 获取带用户ID前缀的存储key
const getDebugParamsKey = () => {
  const userId = getCurrentUserIdOrDefault()
  return `${userId}_knowledgeGraphDebugParams`
}

// 保存到本地存储
const saveToLocalStorage = () => {
  try {
    const key = getDebugParamsKey()
    localStorage.setItem(key, JSON.stringify(localParams.value))
  } catch (error) {
    console.error('❌ 保存参数失败:', error)
  }
}

// 从本地存储加载
const loadFromLocalStorage = () => {
  try {
    const key = getDebugParamsKey()
    const saved = localStorage.getItem(key)
    if (saved) {
      const parsed = JSON.parse(saved)
      // 合并默认值和保存值
      localParams.value = { ...defaultParams.value, ...parsed }
      updateParams()
    }
  } catch (error) {
    console.error('❌ 加载参数失败:', error)
  }
}
```

**设计要点**：
- **用户隔离**：不同用户的参数独立存储
- **默认值合并**：加载时合并默认值，确保新增参数有默认值
- **错误处理**：捕获 JSON 解析和存储错误

### 5. 参数变更检测与格式化

**变更检测**：比较当前值与默认值，只显示修改过的参数

```typescript
const modifiedParams = computed(() => {
  const modified: Array<{
    key: string
    label: string
    value: number | string | boolean
    formatted: string
  }> = []
  const def = defaultParams.value
  const local = localParams.value

  // 参数标签映射
  const paramLabels: Record<string, string> = {
    circularNodeContentFontSize: '圆周节点内容字体大小',
    // ... 其他参数标签
  }

  // 参数格式化函数
  const formatParamValue = (key: string, value: number | string | boolean): string => {
    if (typeof value === 'number') {
      if (key === 'circularNodeContentFontSize' || key === 'circularNodeFontSize') {
        return `${value.toFixed(2)}rem`
      } else if (key.includes('Duration')) {
        return `${value}s`
      } else if (key.includes('Size') || key.includes('Radius')) {
        return `${value}px`
      }
      return String(value)
    }
    return String(value)
  }

  // 比较每个参数
  Object.keys(local).forEach((key) => {
    const localVal = local[key as keyof typeof local]
    const defVal = def[key as keyof typeof def]
    if (localVal !== defVal) {
      modified.push({
        key,
        label: paramLabels[key] || key,
        value: localVal,
        formatted: formatParamValue(key, localVal)
      })
    }
  })

  return modified
})
```

**设计要点**：
- **智能格式化**：根据参数类型和单位自动格式化显示
- **标签映射**：提供用户友好的参数名称
- **变更追踪**：只显示修改过的参数，减少信息噪音

## 设计模式与最佳实践

### 1. 单一数据源原则（Single Source of Truth）

**原则**：参数值只在一个地方定义和管理

- ✅ **正确**：参数在 `KnowledgeGraphView.vue` 中定义，通过 provide 共享
- ❌ **错误**：在多个组件中重复定义参数

### 2. 响应式数据流

**原则**：使用 Vue 3 响应式系统实现自动更新

- ✅ **正确**：使用 `ref` + `computed` 实现响应式
- ❌ **错误**：手动调用更新函数

### 3. 类型安全

**原则**：使用 TypeScript 确保类型正确性

- ✅ **正确**：定义接口类型，使用类型注解
- ❌ **错误**：使用 `any` 类型或忽略类型检查

### 4. 默认值处理

**原则**：在所有层级都提供默认值作为后备


### 5. 单位统一管理

**原则**：在 JS 层统一处理单位转换

- ✅ **正确**：`'--circular-node-content-font-size': \`${value}rem\``
- ❌ **错误**：在 CSS 中拼接单位

### 6. 参数分类组织

**原则**：按功能分类组织参数，使用注释标注

## 注意事项与陷阱

### 1. CSS 变量作用域

**问题**：CSS 变量只在定义它的元素及其子元素中有效

**解决**：确保 CSS 变量定义在正确的元素上

```vue
<!-- ✅ 正确：变量定义在根元素 -->
<div :style="nodeStyleVariables">
  <div class="node-content">...</div>
</div>

<!-- ❌ 错误：变量定义在子元素，父元素无法使用 -->
<div>
  <div :style="nodeStyleVariables" class="node-content">...</div>
</div>
```

### 2. 响应式更新时机

**问题**：参数更新后样式未立即生效

**解决**：确保使用 `computed` 而不是普通函数

```typescript
// ✅ 正确：使用 computed，自动响应参数变化
const nodeStyleVariables = computed(() => {
  const params = debugParams?.value
  return { '--font-size': `${params?.fontSize}rem` }
})

// ❌ 错误：使用普通函数，不会自动更新
const nodeStyleVariables = () => {
  const params = debugParams?.value
  return { '--font-size': `${params?.fontSize}rem` }
}
```

### 3. 默认值一致性

**问题**：JS 层和 CSS 层的默认值不一致

**解决**：统一管理默认值，或使用常量

```typescript
// ✅ 正确：使用常量统一管理默认值
const DEFAULT_FONT_SIZE = 0.875

const nodeStyleVariables = computed(() => {
  return {
    '--font-size': `${params?.fontSize ?? DEFAULT_FONT_SIZE}rem`
  }
})

// CSS
font-size: var(--font-size, 0.875rem);
```

### 4. 参数验证

**问题**：用户输入无效参数值

**解决**：在调试面板中添加参数验证

```vue
<q-slider
  v-model="localParams.fontSize"
  :min="0.5"
  :max="2.0"
  :step="0.01"
  :rules="[(val) => val >= 0.5 && val <= 2.0 || '字体大小必须在 0.5-2.0 之间']"
/>
```
