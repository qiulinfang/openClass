问题序号：MathJax渲染测试页别名解析导致导入报错问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`渲染测试页编译/TypeScript 提示`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在新建的渲染测试页 `RenderTestView.vue` 中使用别名 `@/utils/math/mathjax` 导入 `MathJaxUtils` 时，IDE/TS 报错：Cannot find module。

## 复现步骤
1. 新建 `RenderTestView.vue` 并添加：`import { MathJaxUtils } from '@/utils/math/mathjax'`。
2. 打开文件，出现模块解析报错。

## 用户体验
- IDE 报错干扰开发。
- 影响测试页快速验证。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/RenderTestView.vue`
  - `imates-web/src/utils/math/mathjax.ts`

## 技术原因 (❌)
1. 该测试页场景下 TypeScript/Volar 对 `@` 别名解析不一致或配置未覆盖，导致静态检查失败。

## 正确实现方案 (✅)
1. 将导入改为相对路径，避免别名解析差异：

```typescript
// ✅
import { MathJaxUtils } from '../utils/math/mathjax'
```

## 关键代码/公式
见上。

## 测试验证
- **验证方法**：打开 `RenderTestView.vue`，TS 报错消失；页面可正常渲染并触发 MathJax 渲染。

## 预防措施
- 对“测试页/孤立页面”优先使用相对路径导入，或确保 tsconfig/vite alias 一致。
