问题04：AI回复多图气泡不显示（容器高度为0）问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`聊天气泡多图(multi_image)渲染`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
AI 回复的多图气泡中，图片未显示；排查时看到图片节点宽高表现为 0×0 或父容器高度塌陷。

## 复现步骤
1. 触发 AI 回复返回 `messageType = multi_image` 的消息。
2. 观察气泡：图片区域为空白。
3. 打开开发者工具：img 高度为 0 或父容器无高度。

## 用户体验
- AI 图片回复不可用，用户认为服务异常。
- 多图答案信息丢失。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/chat/ChatMessage.vue`：多图消息分支
  - `imates-web/src/components/chat/MultiImageMessage.vue`：多图网格组件

## 技术原因 (❌)
1. `MultiImageMessage` 内部 img 使用 `height: 100%`，但父容器 `.multi-image-item` 未设置稳定高度，导致高度为 0 时图片不可见。

错误示例：
```scss
.multi-image-item {
  position: relative;
  overflow: hidden;
  border-radius: 8px;
}
.multi-image-img {
  width: 100%;
  height: 100%;
}
```

## 正确实现方案 (✅)
1. 为每个网格项增加稳定的高度兜底（`aspect-ratio` + `min-height`），确保 `height:100%` 有可依赖的父高度。

正确示例：
```scss
.multi-image-item {
  aspect-ratio: 1 / 1;
  min-height: 80px;
}
```

## 关键代码/公式
- `MultiImageMessage.vue`：
  - `.multi-image-item { aspect-ratio: 1/1; min-height: 80px; }`

## 测试验证
- **测试场景**：
  - 场景1：AI 回复多图 1~3 张，网格正常显示。
  - 场景2：图片原始宽高字段缺失/为0时仍应可见。
- **验证方法**：
  - 方法1：肉眼确认渲染。
  - 方法2：检查 DOM 中 `.multi-image-item` 计算高度 > 0。

## 预防措施
- 图片容器不要依赖外部数据（width/height）才能获得高度；布局层应提供稳定尺寸策略。

- Grid 图片布局建议使用 `aspect-ratio` 固定占位，避免加载/数据缺失导致塌陷。
