问题5：KaTeX公式在聊天气泡中重叠错位问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`聊天消息气泡（ChatMessage/StreamingMessage）公式展示排版`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在聊天气泡中渲染包含多行公式或块级公式的文本时：
- 公式与上下文字出现**重叠/挤压/错位**
- 行内公式可能导致相邻行间距异常
- 块级公式缺少上下间距，阅读体验差

## 复现步骤
1. 在聊天消息中粘贴含 `$$...$$` 块级公式的解释文本（多段落）。
2. 渲染后观察到公式行与下一行文字发生重叠，或多行内容挤成一团。

## 用户体验
- 数学内容难以阅读，用户必须反复缩放/滚动确认内容。
- 影响 AI 讲解类内容的可用性与专业观感。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/chat/ChatMessage.vue`：消息内容容器 `.message-text` 的排版样式
  - `imates-web/src/main.ts`：KaTeX CSS 引入（基础样式）
- **涉及模块**：
  - 聊天消息渲染（v-html + KaTeX DOM）

## 技术原因 (❌)
1. `.message-text` 的基础行高/布局适合普通文本，但 KaTeX 生成的 DOM 高度与 baseline 对齐需求更复杂。
2. 未对 `.katex` / `.katex-display` 做针对性样式覆盖：
   - 块级公式缺少 `margin`
   - 横向较长公式未开启横向滚动，可能导致布局压缩
   - inline 公式的 `vertical-align/line-height` 未统一

## 正确实现方案 (✅)
1. 在消息内容容器中增加 KaTeX 专用样式：
   - `.katex`：统一 line-height / baseline
   - `.katex-display`：作为块级元素，并添加上下 margin
   - 过长公式允许横向滚动

正确样式示例：
```scss
/* ✅ KaTeX 公式排版修复 */
:deep(.katex) {
  font-size: 1em;
  line-height: 1.2;
  vertical-align: baseline;
  white-space: normal;
}

:deep(.katex-display) {
  display: block;
  margin: 8px 0;
  overflow-x: auto;
  overflow-y: hidden;
  -webkit-overflow-scrolling: touch;
}

:deep(.katex-display > .katex) {
  white-space: nowrap;
}
```

## 测试验证
- **测试场景**：
  - 场景1：多段落 + 块级公式（`$$...$$`）
  - 场景2：长公式（需要横向滚动）
  - 场景3：密集行内公式（`$...$`）
- **验证方法**：
  - 方法1：块级公式上下留白正常，不再挤压下一行。
  - 方法2：长公式不会撑破气泡布局，可横向滚动。
  - 方法3：行内公式与文本 baseline 对齐，行距稳定。

## 预防措施
- UI 容器样式设计时，为第三方渲染 DOM（KaTeX/MathJax）预留扩展点。
- 建立“富文本/公式”样式规范文件，统一在消息、题目解析等多个场景复用。

## 可复用经验
- 富文本渲染问题优先从 CSS 入手（line-height / overflow / margin / baseline）。
- 对渲染产物（`.katex-display`）做“块级语义化”处理，能显著降低排版问题。
