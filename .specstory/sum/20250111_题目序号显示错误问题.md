# 问题序号：题目序号显示错误问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`题目列表序号显示`
- **发现日期**：`2025-01-11`
- **解决状态**：`已解决`

## 问题现象
切换科目时，题目序号显示不正确。例如：先加载全部学科，然后切换科目为数学，再切换科目为生物，数学题号从1开始（正确），但生物题号从136开始（错误，应该从1开始）。

## 复现步骤
1. 步骤1：打开题目列表页面，加载全部学科（包含数学和生物）
2. 步骤2：切换科目为数学，观察题号从1开始（正确）
3. 步骤3：切换科目为生物，观察题号从136开始（错误，应该从1开始）

## 用户体验
- 用户看到生物题号从136开始，会感到困惑
- 不符合用户预期，每个科目应该从1开始编号
- 影响用户对题目数量的理解

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/QuestionList.vue`：题目列表组件
- **涉及模块**：
  - 题目序号计算模块：`getQuestionOriginalIndex` 函数
  - 题目过滤模块：`filteredQuestions` 和 `displayList` 计算属性

## 技术原因 (❌)
1. 原因1：`getQuestionOriginalIndex` 函数使用 `questions.value.findIndex`，而 `questions.value` 包含所有学科的题目
2. 原因2：当先加载全部学科再切换科目时，`questions.value` 仍然包含所有题目
3. 原因3：在全部题目列表中查找生物题目的索引，会得到136（因为前面有135个数学题目）

```typescript
// ❌ 错误的实现：在全部题目列表中查找索引
const getQuestionOriginalIndex = (questionId: string): number => {
  // 问题：questions.value 包含所有学科的题目
  // 当切换科目时，这个列表仍然包含所有题目
  return questions.value.findIndex((q) => q.id === questionId)
}
```

```vue
<!-- ❌ 模板中使用错误的索引 -->
<div class="question-number">
  题目{{ getQuestionOriginalIndex(question.id) + 1 }}
  <!-- 问题：当切换科目时，这个索引是在全部题目列表中的索引 -->
  <!-- 例如：生物题目在全部列表中是第136个，所以显示"题目136" -->
</div>
```

## 正确实现方案 (✅)
1. 方案1：直接使用模板中的 `index` 变量，因为 `v-for` 已经提供了当前显示列表中的索引
2. 方案2：如果需要计算索引，应该使用 `displayList.value.findIndex`，而不是 `questions.value.findIndex`

```vue
<!-- ✅ 方案1：直接使用模板中的 index -->
<div
  v-for="(question, index) in displayedQuestions"
  :key="question.id"
>
  <div class="question-number">
    题目{{ index + 1 }}
    <!-- ✅ 正确：index 是当前显示列表中的索引，每个科目都从0开始 -->
  </div>
</div>
```

```typescript
// ✅ 方案2：如果需要单独计算，使用 displayList
const getQuestionDisplayIndex = (questionId: string): number => {
  // ✅ 正确：在过滤后的显示列表中查找索引
  return displayList.value.findIndex((q) => q.id === questionId)
}
```

```vue
<!-- ✅ 方案2的模板使用 -->
<div class="question-number">
  题目{{ getQuestionDisplayIndex(question.id) + 1 }}
</div>
```

## 关键代码/公式
- **索引计算原则**：应该基于当前显示的列表计算索引，而不是原始的全部列表
- **模板变量利用**：充分利用 Vue 模板中的 `index` 变量，避免不必要的计算

```typescript
// 关键逻辑：displayList 是过滤后的列表
const displayList = computed(() => {
  return filteredQuestions.value  // 已经根据科目过滤
})

// 在过滤后的列表中查找索引
const index = displayList.value.findIndex((q) => q.id === questionId)
```

## 测试验证
- **测试场景**：
  - 场景1：加载全部学科，验证题号连续
  - 场景2：切换到数学，验证题号从1开始
  - 场景3：切换到生物，验证题号从1开始（不是从136开始）
  - 场景4：搜索过滤题目，验证题号仍然正确
- **验证方法**：
  - 方法1：观察题目序号显示是否正确
  - 方法2：检查不同科目切换后序号是否都从1开始
  - 方法3：验证搜索过滤后序号是否正确

## 预防措施
- 措施1：计算索引时，应该基于当前显示的列表，而不是原始的全部列表
- 措施2：充分利用模板中的 `index` 变量，避免不必要的计算函数
- 措施3：在切换科目或过滤时，确保索引计算逻辑正确

## 可复用经验
- 经验1：索引计算应该基于当前显示的数据，而不是原始的全部数据
- 经验2：充分利用 Vue 模板提供的变量（如 `index`），避免重复计算
- 经验3：在过滤、搜索等操作后，要确保索引计算逻辑仍然正确
- 经验4：切换数据源时，要检查所有依赖该数据源的索引计算
