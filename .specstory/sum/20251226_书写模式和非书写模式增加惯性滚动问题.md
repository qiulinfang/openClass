问题序号：书写模式和非书写模式增加惯性滚动问题

## 问题元信息
- **问题分类**：`前端/交互体验`
- **严重程度**：`中`
- **影响范围**：`PDF阅读器移动端交互体验，影响页面浏览流畅度`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在PDF阅读器中：
- 单指滑动后页面立即停止，没有惯性滚动效果
- 无论是书写模式还是非书写模式，都缺乏流畅的滚动体验
- 移动端浏览体验与原生应用有差距

## 复现步骤
1. 步骤1：打开PDF阅读器，切换到不同模式
2. 步骤2：用单指快速滑动页面
3. 步骤3：观察手指离开后页面的滚动行为

## 用户体验
- 影响点1：滚动停止过于 abrupt，缺乏自然感
- 影响点2：移动端浏览体验不够流畅
- 影响点3：需要频繁滑动来浏览长文档

## 相关文件/模块
- **涉及文件**：
  - `index.html`：PDF阅读器惯性滚动实现
- **涉及模块**：
  - 滚动物理引擎：速度计算和衰减逻辑
  - 模式管理：书写模式和浏览模式的区分
  - 边界处理：滚动边界和反弹效果

## 技术原因 (❌)
1. 原因1：**缺少惯性滚动实现**
   - 手指离开后直接停止，没有物理动画
   - 没有速度追踪和衰减计算

2. 原因2：**模式区分逻辑不完善**
   - 书写模式和平移模式的惯性触发条件不清
   - 没有根据操作类型智能启用惯性

3. 原因3：**物理参数缺失**
   - 没有摩擦力系数和速度阈值
   - 缺乏边界反弹和速度衰减的物理计算

错误示例：
```typescript
// ❌ 直接停止，没有惯性
const onPointerUp = (e) => {
  activePointers.delete(e.pointerId);
  if (activePointers.size === 0) {
    // 直接结束，没有惯性动画
    endDrawing();
  }
};
```

## 正确实现方案 (✅)
1. 方案1：**实现物理惯性滚动**
   - 追踪手指滑动速度
   - 使用摩擦力模拟自然衰减

2. 方案2：**智能模式区分**
   - 书写模式下只在非绘制操作时启用惯性
   - 非书写模式下始终启用惯性

3. 方案3：**完整的物理引擎**
   - 速度计算、摩擦衰减、边界处理
   - 使用 requestAnimationFrame 实现流畅动画

正确示例：
```typescript
// ✅ 物理惯性滚动实现
let velocity = { x: 0, y: 0 };
let rafId = null;
const FRICTION = 0.95;

const applyInertia = () => {
  if (Math.abs(velocity.x) < 0.1 && Math.abs(velocity.y) < 0.1) {
    stopInertia();
    return;
  }
  
  offset.value.x += velocity.x;
  offset.value.y += velocity.y;
  
  // 应用边界限制
  clampOffset();
  
  velocity.x *= FRICTION;
  velocity.y *= FRICTION;
  
  rafId = requestAnimationFrame(applyInertia);
};

const startInertiaAnimation = () => {
  if (rafId) return;
  rafId = requestAnimationFrame(applyInertia);
};
```

## 关键代码/公式
- 代码片段1：速度追踪逻辑
```typescript
// 在移动过程中计算速度
const onPointerMove = (e) => {
  // ... 其他逻辑 ...
  
  const now = Date.now();
  const dx = e.clientX - lastPointerPos.x;
  const dy = e.clientY - lastPointerPos.y;
  
  const dt = now - lastTouchTime;
  if (dt > 0) {
    velocity.x = dx;
    velocity.y = dy;
  }
  
  lastPointerPos = { x: e.clientX, y: e.clientY };
  lastTouchTime = now;
};
```

- 代码片段2：智能惯性触发
```typescript
// 根据模式和操作类型决定是否启用惯性
const onPointerUp = (e) => {
  activePointers.delete(e.pointerId);
  
  if (activePointers.size === 0) {
    endDrawing();
    
    // 智能判断是否启用惯性
    const shouldApplyInertia = 
      !isDrawing.value || // 非书写模式
      isPanningInDrawMode; // 书写模式下的平移操作
    
    if (shouldApplyInertia) {
      startInertiaAnimation();
    }
  }
};
```

```typescript
// 摩擦力衰减公式
const FRICTION = 0.95; // 摩擦系数
```
