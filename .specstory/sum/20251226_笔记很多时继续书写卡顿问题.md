问题序号：笔记很多时继续书写卡顿问题

## 问题元信息
- **问题分类**：`前端/性能`
- **严重程度**：`高`
- **影响范围**：`PDF阅读器笔记功能，笔记数量多时书写体验严重下降`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在PDF阅读器中：
- 当页面上已经有大量笔记时，继续书写新笔记会出现明显的卡顿
- 书写过程不流畅，笔迹出现延迟和断续
- 帧率显著下降，影响书写体验

## 复现步骤
1. 步骤1：打开PDF阅读器，在页面上绘制大量笔记
2. 步骤2：继续在有笔记的区域书写新的笔记
3. 步骤3：观察书写过程中的流畅度和响应速度

## 用户体验
- 影响点1：书写不跟手，笔迹出现延迟
- 影响点2：大量笔记时无法流畅记录新内容
- 影响点3：严重影响笔记功能的可用性

## 相关文件/模块
- **涉及文件**：
  - `index.html`：PDF阅读器笔记绘制实现
- **涉及模块**：
  - Canvas 渲染系统：笔记绘制和重绘逻辑
  - 事件处理系统：pointermove 事件处理
  - 性能优化系统：绘制策略和缓存机制

## 技术原因 (❌)
1. 原因1：**全量重绘策略**
   - 每次 pointermove 都调用 drawAllPaths() 重绘所有笔记
   - 随着笔记数量增加，重绘开销呈线性增长

2. 原因2：**Canvas 清空重绘模式**
   - 每次绘制都执行 ctx.clearRect() 清空整个画布
   - 然后重新绘制所有历史笔记 + 当前笔迹

3. 原因3：**事件处理频率过高**
   - 高频的 pointermove 事件触发重绘
   - 没有有效的节流或合并机制

错误示例：
```typescript
// ❌ 全量重绘策略
const onPointerMove = (e) => {
  // 每次移动都重绘所有内容
  events.forEach(ev => {
    currentPath.value.push({ x: loc.x, y: loc.y });
    drawAllPaths(); // O(n) 复杂度，n为笔记总数
  });
};

const drawAllPaths = () => {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // 清空画布
  paths.value.forEach(path => drawSinglePath(ctx, path)); // 重绘所有
  if (currentPath.value) drawSinglePath(ctx, currentPath.value);
};
```

## 正确实现方案 (✅)
1. 方案1：**增量绘制策略**
   - 只绘制新增的笔迹线段，不清空画布
   - 历史笔记保持不动，只追加新内容

2. 方案2：**局部重绘优化**
   - 区分历史笔记和当前绘制笔记
   - 当前笔记使用增量绘制，历史笔记保持静态

3. 方案3：**智能重绘触发**
   - 只在必要时进行全量重绘（如缩放结束、笔记删除）
   - 书写过程中使用增量更新

正确示例：
```typescript
// ✅ 增量绘制策略
const drawIncremental = (pageIndex, points) => {
  const canvas = inkRefs.value[pageIndex];
  if (!canvas || points.length < 2) return;
  
  const ctx = canvas.getContext('2d');
  // 不清空画布，直接在现有内容上追加绘制
  drawSingleSegment(ctx, points); // 只绘制最新线段
};

// 只在特定时机全量重绘
const redrawAllPagesInk = () => {
  inkRefs.value.forEach((_, idx) => redrawPageInk(idx));
```

## 关键代码/公式
- 代码片段1：增量绘制逻辑
```typescript
// 只绘制新增线段，不清空历史内容
const drawIncremental = (pageIndex, points) => {
  if (points.length < 2) return;
  
  const i = points.length - 2;
  const p1 = points[i];
  const p2 = points[i + 1];
  
  // 计算贝塞尔曲线控制点并绘制
  const midX = (p1.x + p2.x) / 2;
  const midY = (p1.y + p2.y) / 2;
  
  ctx.beginPath();
  ctx.moveTo(p1.x * QUALITY, p1.y * QUALITY);
  ctx.quadraticCurveTo(
    p1.x * QUALITY, p1.y * QUALITY,
    midX * QUALITY, midY * QUALITY
  );
  ctx.stroke();
};
```
