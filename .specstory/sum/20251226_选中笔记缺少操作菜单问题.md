# 问题序号：选中笔记缺少操作菜单问题

## 问题元信息
- **问题分类**：前端/UI
- **严重程度**：中
- **影响范围**：笔记编辑功能，影响用户对选中笔记的操作体验
- **发现日期**：2025-12-26
- **解决状态**：已解决

## 问题现象
用户选中笔记后没有任何操作菜单，无法进行复制、删除等操作，严重影响用户体验。

## 复现步骤
1. 步骤1：在Canvas上绘制一些笔迹
2. 步骤2：切换到选择模式，选中一个或多个笔迹
3. 步骤3：观察到没有出现任何操作菜单

## 用户体验
- 影响点1：无法对选中笔记进行任何操作
- 影响点2：用户不知道如何删除不需要的笔迹
- 影响点3：功能不完整，用户体验不佳

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/drawingBoardNew.vue`：Canvas绘制组件
- **涉及模块**：
  - 笔记选择系统：负责选中状态管理和UI反馈

## 技术原因 (❌)
缺少操作菜单的UI组件和相关逻辑：

1. **缺少菜单UI**：没有实现选中状态下的操作菜单
2. **缺少事件处理**：没有实现复制和删除功能的处理逻辑
3. **缺少状态计算**：没有计算菜单显示位置和显示条件

❌ **错误代码示例：**
```vue
<template>
  <!-- ❌ 缺少操作菜单 -->
  <canvas ref="canvasRef" />
</template>
```

## 正确实现方案 (✅)
添加完整的操作菜单UI和功能：

1. **添加菜单UI组件**：在选中状态下显示操作菜单
2. **实现菜单定位**：根据选中笔迹位置智能定位菜单
3. **实现功能逻辑**：添加复制和删除功能的完整实现
4. **状态管理优化**：使用computed属性管理菜单显示状态

✅ **正确代码示例：**
```vue
<template>
  <!-- 笔记操作菜单 -->
  <div
    v-if="showActionsMenu"
    class="note-actions-menu"
    :style="{
      left: actionsMenuPosition.x + 'px',
      top: actionsMenuPosition.y + 'px'
    }"
  >
    <button @click="copySelectedStrokes">复制</button>
    <button @click="deleteSelectedStrokes">删除</button>
  </div>
</template>

<script setup>
// 菜单显示条件
const showActionsMenu = computed(() => {
  return selectedIndices.size > 0 && currentMode.value === 'select'
})

// 菜单位置计算
function updateActionsMenuPosition() {
  if (selectedIndices.size > 0) {
    const bounds = getGroupBounds(selectedIndices)
    if (bounds) {
      const screenPos = worldToScreen(bounds.minX, bounds.minY)
      actionsMenuPosition.x = screenPos.x + 10
      actionsMenuPosition.y = screenPos.y - 50
    }
  }
}
</script>
```

## 关键代码/公式
**菜单定位算法：**
```typescript
// 根据选中笔迹边界计算菜单位置
const bounds = getGroupBounds(selectedIndices) // 获取选中笔迹的包围盒
const screenPos = worldToScreen(bounds.minX, bounds.minY) // 转换到屏幕坐标
actionsMenuPosition.x = screenPos.x + 10 // 水平偏移10px
actionsMenuPosition.y = screenPos.y - 50 // 垂直向上偏移50px
```
