问题序号：Node版本不满足Vite要求导致无法启动开发服务问题

## 问题元信息
- **问题分类**：`兼容性`
- **严重程度**：`高`
- **影响范围**：`imates-web 本地开发与调试`
- **发现日期**：`2025-12-26`
- **解决状态**：`待解决`

## 问题现象
执行 `npm run dev` / `npm run dev:test` 时直接退出，提示 Node 版本不符合 Vite 运行要求。

## 复现步骤
1. 使用 Node.js `22.11.0`。
2. 在 `imates-web` 目录执行 `npm run dev`。
3. 输出：Vite requires Node.js version `20.19+` or `22.12+`。

## 用户体验
- 无法启动本地开发服务器，阻塞所有前端调试与验证。

## 相关文件/模块
- **涉及模块**：
  - 构建工具：Vite
  - 运行环境：Node.js

## 技术原因 (❌)
1. Vite 对 Node 版本有最低要求，当前环境 `22.11.0` 小于 `22.12.0`。

## 正确实现方案 (✅)
1. 升级 Node 到满足要求的版本：
   - `22.12+`（同大版本升级）或
   - `20.19+`（LTS 线）
2. 团队建议使用版本管理工具（如 nvm-windows）锁定 Node 版本，并在项目文档中标注。

## 关键代码/公式
无。

## 测试验证
- **测试场景**：升级 Node 后运行 `npm run dev`。
- **验证方法**：
  - dev server 正常启动
  - 页面可访问且热更新正常

## 预防措施
- 在 README/开发规范中明确 Node 版本区间。
- CI 增加 node 版本检查，避免环境漂移。
