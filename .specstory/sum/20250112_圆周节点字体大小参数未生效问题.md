# 问题序号：圆周节点字体大小参数未生效问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`低`
- **影响范围**：`知识图谱调试面板功能，无法通过参数调整圆周节点标题字体大小`
- **发现日期**：`2025-01-12`
- **解决状态**：`已解决`

## 问题现象
在 `KnowledgeGraphView.vue` 中定义了 `circularNodeFontSize` 参数（默认值为 1.2），用于调整圆周节点标题的字体大小。但在实际运行时，修改该参数值后，圆周节点标题的字体大小并未发生变化，参数未生效。

## 复现步骤
1. 步骤1：打开知识图谱页面，进入调试面板
2. 步骤2：找到 `circularNodeFontSize` 参数，修改其值（例如从 1.2 改为 1.5）
3. 步骤3：观察圆周节点标题的字体大小，发现没有变化

## 用户体验
- 影响点1：调试面板中的 `circularNodeFontSize` 参数无法正常工作，影响调试体验
- 影响点2：无法通过参数动态调整圆周节点标题的字体大小，限制了自定义能力
- 影响点3：参数定义与实际效果不一致，造成困惑

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/KnowledgeGraphView.vue`：定义了 `circularNodeFontSize` 参数
  - `imates-web/src/components/knowledge-graph/GraphNode.vue`：圆周节点标题样式定义，未使用该参数
- **涉及模块**：
  - 知识图谱组件：圆周节点渲染和样式控制
  - 调试面板：参数配置和传递

## 技术原因 (❌)
1. **CSS 变量未定义**：在 `GraphNode.vue` 的 `nodeStyleVariables` computed 属性中，没有定义 `--circular-node-font-size` CSS 变量，导致参数值无法传递到样式层
2. **样式硬编码**：圆周节点标题的字体大小在 CSS 中硬编码为 `1.2rem`，没有使用 CSS 变量
3. **收缩状态未关联**：当圆周节点处于收缩状态（`node-content--shrunk`）时，字体大小也是硬编码的 `0.875rem`，未与参数关联

## 正确实现方案 (✅)
1. **添加 CSS 变量定义**：在 `nodeStyleVariables` computed 属性中添加 `--circular-node-font-size` 变量，从 `debugParams` 中读取 `circularNodeFontSize` 参数值（默认 1.2rem）
2. **更新正常状态样式**：将 `.node-content--circular .node-title` 的 `font-size` 改为使用 `var(--circular-node-font-size, 1.2rem)`
3. **更新收缩状态样式**：将 `.node-content--circular.node-content--shrunk .node-title` 的 `font-size` 改为使用 `calc(var(--circular-node-font-size, 1.2rem) * 0.729)`，保持约为正常状态的 73% 比例

**正确代码示例**：

```214:227:imates-web/src/components/knowledge-graph/GraphNode.vue
// 计算所有 CSS 变量值
const nodeStyleVariables = computed(() => {
  const params = debugParams?.value
  return {
    '--node-animation-duration': `${params?.nodeEnterExitDuration ?? 0.6}s`,
    '--node-base-transition-duration': `${params?.nodeBaseTransitionDuration ?? 0.3}s`,
    '--node-content-transition-duration': `${params?.nodeContentTransitionDuration ?? 0.3}s`,
    '--node-active-transition-duration': `${params?.nodeActiveTransitionDuration ?? 0.1}s`,
    '--learning-tag-transition-duration': `${params?.learningTagTransitionDuration ?? 0.3}s`,
    '--bubble-button-transition-duration': `${params?.bubbleButtonTransitionDuration ?? 0.2}s`,
    '--circular-node-radius': `${params?.circularNodeRadius ?? 100}px`,
    '--circular-node-font-size': `${params?.circularNodeFontSize ?? 1.2}rem` // ✅ 添加字体大小变量
  }
})
```

## 关键代码/公式
- **CSS 变量定义**：`'--circular-node-font-size': \`${params?.circularNodeFontSize ?? 1.2}rem\``
  - 从 `debugParams` 读取 `circularNodeFontSize` 参数，默认值为 1.2rem
- **正常状态字体大小**：`font-size: var(--circular-node-font-size, 1.2rem)`
  - 使用 CSS 变量，提供默认值作为后备
- **收缩状态字体大小**：`font-size: calc(var(--circular-node-font-size, 1.2rem) * 0.729)`
  - 使用 `calc()` 函数计算，保持约为正常状态的 73% 比例（0.875 / 1.2 ≈ 0.729）

## 预防措施
- 措施1：**统一使用 CSS 变量**：所有可通过调试参数调整的样式属性都应使用 CSS 变量，避免硬编码
- 措施2：**参数与变量映射检查**：在代码审查时，检查所有定义的调试参数是否都有对应的 CSS 变量定义
