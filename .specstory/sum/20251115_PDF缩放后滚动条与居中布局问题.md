问题序号：PDF缩放后滚动条与居中布局问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`PDF 阅读页在 Web / Android WebView 中的布局与滚动体验`
- **发现日期**：`2025-11-15`
- **解决状态**：`已解决`

## 问题现象
1. 当 PDF 放大到很大时：
   - `pdf-page` 容器已经出现横向滚动条，但将滚动条拖到最左侧时，canvas 的最左侧仍未真正贴到容器左边，存在“错位感”。
2. 当 PDF 缩放到最小时：
   - PDF 内容没有居中显示，而是贴在 `pdf-page` 的左侧，flex 居中也无法解决视觉上的居中问题。
3. 在一度尝试使用 `transform: scale` 直接作用于单层容器时：
   - flex 居中的是“未缩放的 DOM 盒子”，而不是缩放后可见的内容，导致视觉居中与滚动行为不一致。

## 复现步骤
1. 打开 `pdfpage.vue` 所在的 PDF 阅读页。
2. 执行以下操作：
   1. 将 PDF 放大到最大（例如 `scale = 4.0`），然后拖动横向滚动条到最左：
      - 观察 PDF 左边是否真正贴近 `pdf-page` 左边界。
   2. 将 PDF 缩放到最小（例如 `scale = 0.25`）：
      - 观察内容是否处于 `pdf-page` 的水平中心位置，或仍然靠左。

## 用户体验
- 放大时：滚动条位置与真正内容位置不匹配，用户难以判断是否已经滚到“最左/最右”。
- 缩小时：整页 PDF 没有居中，显得“不对称”，影响阅读舒适度。
- 对触摸和滚动的结合体验带来困惑，尤其是在大屏和平板上体验不佳。

## 相关文件/模块
- **涉及文件**：
  - `src/components/pdfpage.vue`：PDF 阅读页核心组件，包含渲染布局、缩放和滚动逻辑。
- **涉及模块**：
  - PDF 渲染容器层（原 `viewerContainer`）。
  - 滚动容器 `pdf-page`。

## 技术原因 (❌)
1. 使用 `transform: scale` 直接作用于单层 `viewerContainer`：
   - DOM 盒子的 `width/height` 不随 `scale` 改变，仅视觉变换。
   - 横向滚动条基于 DOM 的 `scrollWidth`，而不是视觉宽度，导致滚动条极值与视觉边界不一致。
2. 初始实现中通过 margin 或 flex 试图做居中：
   ```typescript
   const viewerContainerStyle = computed(() => ({
     width: `${maxWidth.value}px`,
     minHeight: `${totalHeight.value}px`,
     margin: '0 auto',
     position: 'relative' as const,
     transform: `scale(${store.scale})`,
     transformOrigin: 'top center',
   }))
   ```
   - `margin: 0 auto` 是基于未缩放的 `width` 做居中；
   - 缩放后视觉宽度 < 容器宽度时，内容看似仍贴左侧或中心偏移。
3. 为了撑大滚动区域引入了 `scroll-size-helper` 占位 div：
   ```typescript
   <div
     class="scroll-size-helper"
     :style="{
       position: 'absolute',
       top: '0',
       left: '50%',
       transform: 'translateX(-50%)',
       width: maxWidth * store.scale + 'px',
       height: totalHeight * store.scale + 'px',
     }"
   />
   ```
   - 该占位元素最初是居中的（left + translateX），导致滚动条的极值与真正内容左边界对不齐。

## 正确实现方案 (✅)
1. 校正滚动条与内容左边界对齐：
   - 将 `scroll-size-helper` 改为左上角对齐：
   ```typescript
   <div
     class="scroll-size-helper"
     :style="{
       position: 'absolute',
       top: '0',
       left: '0',
       width: maxWidth * store.scale + 'px',
       height: totalHeight * store.scale + 'px',
     }"
   />
   ```
   - 并将每页的 `margin: 0 auto` 改为 `margin-bottom`，确保页面左对齐：
   ```typescript
   const getPageStyle = (layout) => ({
     position: 'relative' as const,
     width: `${layout.width}px`,
     height: `${layout.height}px`,
     margin: `0 0 ${store.pageGap}px`,
   })
   ```
2. 拆分容器为“外层布局 + 内层缩放”：
   - 外层容器 `viewerOuterStyle`：负责滚动区域和水平居中逻辑，宽高按缩放后视觉尺寸计算：
   ```typescript
   const containerWidth = ref(0)

   const viewerOuterStyle = computed(() => {
     const scale = store.scale
     const visualWidth = maxWidth.value * scale
     const visualHeight = totalHeight.value * scale

     let paddingLeft = 0
     if (containerWidth.value > 0 && visualWidth < containerWidth.value) {
       paddingLeft = (containerWidth.value - visualWidth) / 2
     }

     return {
       position: 'relative' as const,
       width: `${visualWidth}px`,
       minHeight: `${visualHeight}px`,
       paddingLeft: `${paddingLeft}px`,
     }
   })
   ```
   - 内层容器 `viewerInnerStyle`：只负责视觉缩放：
   ```typescript
   const viewerInnerStyle = computed(() => ({
     width: `${maxWidth.value}px`,
     minHeight: `${totalHeight.value}px`,
     position: 'relative' as const,
     transform: `scale(${store.scale})`,
     transformOrigin: 'top left',
   }))
   ```
   - 模板结构：
   ```vue
   <div ref="viewerContainer" :style="viewerOuterStyle">
     <div class="viewer-inner" :style="viewerInnerStyle">
       <div
         v-for="(layout, index) in pageLayouts"
         :key="index"
         class="page"
         :style="getPageStyle(layout)"
       >
         <canvas :ref="(el) => setPageCanvasRef(el, index)" class="page-canvas" />
       </div>
     </div>
   </div>
   ```
3. 结合 flex 布局统一控制：
   - `pdf-page` 使用 flex 将 `viewerContainer`（外层容器）整体水平居中，同时允许内容溢出产生滚动条：
   ```css
   .pdf-page {
     display: flex;
     justify-content: center;   /* 水平居中 viewerContainer */
     align-items: flex-start;   /* 顶部对齐 */
     width: 100%;
     height: 100%;
     overflow: auto;
   }
   ```

## 关键代码/公式
- 缩放后视觉宽度：`visualWidth = maxWidth * scale`
- 居中偏移（当视觉宽度小于容器宽度时）：
  - `paddingLeft = (containerWidth - visualWidth) / 2`

## 测试验证
- **测试场景**：
  - 场景1：放大到最大并横向滚动到最左。
    - 预期：PDF 左边界与 `pdf-page` 左边界对齐，无可见空隙。
  - 场景2：缩放到最小。
    - 预期：PDF 内容横向居中显示，不再贴左或偏移。
  - 场景3：连续放大/缩小 + 滚动。
    - 预期：滚动条极值与视觉边界一致，缩放中心行为合理。
- **验证方法**：
  - 在桌面浏览器和 Android WebView 中分别验证以上场景，比较缩放前后内容位置是否符合预期。

## 预防措施
- 在使用 `transform: scale` 时，清晰区分“视觉尺寸”和“DOM 尺寸”，避免直接依赖 transform 后的视觉结果做布局判断。
- 对需要精确滚动条行为的场景，优先把“撑开滚动区域”的逻辑独立出来（如外层容器 + 哨兵元素），避免使用居中+scale 的混合方案导致错位。
- 如需实现复杂缩放+滚动逻辑，优先设计好容器层级：滚动层、缩放层、内容层的职责要明确分离。

## 可复用经验
- 对于 PDF / 大画布类内容，推荐采用“外层滚动 + 内层缩放”的两层容器结构，便于同时控制缩放、滚动和居中。
- 在多端（Web + WebView）场景中，尽量避免依赖浏览器默认的缩放和滚动行为，改为显式管理滚动区域和视觉缩放。
- 把复杂布局问题总结成“坐标系 + 容器层级 + 视觉变换”的组合思路，更容易定位和修复类似问题。
