问题序号：2 作业套餐学科字段来源与定义说明

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`低`
- **影响范围**：`题库详情页 / 作业套餐发布`
- **发现日期**：`2025-12-10`
- **解决状态**：`已解决`

## 问题现象
发布作业套餐时需要传入 `subject` 字段，但前端只是在调试日志中输出 `subjectId`，未说明其具体值与来源，导致后续排查与接口对齐困难。

## 复现步骤
1. 进入题库详情页（`Details.vue`），选中任意题目。
2. 点击「发布」并在弹窗中确认发布。
3. 查看控制台日志和接口请求，发现 `subject` 直接等于某个数字 ID，且缺少解释。

## 用户体验
- 研发人员无法快速判断该 ID 对应的学科。
- 新人接手发布功能时需要反复查代码确认来源。

## 相关文件/模块
- **涉及文件**：
  - `研伴-前端/src/views/exercises/questionBank/Details.vue`：发布逻辑与 `subjectId` 赋值。
- **涉及模块**：
  - 题库详情页、作业套餐发布 API。

## 技术原因 (❌)
1. `subjectId` 仅在页面状态中保存，缺少明确注释与说明。
2. 未在文档中记录「题目 subject 字段 = 学科 ID」的约定。

错误示例（缺少说明）：
```ts
let param = {
  subject: subjectId.value,
  ...
}
```

## 正确实现方案 (✅)
1. 明确 `subjectId` 的来源：始终读取题目记录的 `subject` 字段，并在文档中说明这是后端定义的学科枚举 ID。
2. 在需要时通过字典接口或常量表将 ID 映射为名称（供 UI 展示、调试）。

正确示例：
```ts
const updateDetail = (row) => {
  subjectId.value = row.subject; // 题目内置的学科 ID
};

const confirmPublish = () => {
  const param = {
    subject: subjectId.value, // 直接透传当前题目的学科 ID
    ...
  };
  questionBankAPI.package_save(param);
};
```

## 关键代码/公式
- `updateDetail` 更新当前题目详情并写入 `subjectId` @/研伴-前端/src/views/exercises/questionBank/Details.vue#222-230
- `confirmPublish` 中将 `subjectId` 作为 `subject` 传给 `package_save` @/研伴-前端/src/views/exercises/questionBank/Details.vue#66-99

## 测试验证
- **测试场景**：
  - 场景1：切换不同学科的题目后发布，确认 `subject` 跟随题目变化。
  - 场景2：接口返回的 `subject` 为空或异常时，前端应阻止发布并提示。
- **验证方法**：
  - 方法1：抓包校验 `subject` 数值是否与题目记录一致。
  - 方法2：对照后端学科枚举，手动核验映射关系。

## 预防措施
- 在代码和文档中标注字段含义，减少后续重复确认。
- 如需学科名称展示，统一引用后端字典接口或常量表。
