问题序号：知识图谱指示器渐变透明度效果实现

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`低`
- **影响范围**：`知识图谱视图中的指示器显示效果`
- **发现日期**：`2025-01-12`
- **解决状态**：`已解决`

## 问题现象
知识图谱视图右边框中心位置的指示器（indicator-dot）在激活状态下，所有非激活的指示器显示效果相同，缺乏视觉层次感。用户希望实现渐变透明度效果，让距离激活指示器越远的指示器透明度越高（越不清晰），同时大小也根据距离动态调整，以增强视觉引导效果。

## 复现步骤
1. 步骤1：打开知识图谱视图
2. 步骤2：选择一个章节，查看右边框的指示器
3. 步骤3：点击任意一个指示器激活对应的图谱
4. 步骤4：观察非激活指示器的显示效果
5. 问题表现：所有非激活指示器的透明度和大小相同，缺乏距离感的视觉反馈

## 用户体验
- 影响点1：用户无法直观地感知当前激活指示器与其他指示器的相对位置关系
- 影响点2：缺乏视觉层次感，所有指示器看起来同等重要
- 影响点3：视觉引导效果不足，用户难以快速理解指示器的位置关系

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/KnowledgeGraphView.vue`：知识图谱视图组件，包含指示器的渲染逻辑和样式定义
- **涉及模块**：
  - 指示器渲染模块：负责渲染右边框中心位置的指示器列表
  - 样式计算模块：负责计算指示器的透明度和大小

## 技术原因 (❌)
（此问题为功能增强需求，非bug修复）

1. **缺少动态透明度计算**：指示器组件没有根据距离激活指示器的位置动态计算透明度
2. **缺少动态大小计算**：指示器组件没有根据距离激活指示器的位置动态计算大小
3. **样式绑定不完整**：模板中只绑定了 `active` 类，没有绑定动态的 `opacity`、`width` 和 `height` 样式
4. **CSS 固定尺寸**：CSS 中使用了固定的宽度和高度，无法实现动态大小变化

## 正确实现方案 (✅)
1. **添加透明度计算函数**：创建 `getIndicatorOpacity` 函数，根据指示器距离激活指示器的距离计算透明度
2. **添加大小计算函数**：创建 `getIndicatorSize` 函数，根据指示器距离激活指示器的距离计算大小
3. **更新模板绑定**：在模板中为每个指示器添加动态样式绑定，包括 `opacity`、`width` 和 `height`
4. **优化 CSS 样式**：移除固定的宽度和高度，改为通过内联样式动态设置，同时增强激活状态的视觉效果

## 关键代码/公式

### 透明度计算函数
```typescript
// 计算指示器的透明度，基于距离激活指示器的距离
const getIndicatorOpacity = (subChapterId: string, index: number) => {
  const subChapters = getSubChapters(selectedChapterDetails.value)
  const currentExpandedGraph = getCurrentChapterExpandedGraph()
  
  // 如果没有激活的图谱，所有指示器使用较低透明度
  if (!currentExpandedGraph) {
    return 0.3
  }
  
  // 找到激活指示器的索引
  const activeIndex = subChapters.findIndex(chapter => chapter.id === currentExpandedGraph)
  if (activeIndex === -1) {
    return 0.3
  }
  
  // 计算距离激活指示器的距离
  const distance = Math.abs(index - activeIndex)
  const totalChapters = subChapters.length
  
  // 激活的指示器完全不透明
  if (distance === 0) {
    return 1
  }
  
  // 根据距离计算透明度：距离越远，透明度越低
  // 使用更明显的线性衰减，让距离效果更清晰
  // 最远的指示器透明度最低（约0.2），最近的指示器透明度较高
  const maxDistance = Math.max(activeIndex, totalChapters - 1 - activeIndex)
  if (maxDistance === 0) {
    return 1
  }
  
  // 线性衰减：从1（激活）到0.2（最远）
  const opacity = Math.max(0.2, 1 - (distance / maxDistance) * 0.8)
  return opacity
}
```

### 大小计算函数
```typescript
// 计算指示器的大小，基于距离激活指示器的距离
const getIndicatorSize = (subChapterId: string, index: number) => {
  const subChapters = getSubChapters(selectedChapterDetails.value)
  const currentExpandedGraph = getCurrentChapterExpandedGraph()
  
  // 如果没有激活的图谱，所有指示器使用默认大小
  if (!currentExpandedGraph) {
    return 14
  }
  
  // 找到激活指示器的索引
  const activeIndex = subChapters.findIndex(chapter => chapter.id === currentExpandedGraph)
  if (activeIndex === -1) {
    return 14
  }
  
  // 激活的指示器最大
  if (index === activeIndex) {
    return 24
  }
  
  // 计算距离激活指示器的距离
  const distance = Math.abs(index - activeIndex)
  const maxDistance = Math.max(activeIndex, subChapters.length - 1 - activeIndex)
  
  // 根据距离计算大小：距离越远，大小越小
  const size = 14 + (10 * (1 - distance / maxDistance))
  return Math.max(14, Math.min(24, size))
}
```

### 模板更新
```vue
<div 
  v-for="(subChapter, index) in getSubChapters(selectedChapterDetails)" 
  :key="subChapter.id"
  class="indicator-dot"
  :class="{ 'active': getCurrentChapterExpandedGraph() === subChapter.id }"
  :style="{
    opacity: getIndicatorOpacity(subChapter.id, index),
    width: `${getIndicatorSize(subChapter.id, index)}px`,
    height: `${getIndicatorSize(subChapter.id, index)}px`
  }"
  @click="handleIndicatorClick(subChapter.id)"
>
  <img 
    v-if="getCurrentChapterExpandedGraph() === subChapter.id" 
    :src="indicatorIcon"

    class="indicator-icon"
  />
</div>
```

### 透明度计算公式
```
opacity = max(0.2, 1 - (distance / maxDistance) * 0.8)
```
- `distance`：当前指示器距离激活指示器的距离（索引差值）
- `maxDistance`：激活指示器到两端的最远距离
- 结果范围：0.2（最远）到 1.0（激活）

### 大小计算公式
```
size = 14 + (10 * (1 - distance / maxDistance))
size = clamp(14, size, 24)
```
- `distance`：当前指示器距离激活指示器的距离（索引差值）
- `maxDistance`：激活指示器到两端的最远距离
- 结果范围：14px（最远）到 24px（激活）

## 预防措施
- 措施1：在实现动态样式效果时，优先考虑使用计算属性或函数，而不是硬编码值
- 措施2：对于需要根据相对位置计算样式的场景，应该考虑边界情况（如只有一个元素、激活元素在两端等）
- 措施3：在更新样式时，确保 CSS 过渡动画能够平滑地处理动态变化
- 措施4：移动端适配时，使用 `min-width` 和 `min-height` 而不是固定尺寸，确保触摸区域足够大

## 可复用经验
- 经验1：**距离衰减算法**：使用线性衰减公式 `value = max + (range * (1 - distance / maxDistance))` 可以实现平滑的距离效果，适用于透明度、大小、颜色等多种视觉属性
- 经验2：**动态样式绑定**：在 Vue 中，使用 `:style` 绑定计算函数可以实现响应式的样式变化，比纯 CSS 更灵活
- 经验3：**边界情况处理**：在计算距离相关的效果时，需要处理边界情况（如只有一个元素、激活元素在两端、没有激活元素等），确保计算逻辑的健壮性
- 经验4：**视觉层次设计**：通过透明度、大小、阴影等多维度视觉属性的组合，可以创建清晰的视觉层次，引导用户注意力
- 经验5：**过渡动画优化**：在实现动态样式变化时，使用 CSS `transition` 属性可以确保变化平滑，提升用户体验
