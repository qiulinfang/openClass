问题序号：缩放过程中笔记与PDF清晰度问题

## 问题元信息
- **问题分类**：`前端/渲染性能`
- **严重程度**：`中`
- **影响范围**：`PDF阅读器缩放功能，影响笔记和PDF内容的视觉质量`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在PDF阅读器中进行缩放操作时：
- 笔记（笔迹）和PDF内容在缩放过程中出现模糊
- 缩放到较大倍数时，线条和文字边缘出现锯齿
- 缩放动画不够平滑，影响视觉体验

## 复现步骤
1. 步骤1：打开PDF阅读器，绘制一些笔记
2. 步骤2：使用滚轮或双指进行缩放操作
3. 步骤3：观察缩放过程中笔记和PDF内容的清晰度变化

## 用户体验
- 影响点1：缩放时内容模糊，影响阅读和笔记查看体验
- 影响点2：大倍数查看时细节不清楚，影响精确标注
- 影响点3：缩放动画不流畅，影响交互体验

## 相关文件/模块
- **涉及文件**：
  - `index.html`：PDF阅读器实现
- **涉及模块**：
  - Canvas 渲染系统：PDF和笔记的绘制
  - 缩放控制系统：zoomAt 和双指缩放逻辑
  - DPR 自适应系统：设备像素比处理

## 技术原因 (❌)
1. 原因1：**渲染质量设置过低**
   - 使用固定的 RENDER_QUALITY = 2.0，但没有根据设备像素比调整
   - 在高DPI屏幕上仍可能出现模糊

2. 原因2：**缩放时重绘频率过高**
   - 双指缩放过程中频繁触发 redrawAllPagesInk()
   - 每次重绘都消耗大量计算资源

3. 原因3：**Canvas 物理尺寸未优化**
   - Canvas 的 width/height 属性没有根据缩放比例动态调整
   - 导致在不同缩放级别下的像素密度不匹配

错误示例：
```typescript
// ❌ 固定渲染质量，未考虑设备差异
const RENDER_QUALITY = 2.0; // 在普通屏幕上可能过度，在高DPI屏幕上可能不足

// ❌ 缩放过程中频繁重绘
const onPointerMove = (e) => {
  // ... 缩放逻辑 ...
  redrawAllPagesInk(); // 每帧都重绘，性能浪费
};
```

## 正确实现方案 (✅)
1. 方案1：**动态渲染质量调整**
   - 根据 window.devicePixelRatio 动态计算渲染质量
   - 确保在不同设备上都有合适的清晰度

2. 方案2：**优化缩放重绘策略**
   - 缩放过程中使用 CSS transform，避免 Canvas 重绘
   - 只在缩放结束时进行高质量重绘

3. 方案3：**Canvas 尺寸优化**
   - 使用更高的基础渲染质量（如 3.0）
   - 结合 CSS transform 实现平滑缩放

正确示例：
```typescript
// ✅ 动态质量调整
const RENDER_QUALITY = 3.0; // 提高基础质量

// ✅ 缩放时使用 CSS transform
const containerStyle = computed(() => ({
  transform: `translate(${offset.value.x}px, ${offset.value.y}px) scale(${scale.value})`
}));

// ✅ 只在缩放结束时重绘
const onPointerUp = (e) => {
  if (activePointers.size === 0) {
    // 缩放结束，执行高质量重绘
    redrawAllPagesInk();
  }
};
```

## 关键代码/公式
- 代码片段1：动态渲染质量计算
```typescript
// 基础质量 + 设备像素比适配
const baseQuality = 3.0;
const deviceQuality = window.devicePixelRatio || 1;
const finalQuality = Math.min(baseQuality * deviceQuality, 6.0);
```

- 代码片段2：CSS transform 缩放
```typescript
// 使用 CSS transform 实现硬件加速缩放
const containerStyle = computed(() => ({
  transform: `translate(${offset.x}px, ${offset.y}px) scale(${scale})`,
  willChange: 'transform'  // 优化硬件加速
}));
```

- 代码片段3：智能重绘策略
```typescript
// 双指缩放中不重绘，结束时重绘
if (activePointers.size === 2) {
  // 缩放逻辑，但不重绘
  scale.value = newScale;
  // CSS transform 会自动处理视觉效果
}

// 缩放结束后重绘
if (activePointers.size === 0) {
  redrawAllPagesInk(); // 高质量重绘
}
```
