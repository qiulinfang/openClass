# 问题序号：选中多个笔迹菜单不显示问题

## 问题元信息
- **问题分类**：前端/逻辑
- **严重程度**：中
- **影响范围**：笔记多选功能，影响批量操作体验
- **发现日期**：2025-12-26
- **解决状态**：已解决

## 问题现象
当用户选中多个笔迹时，操作菜单不显示，导致无法对多个笔迹进行批量操作。

## 复现步骤
1. 步骤1：在Canvas上绘制多条笔迹
2. 步骤2：使用选择工具选中多个笔迹
3. 步骤3：观察到操作菜单没有出现

## 用户体验
- 影响点1：无法批量删除多个不需要的笔迹
- 影响点2：多选功能形同虚设，用户体验不佳
- 影响点3：功能不完整，影响工作效率

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/drawingBoardNew.vue`：Canvas绘制组件
- **涉及模块**：
  - 笔记选择系统：多选状态管理和菜单显示逻辑

## 技术原因 (❌)
菜单显示逻辑依赖错误的边界计算：

1. **依赖全局边界变量**：`updateActionsMenuPosition()`依赖`groupBounds`全局变量
2. **边界计算时机错误**：`groupBounds`在`renderAll()`中更新，但菜单更新在选中时调用
3. **缺少自计算边界**：函数没有自己计算选中笔迹的边界

❌ **错误代码示例：**
```typescript
function updateActionsMenuPosition() {
  if (selectedIndices.size > 0 && groupBounds) { // ❌ 依赖全局变量，可能为null
    const screenPos = worldToScreen(groupBounds.minX, groupBounds.minY)
    // ...
  }
}

// groupBounds在renderAll()中更新，但菜单更新时机不对
function renderAll() {
  if (selectedIndices.size > 0 && currentMode.value === 'select') {
    groupBounds = getGroupBounds(selectedIndices) // ❌ 时机不对
    // ...
  }
}
```

## 正确实现方案 (✅)
让菜单位置计算函数自主计算边界：

1. **自主计算边界**：`updateActionsMenuPosition()`自己调用`getGroupBounds()`
2. **移除全局依赖**：不依赖`groupBounds`全局变量
3. **确保计算时机**：在任何需要更新菜单位置时都能正确计算

✅ **正确代码示例：**
```typescript
function updateActionsMenuPosition() {
  if (selectedIndices.size > 0) {
    // ✅ 自主计算边界，不依赖全局变量
    const bounds = getGroupBounds(selectedIndices)
    if (bounds) {
      const screenPos = worldToScreen(bounds.minX, bounds.minY)
      actionsMenuPosition.x = screenPos.x + 10
      actionsMenuPosition.y = screenPos.y - 50
    }
  }
}

// 在所有选中状态变化的地方调用
function handlePointerDown(e) {
  // ... 选中逻辑 ...
  if (!selectedIndices.has(hitIndex)) {
    selectedIndices.clear()
    selectedIndices.add(hitIndex)
    updateActionsMenuPosition() // ✅ 及时更新菜单位置
  }
}
```

## 关键代码/公式
**边界计算函数：**
```typescript
function getGroupBounds(indices) {
  if (!indices || indices.size === 0) return null

  let minX = Infinity, minY = Infinity
  let maxX = -Infinity, maxY = -Infinity

  indices.forEach((idx) => {
    const s = strokes[idx]
    if (s.bounds) {
      minX = Math.min(minX, s.bounds.minX)
      minY = Math.min(minY, s.bounds.minY)
      maxX = Math.max(maxX, s.bounds.maxX)
      maxY = Math.max(maxY, s.bounds.maxY)
    }
  })

  if (minX === Infinity) return null

  return {
    minX, minY, maxX, maxY,
    width: maxX - minX,
    height: maxY - minY
  }
}
```
