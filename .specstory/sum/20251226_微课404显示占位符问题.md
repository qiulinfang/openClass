# 微课404显示占位符问题

## 问题元信息
- **问题分类**：前端
- **严重程度**：中
- **影响范围**：微课功能模块，用户在加载微课内容时
- **发现日期**：2025-12-19
- **解决状态**：已解决

## 问题现象
微课视频加载失败时，会先短暂显示404错误页面，然后才跳转到占位符界面，用户体验不佳。

## 复现步骤
1. 打开包含微课的题目页面
2. 点击播放不存在或已删除的微课内容
3. 观察到先显示404页面，然后才显示占位符

## 用户体验
- 影响点1：用户会看到短暂的404错误页面，造成视觉干扰
- 影响点2：占位符显示有延迟，用户以为功能故障
- 影响点3：整体加载体验不够流畅

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/MiniClass.vue`：微课组件，负责内容加载和404检测
- **涉及模块**：
  - MiniClass组件：微课播放和占位符显示逻辑

## 技术原因 (❌)
1. 原因1：iframe加载404页面后才触发load事件，检测逻辑在事件触发后执行
2. 原因2：预检测逻辑设置了loading状态，导致用户看到加载过程
3. 原因3：跨域限制导致无法直接检测iframe内容状态

```typescript
// ❌ 原始代码：加载后再检测，会有闪烁
const handleIframeLoad = () => {
  // 加载完成后才开始检测404
  setTimeout(() => {
    fetch(normalizedUrl, { method: 'HEAD' })
      .then(response => {
        if (response.status === 404) {
          is404.value = true
        }
      })
  }, 1000)
}
```

## 正确实现方案 (✅)
1. 方案1：在加载前预检测微课URL是否存在
2. 方案2：检测到404直接显示占位符，避免加载iframe
3. 方案3：移除预检测时的loading状态，防止闪烁

```typescript
// ✅ 修复代码：预检测避免闪烁
const loadContent = async (url: string) => {
  // ... 其他代码 ...
  
  // 预检测：如果是微课 /wk/ 链接，先ajax检测是否404
  if (isMicroClassWkUrl(normalizedUrl)) {
    try {
      console.log('[MiniClass] 预检测微课URL:', normalizedUrl)
      const response = await fetch(normalizedUrl, {
        method: 'GET',
        cache: 'no-cache',
      })
      
      if (response.status === 404) {
        console.warn('[MiniClass] 预检测发现微课404，直接显示占位符:', { url: normalizedUrl })
        loading.value = false
        is404.value = true
        return
      }
      
      console.log('[MiniClass] 预检测通过:', { url: normalizedUrl, status: response.status })
    } catch (e) {
      console.warn('[MiniClass] 预检测失败:', { url: normalizedUrl, error: e })
      // 检测失败也直接显示占位符，避免显示404页面
      loading.value = false
      is404.value = true
      return
    }
  }
  
  // 非微课链接或预检测通过的微课链接，走正常加载流程
  loading.value = true
  error.value = null
  is404.value = false
}
```
