# 问题序号：PDF笔记丢失问题分析

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`高`
- **影响范围**：`PDF查看器、笔记绘制功能、用户数据持久化`
- **发现日期**：`2025-11-08`
- **解决状态**：`待解决`

## 问题现象
在 `PdfViewerView.vue` 中绘制笔记后，退出再进入时笔记丢失。

## 复现步骤
1. 步骤1：进入PDF查看器，绘制笔记
2. 步骤2：退出PDF查看器
3. 步骤3：重新进入PDF查看器
4. 步骤4：笔记丢失，无法看到之前绘制的笔记

## 用户体验
- 笔记丢失，用户无法看到之前绘制的笔记
- 影响用户体验，用户需要重新绘制笔记
- 数据丢失风险，用户可能丢失重要笔记

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/PdfViewerView.vue`：PDF查看器视图
  - `imates-web/src/components/PdfPage.vue`：PDF页面组件
  - `imates-web/src/stores/pdfViewerStore.ts`：PDF查看器Store
  - `imates-web/src/services/resource-storage.ts`：资源存储服务
- **涉及模块**：
  - 笔记绘制功能
  - 笔记保存逻辑
  - 笔记加载逻辑
  - IndexedDB存储

## 技术原因 (❌)

1. **防抖延迟导致未保存**：
   - 笔记保存使用2秒防抖延迟
   - 如果用户在2秒内退出，笔记可能未保存
   - 虽然 `onBeforeUnmount` 中调用 `flushSave()` 立即保存，但可能存在时序问题

2. **currentFileId/currentResourceId 未正确设置**：
   - `saveAnnotationsToLocalFile()` 依赖 `currentFileId` 和 `currentResourceId`
   - 如果这两个值未正确设置，保存会失败
   - Store是全局的，可能被其他页面重置

3. **笔记加载时机问题**：
   - `loadAnnotationsFromLocalFile()` 在 `loadPdfWithService` 中调用
   - 但 `PdfPage.vue` 组件可能在笔记加载完成前就初始化了
   - 虚拟滚动导致 `PdfPage` 组件延迟创建，笔记加载完成时，某些页面组件还未创建

4. **数据格式不匹配**：
   - 保存时使用 `toRaw(this.allAnnotations)`
   - 加载时直接赋值 `this.allAnnotations = localFile.annotations`
   - 可能存在格式不匹配问题

5. **IndexedDB保存失败但未提示**：
   - `saveAnnotationsToLocalFile()` 中的错误被捕获但可能未正确处理
   - 用户可能不知道保存失败

### 错误代码示例
```typescript
// ❌ 防抖延迟可能导致保存失败
debouncedSave() {
  if (saveDebounceTimer) {
    clearTimeout(saveDebounceTimer)
    saveDebounceTimer = null
  }
  
  // 2秒后保存，如果用户在2秒内退出，可能未保存
  saveDebounceTimer = setTimeout(async () => {
    await this.autoSaveAnnotations()
  }, 2000)
}
```

## 正确实现方案 (✅)

1. **确保保存成功（高优先级）**：
   - 减少防抖延迟时间（从2秒改为1秒）
   - 在多个时机触发保存：
     - 每次笔记更新时（防抖）
     - 页面切换时
     - 组件卸载时（立即保存）
     - 页面可见性变化时（visibilitychange事件）

2. **添加保存状态反馈（中优先级）**：
   - 添加保存状态提示
   - 保存失败时提示用户

3. **优化加载时机（中优先级）**：
   - 在 `PdfPage.vue` 中添加 `watch` 监听 `store.allAnnotations` 变化
   - 当笔记数据加载完成后，重新加载笔记

4. **增强错误处理（低优先级）**：
   - 添加保存失败提示
   - 记录保存失败日志
   - 提供手动保存按钮

### 正确代码示例
```typescript
// ✅ 在多个时机触发保存
onMounted(() => {
  // 监听页面可见性变化
  document.addEventListener('visibilitychange', handleVisibilityChange)
})

onBeforeUnmount(() => {
  document.removeEventListener('visibilitychange', handleVisibilityChange)
  store.flushSave()
})

const handleVisibilityChange = async () => {
  if (document.hidden) {
    // 页面隐藏时立即保存
    await store.flushSave()
  }
}
```

```typescript
// ✅ 在 PdfPage.vue 中添加 watch 监听
watch(() => store.allAnnotations[props.layout.pageNum], async (newAnnotations) => {
  if (newAnnotations && newAnnotations.length > 0 && fabricService.value) {
    await loadAnnotations()
  }
}, { deep: true })
```

## 关键代码/公式

### 保存流程
1. **用户绘制笔记** → `PdfPage.vue` 的 `onAnnotationChanged` 回调
2. **更新Store** → `store.updateAnnotations(pageNum, serializedObjects)`
3. **触发防抖保存** → `debouncedSave()` (延迟2秒)
4. **自动保存** → `autoSaveAnnotations()` → `saveAnnotationsToLocalFile()`
5. **保存到IndexedDB** → `resourceManager.indexedDB.put('textbooks', textbook)`

### 加载流程
1. **从路由加载文件** → `loadFileFromRoute()`
2. **设置当前文件信息** → `store.setCurrentFileInfo(id, resourceId)`
3. **加载PDF** → `loadPdfWithService(file)`
4. **加载笔记数据** → `store.loadAnnotationsFromLocalFile()`
5. **渲染PDF页面** → `PdfPage.vue` 组件初始化
6. **加载笔记到Canvas** → `loadAnnotations()`

- **测试场景**：

  - 场景2：绘制笔记后等待2秒再退出，检查笔记是否保存
  - 场景3：检查IndexedDB数据，确认笔记数据已保存

- **验证方法**：
  - 方法1：在浏览器开发者工具中查看IndexedDB，确认笔记数据已保存
  - 方法2：检查控制台错误，查看是否有保存失败的错误
  - 方法3：切换账号后检查笔记是否隔离

## 预防措施
- **措施1**：减少防抖延迟时间，提高保存频率
- **措施2**：在多个时机触发保存，确保笔记不会丢失
- **措施3**：添加保存状态反馈，让用户知道保存状态
- **措施4**：优化加载时机，确保笔记在组件创建后加载
- **措施5**：增强错误处理，保存失败时提示用户
