问题06：登录页版本号显示1.0.0与更新接口路由问题

## 问题元信息
- **问题分类**：`前端`
- **严重程度**：`中`
- **影响范围**：`登录页版本号展示、更新检查接口`
- **发现日期**：`2025-12-26`
- **解决状态**：`进行中`

## 问题现象
生产环境登录页底部版本号显示为 `1.0.0`，与预期服务器版本不一致。

## 复现步骤
1. 打开登录页。
2. 观察版本号为 `1.0.0`。
3. 抓包/控制台发现更新检查未能正确覆盖版本号。

## 用户体验
- 用户无法确认当前版本是否为最新。
- 运维/测试定位版本困难。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/views/LoginView.vue`：版本号读取与 checkAppUpdate
  - `imates-web/src/config/env-config.ts`：`getAppUpdateUrl()`
  - `imates-web/src/services/http/http-client.ts`：file:// 环境路由映射（/bj101 前缀）

## 技术原因 (❌)
1. 登录页版本号逻辑：先读 `localStorage['app_version']`，读不到会默认返回 `1.0.0`。
2. 只有当 `checkAppUpdate()` 请求成功且返回包含 `VersionName/versionName` 字段时，才会覆盖 `appVersion`。
3. `/bj101/appupdate.json` 在 file:// 环境下的路由映射如果指向资源服务器（如 `:9099`），可能出现 404/证书/CORS/字段不匹配，导致更新检查失败，从而一直显示 1.0.0。

错误示例：
```ts
// LoginView.vue
const savedVersion = localStorage.getItem('app_version')
return savedVersion || '1.0.0'
```

## 正确实现方案 (✅)
1. 明确 `/bj101/appupdate.json` 的来源：如果业务要求“永远走学班正式服务器”，则在 `http-client` 的路由映射里将 `/bj101` 指向学班服务域名（apiBaseUrl 或固定域名）。
2. 在 `LoginView.checkAppUpdate` 中增加更明确的日志与字段兼容，并在失败时提示/回退策略。

示例：
```ts
// http-client.ts
'/bj101': apiBaseUrl

// LoginView.vue
const serverVersion = result.versionName || result.VersionName || ''
```

## 关键代码/公式
- `LoginView.vue`：`loadAppVersion()` / `checkAppUpdate()`
- `http-client.ts`：`buildFullUrl()` / `getRouteBaseMap()`

## 测试验证
- **测试场景**：
  - 场景1：清空 localStorage 后打开登录页，应通过更新接口拿到服务器版本并覆盖显示。
  - 场景2：接口返回字段为 `VersionName` 或 `versionName` 都能被识别。
- **验证方法**：
  - 方法1：抓包确认最终请求 URL 与返回体。
  - 方法2：控制台确认 `appVersion` 被赋值且写回 localStorage。

## 预防措施
- 将更新检查的 URL/路由映射写入可测试的配置，并提供环境自检工具页面。
- 对更新 JSON 结构增加 schema 校验/类型定义，避免字段漂移。
