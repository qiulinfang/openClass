问题序号：笔记绘制偏离问题

## 问题元信息
- **问题分类**：`前端/交互体验`
- **严重程度**：`高`
- **影响范围**：`PDF阅读器多页渲染模式下的笔记绘制功能`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在多页PDF阅读器中，用户发现：
- 笔记（笔迹）绘制位置与手指/鼠标点击位置不一致
- 笔迹出现明显的偏移，偏离实际点击位置
- 特别是在多页布局下，笔记可能绘制到错误的页面或位置

## 复现步骤
1. 步骤1：打开多页PDF阅读器，启用画笔模式
2. 步骤2：在PDF页面上点击或拖拽绘制笔记
3. 步骤3：观察笔记出现的位置与实际点击位置的偏差

## 用户体验
- 影响点1：笔记绘制不准确，用户需要反复调整位置
- 影响点2：降低笔记功能的可用性，影响学习和工作效率
- 影响点3：可能导致笔记记录到错误的页面位置

## 相关文件/模块
- **涉及文件**：
  - `index.html`：多页PDF阅读器实现
- **涉及模块**：
  - 坐标转换系统：从屏幕坐标到PDF页面坐标的转换
  - 事件处理系统：pointerdown/move/up 事件处理
  - 多页布局系统：页面定位和边界计算

## 技术原因 (❌)
1. 原因1：**坐标转换逻辑错误**
   - 使用了 `getBoundingClientRect()` 但没有考虑容器的 CSS transform
   - 计算相对位置时没有正确处理缩放和偏移变换

2. 原因2：**DOM 回流性能问题**
   - 在 pointermove 事件中频繁调用 `getBoundingClientRect()`
   - 每次调用都会触发浏览器重排，影响性能

3. 原因3：**多页布局坐标计算复杂**
   - 页面排列使用 flex 布局，但坐标计算没有考虑布局特性
   - 页面间距和对齐方式影响了坐标映射

错误示例：
```typescript
// ❌ 错误：直接使用 DOM 方法，没有考虑 transform
const getPdfLocation = (clientX, clientY) => {
  const rect = pdfRefs.value[pageIndex].getBoundingClientRect();
  return {
    x: (clientX - rect.left) / scale.value,
    y: (clientY - rect.top) / scale.value
  };
};
```

## 正确实现方案 (✅)
1. 方案1：**预计算页面布局坐标**
   - 在初始化时计算所有页面的绝对位置
   - 避免在事件处理过程中调用 DOM 方法

2. 方案2：**纯数学坐标转换**
   - 使用预计算的页面坐标数据
   - 通过数学计算实现从屏幕坐标到页面坐标的转换

3. 方案3：**优化性能和准确性**
   - 减少 DOM 查询，提升性能
   - 确保坐标转换的精确性

正确示例：
```typescript
// ✅ 预计算页面坐标，避免 DOM 查询
const initPDF = async () => {
  // 预计算每页的布局坐标
  pageList.value = pages.map((_, i) => ({
    y: currentY,
    x: (maxW - pageWidth) / 2  // 水平居中
  }));
};

// 纯数学坐标转换
const getPdfLocation = (clientX, clientY) => {
  const mx = clientX - rect.left;
  const my = clientY - rect.top;
  const localX = (mx - offset.value.x) / scale.value;
  const localY = (my - offset.value.y) / scale.value;
  
  // 使用预计算坐标进行页面定位
  for (let i = 0; i < pageList.value.length; i++) {
    const p = pageList.value[i];
    if (localY >= p.y && localY <= p.y + pageHeight) {
      if (localX >= p.x && localX <= p.x + pageWidth) {
        return {
          pageIndex: i,
          x: localX - p.x,
          y: localY - p.y
        };
      }
    }
  }
  return null;
};
```

## 关键代码/公式
- 代码片段1：预计算页面布局
```typescript
// 页面布局预计算
const list = [];
let currentY = PAGE_GAP;
for (let i = 0; i < tempSizes.length; i++) {
  const size = tempSizes[i];
  list.push({
    viewWidth: size.w,
    viewHeight: size.h,
    y: currentY,
    x: (maxW - size.w) / 2  // 水平居中计算
  });
  currentY += size.h + PAGE_GAP;
}
```

- 代码片段2：纯数学坐标转换
```typescript
// 屏幕坐标 -> 容器坐标 -> 页面相对坐标
const localX = (clientX - rect.left - offset.x) / scale;
const localY = (clientY - rect.top - offset.y) / scale;

// 页面定位逻辑
if (localY >= page.y && localY <= page.y + page.viewHeight &&
    localX >= page.x && localX <= page.x + page.viewWidth) {
  return {
    pageIndex: i,
    x: localX - page.x,  // 页面内相对坐标
    y: localY - page.y
  };
}
```
