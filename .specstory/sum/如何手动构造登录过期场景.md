# 如何手动构造登录过期场景

## 概述

登录过期场景会在以下情况下触发：
1. API 返回 401 未授权错误
2. 自动重新登录失败（没有保存的用户凭据或重新登录失败）

本文档提供多种方法来手动构造登录过期场景，用于测试和调试。

---

## 方法一：直接清除 Token（最简单）

### 1.1 清除学班 Token

**适用场景**：测试学班管理员相关接口的登录过期

**操作步骤**：

1. 打开浏览器开发者工具（F12）
2. 进入 Console 标签页
3. 执行以下命令：

```javascript
// 清除学班 Token
localStorage.removeItem('XUEBAN_TOKEN')

// 或者使用工具函数（需要先导入）
// import { setXuebanToken } from '@/utils/user/authStorage'
// setXuebanToken(null)
```

4. 触发任意学班相关接口请求（如 `/permission/*`, `/admin/info`, `/biologyTopicKnowledge/*`）
5. 后端会返回 401 错误，触发登录过期流程

### 1.2 清除研伴 Token

**适用场景**：测试研伴学生相关接口的登录过期

**操作步骤**：

```javascript
// 清除研伴 Token
localStorage.removeItem('YANBAN_TOKEN')

// 或者使用工具函数
// import { setYanbanToken } from '@/utils/user/authStorage'
// setYanbanToken(null)
```

4. 触发任意研伴相关接口请求（如 `/blw-edu-yb/*`）
5. 后端会返回 401 错误，触发登录过期流程

## 方法二：修改 Token 为无效值

### 2.1 修改学班 Token 为无效值

**适用场景**：模拟 Token 格式正确但已过期或被后端拒绝的情况

**操作步骤**：

```javascript
// 将 Token 设置为无效值（如空字符串、随机字符串等）
localStorage.setItem('XUEBAN_TOKEN', 'invalid_token_12345')

// 或者设置为空字符串
localStorage.setItem('XUEBAN_TOKEN', '')

// 或者设置为已过期的 Token（如果有的话）
localStorage.setItem('XUEBAN_TOKEN', 'expired_token_here')
```

4. 触发学班相关接口请求
5. 后端会验证 Token 并返回 401 错误

### 2.2 修改研伴 Token 为无效值

```javascript
// 将 Token 设置为无效值
localStorage.setItem('YANBAN_TOKEN', 'invalid_token_12345')
```

---

## 方法三：清除用户凭据（测试自动重新登录失败）

### 3.1 清除用户 ID 和密码

**适用场景**：测试自动重新登录失败的情况，会直接显示"登录已过期，请重新登录"

**操作步骤**：

```javascript
// 清除用户凭据（保留 Token，这样会先触发 401，然后自动重新登录失败）
localStorage.removeItem('userId')
localStorage.removeItem('userPassword')

// 或者设置为无效值
localStorage.setItem('userId', '')
localStorage.setItem('userPassword', '')
```

**预期行为**：

1. 触发 API 请求 → 返回 401
2. 系统尝试自动重新登录 → 发现没有保存的用户凭据
3. 显示"登录已过期，请重新登录"消息
4. 抛出 401 错误

### 3.2 清除学班用户凭据

```javascript
// 清除学班用户凭据
localStorage.removeItem('userId')
localStorage.removeItem('userPassword')
```

### 3.3 清除研伴用户凭据

```javascript
// 清除研伴用户凭据（研伴登录使用 studentUserId）
localStorage.removeItem('studentUserId')
localStorage.removeItem('userPassword')
```

## 方法四：使用浏览器开发者工具拦截请求

### 4.1 使用 Network 面板修改响应

**适用场景**：精确控制返回 401 错误，不实际清除 Token

**操作步骤**：

1. 打开浏览器开发者工具（F12）
2. 进入 Network 标签页
3. 找到要测试的 API 请求
4. 右键点击请求 → 选择 "Override content" 或使用 "Request blocking"
5. 修改响应状态码为 401

**注意**：不同浏览器的操作方式可能不同，Chrome 可以使用 "Request blocking" 或 "Network request blocking" 扩展。

### 4.2 使用 Service Worker 拦截请求

**适用场景**：需要更复杂的拦截逻辑

**操作步骤**：

1. 注册 Service Worker
2. 在 `fetch` 事件中拦截特定请求
3. 返回 401 响应

```javascript
// Service Worker 示例代码
self.addEventListener('fetch', event => {
  if (event.request.url.includes('/admin/info')) {
    event.respondWith(
      new Response(null, {
        status: 401,
        statusText: 'Unauthorized'
      })
    )
  }
})
```

## 方法五：修改后端返回状态码（需要后端配合）

### 5.1 后端临时返回 401

**适用场景**：测试完整的登录过期流程

**操作步骤**：

1. 修改后端代码，临时让特定接口返回 401
2. 或者在后端添加测试参数，如 `?force_401=true`
3. 前端请求时带上该参数

## 方法六：使用代码直接调用清除函数

### 6.1 在 Vue 组件中调用

**适用场景**：在开发环境中添加测试按钮

**代码示例**：

```vue
<template>
  <button @click="simulateTokenExpired">模拟 Token 过期</button>
</template>

<script setup lang="ts">
import { setXuebanToken, setYanbanToken } from '@/utils/user/authStorage'

const simulateTokenExpired = () => {
  // 清除学班 Token
  setXuebanToken(null)
  
  // 或者清除研伴 Token
  // setYanbanToken(null)
  
  console.log('Token 已清除，下次 API 请求将触发登录过期')
}
</script>
```

### 6.2 在浏览器 Console 中使用工具函数

**操作步骤**：

1. 打开浏览器开发者工具（F12）
2. 进入 Console 标签页
3. 动态导入工具函数：

```javascript

// 清除学班 Token
setXuebanToken(null)

// 清除研伴 Token

```

**注意**：路径可能需要根据实际项目结构调整。

## 方法七：清除所有认证信息

### 7.1 清除所有 Token 和用户信息

**适用场景**：完全重置登录状态

**操作步骤**：


## 测试场景组合

### 场景 1：Token 过期 + 自动重新登录成功

**操作步骤**：

1. 确保已保存用户凭据（`userId` 和 `userPassword`）
2. 清除 Token：`localStorage.removeItem('XUEBAN_TOKEN')`
3. 触发 API 请求
4. **预期结果**：自动重新登录成功，请求继续执行

### 场景 2：Token 过期 + 自动重新登录失败

**操作步骤**：

1. 清除 Token：`localStorage.removeItem('XUEBAN_TOKEN')`
2. 清除用户凭据：`localStorage.removeItem('userId')` 和 `localStorage.removeItem('userPassword')`
3. 触发 API 请求
4. **预期结果**：显示"登录已过期，请重新登录"消息，请求失败

### 场景 3：无效 Token + 后端拒绝

**操作步骤**：

1. 设置无效 Token：`localStorage.setItem('XUEBAN_TOKEN', 'invalid_token')`
2. 确保已保存用户凭据
3. 触发 API 请求
4. **预期结果**：后端返回 401，自动重新登录成功，请求继续执行

## 验证登录过期是否触发

### 检查点

1. **控制台日志**：查看是否有以下日志
   - `userId` 和 `password` 的输出（在 `tryAutoRelogin` 方法中）
   - 401 错误信息

2. **UI 提示**：查看是否显示"登录已过期，请重新登录"消息

3. **Network 面板**：查看请求是否返回 401 状态码

4. **Token 状态**：检查 `localStorage` 中的 Token 是否被清除

## 注意事项

1. **测试环境**：建议在开发环境或测试环境进行，避免影响生产环境
2. **数据备份**：清除 Token 前，建议先记录当前的 Token 值，以便恢复
3. **自动重新登录**：如果保存了用户凭据，系统会自动尝试重新登录，可能不会立即显示过期提示
4. **Token 类型**：根据测试的接口类型，选择清除对应的 Token（学班或研伴）
5. **浏览器刷新**：某些情况下可能需要刷新页面才能看到效果
