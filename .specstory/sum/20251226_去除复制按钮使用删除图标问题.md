# 问题序号：去除复制按钮使用删除图标问题

## 问题元信息
- **问题分类**：前端/UI
- **严重程度**：低
- **影响范围**：操作菜单UI，影响视觉一致性和用户体验
- **发现日期**：2025-12-26
- **解决状态**：已解决

## 问题现象
操作菜单中的复制按钮功能冗余，删除按钮使用SVG图标与项目整体图标风格不一致。

## 复现步骤
1. 步骤1：选中Canvas上的笔迹
2. 步骤2：观察操作菜单显示复制和删除两个按钮
3. 步骤3：注意到删除按钮使用内联SVG，而非项目统一的图标资源

## 用户体验
- 影响点1：复制功能在当前场景下使用频率低
- 影响点2：删除按钮图标风格与项目其他图标不一致
- 影响点3：菜单按钮过多影响简洁性

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/drawingBoardNew.vue`：操作菜单组件
- **涉及模块**：
  - UI组件系统：图标和按钮样式统一

## 技术原因 (❌)
UI设计不一致和技术债务：

1. **功能冗余**：复制功能在当前使用场景中不常用
2. **图标不统一**：删除按钮使用内联SVG而非项目图标资源
3. **代码冗余**：包含未使用的复制功能代码

❌ **错误代码示例：**
```vue
<template>
  <!-- ❌ 使用内联SVG，不统一 -->
  <button class="action-btn action-delete">
    <svg width="16" height="16" viewBox="0 0 24 24">
      <!-- 内联SVG代码 -->
    </svg>
  </button>
</template>
```

## 正确实现方案 (✅)
简化菜单并使用统一图标资源：

1. **去除复制按钮**：移除不常用的复制功能
2. **使用项目图标**：删除按钮使用`/icons/delete.svg`
3. **样式优化**：为图标添加适当的CSS过滤器适配主题
4. **代码清理**：移除相关的复制功能代码

✅ **正确代码示例：**
```vue
<template>
  <!-- 笔记操作菜单 -->
  <div v-if="showActionsMenu" class="note-actions-menu">
    <button class="action-btn action-delete" @click="deleteSelectedStrokes">
      <img src="/icons/delete.svg" alt="删除" width="16" height="16" />
    </button>
  </div>
</template>

<style scoped>
.action-delete img {
  filter: brightness(0) saturate(100%) invert(24%) sepia(97%) saturate(7460%)
          hue-rotate(0deg) brightness(95%) contrast(105%);
}

.action-delete:hover img {
  filter: brightness(0) saturate(100%) invert(16%) sepia(86%) saturate(7460%)
          hue-rotate(0deg) brightness(95%) contrast(105%);
}
</style>
```

## 关键代码/公式
**图标颜色适配CSS过滤器：**

```css
/* 删除图标颜色过滤器 - 将红色图标转换为主题色 */
.action-delete img {
  /* 将红色图标转换为深红色 */
  filter: brightness(0) saturate(100%) invert(24%) sepia(97%) saturate(7460%)
          hue-rotate(0deg) brightness(95%) contrast(105%);
}

.action-delete:hover img {
  /* 悬停时转换为更深的红色 */
  filter: brightness(0) saturate(100%) invert(16%) sepia(86%) saturate(7460%)
          hue-rotate(0deg) brightness(95%) contrast(105%);
}
```
