问题序号：Pdf笔记列表跨页展示与滚动定位

## 问题元信息
- **问题分类**：`前端 / 交互`
- **严重程度**：`中`
- **影响范围**：`PdfPage 笔记列表的可用性与可见性`
- **发现日期**：2025-11-19
- **解决状态**：`已解决`

## 背景
- 在 `PdfPage` 中已经支持在页面上添加笔记锚点（note marker），并在右侧通过 `PdfNoteListPanel` 展示笔记列表。
- 初始实现中，右侧列表只展示**当前页**的笔记（通常通过 `currentPageNotes` 这样的计算属性过滤得到）。
- 实际使用中，用户希望能够在右侧一次性看到**整个文档所有页面**的笔记，并能快速跳转到任意一条笔记所在的页和位置。

## 问题描述
- 现状：
  - 右侧 `PdfNoteListPanel` 组件绑定的是当前页笔记数组，例如：
    - `:notes="currentPageNotes"`。
  - 这样导致的问题：
    - 只能看到当前页的笔记，无法从列表中感知整本 PDF 的笔记分布情况。
    - 想跳转到其他页面的笔记时，只能先滚动到那个页面再看当前页列表，体验较差。

- 目标：
  - 右侧笔记列表展示**所有页面**的笔记，并在每条记录中注明所在页码。
  - 点击任意一条记录时，左侧 PDF 区域自动滚动到对应的页面及相对位置。
  - 保持现有 IndexedDB 持久化方案不变（仍然按文档维度存储 notes）。

## 方案设计

### 1. PdfNoteListPanel.vue 的接口设计

#### 接口定义
- `PdfNoteListPanel.vue` 采用通用的 `PageNote` 结构：

```ts
interface PageNote {
  id: string
  pageIndex: number
  x: number
  y: number
  text: string
}
```

- Props：
  - `visible: boolean`：控制面板是否显示。
  - `notes: PageNote[]`：传入要展示的笔记列表（支持全局 notes）。

- Emits：
  - `update:visible`：用于关闭/打开面板的双向绑定。
  - `select`：当用户点击某一条笔记时发出，对应的 payload 为 `PageNote`。

#### 展示逻辑
- 列表使用 `q-list` / `q-item` 渲染每条笔记：
  - 标题中展示：`笔记 · 第 {{ note.pageIndex + 1 }} 页`，明确标出页码。
  - 副标题展示笔记的 `text` 内容，超长时省略号处理。
- 组件**不负责过滤是当前页还是全部页**：
  - 只负责展示「调用方给它的 notes 数组」。
  - 是否传当前页笔记或全局笔记，由上层 `PdfPage` 控制。

### 2. pdfpage.vue 中 notes 与 currentPageNotes 的区别

#### 核心状态
- `notes: Ref<PageNote[]>`：
  - 存储整个文档的所有笔记。
  - 与 IndexedDB 中的记录一一对应（按文档 `docKey` 存储）。

- `currentPageIndex: Ref<number>`：
  - 通过 `scroll` 事件与页面布局计算出当前可见页索引。

- `currentPageNotes: Computed<PageNote[]>`：

```ts
const currentPageNotes = computed(() =>
  notes.value.filter((n) => n.pageIndex === currentPageIndex.value),
)
```

- 用途：
  - 左侧 PDF 页面上的笔记 marker 渲染时，可以按页面分组：
    - 例如通过 `pageNotesByIndex` 把 `notes` 分组到每一页。

#### 本次改动的关键点
- 右侧 `PdfNoteListPanel` 的 `notes` 绑定，从 `currentPageNotes` 改为 `notes`：

```vue
<PdfNoteListPanel
  :visible="isNotePanelOpen"
  :notes="notes"               <!-- 使用全局 notes，而不是 currentPageNotes -->
  @update:visible="(v) => (isNotePanelOpen = v)"
  @select="scrollToNote"
/>
```

- 左侧页面上的 marker 渲染方式不变：
  - 仍然通过 `pageNotesByIndex`（由全局 `notes` 分组计算）在每一页上渲染 marker。
  - 因此，右侧列表展示范围扩大为“全局”，左侧则按页展示，但二者都来自同一份 `notes` 数据源。

### 3. 滚动定位逻辑 scrollToNote

- 当用户在右侧列表点击某条笔记时，`PdfNoteListPanel` 通过 `select` 事件向上抛出 `note` 对象：

```ts
const handleSelect = (note: PageNote) => {
  emit('select', note)
}
```

- `pdfpage.vue` 中的 `scrollToNote` 负责处理滚动定位：

```ts
const scrollToNote = (note: PageNote) => {
  if (!containerRef.value || pageLayouts.value.length === 0) return

  const pageIndex = note.pageIndex
  if (pageIndex < 0 || pageIndex >= pageLayouts.value.length) return

  const pageGap = store.pageGap
  let offsetY = 0
  for (let i = 0; i < pageIndex; i++) {
    offsetY += pageLayouts.value[i].height + pageGap
  }

  const layout = pageLayouts.value[pageIndex]
  offsetY += note.y * layout.height

  const scale = store.scale || 1
  const targetScrollTop = offsetY * scale

  containerRef.value.scrollTop = targetScrollTop
}
```

- 逻辑说明：
  - 使用 `pageIndex` 累加前面页面的高度加间距，得到目标页顶部在内容坐标中的位置。
  - 再加上 `note.y * layout.height`，得到笔记在该页中的垂直位置。
  - 最后乘以当前缩放比例 `scale`，换算到滚动容器的实际滚动值 `scrollTop`。

- 因为 `notes` 中每条记录都包含 `pageIndex`、`y`，所以从**全局列表**中任意选择一条，都可以准确滚动到对应位置。

## 代码位置

- `imates-web/src/components/PdfNoteListPanel.vue`

- `imates-web/src/components/pdfpage.vue`
  - `notes` / `currentPageNotes` / `pageNotesByIndex` 状态与计算逻辑。

  - Template 中右侧 `PdfNoteListPanel` 的绑定由 `currentPageNotes` 改为 `notes`。

## 注意事项

1. **性能注意**
   - 对于页数较多、笔记数量较大的 PDF，右侧列表一次性展示所有笔记可能较长，但由于只是渲染一个线性列表，性能压力可控。
   - 如后续发现性能瓶颈，可以考虑分页加载或虚拟列表。

2. **排序与分组**
   - 当前列表按 `notes` 数组顺序展示（通常是创建顺序）。
   - 可扩展点：
     - 按 `pageIndex` 先排序，再按创建时间排序。
     - 在 UI 上按页分组（例如“第 N 页”分组标题）。

3. **与 IndexedDB 的一致性**
   - `notes` 作为整本文档的笔记集合，写回 IndexedDB 时需整体覆盖：
     - 新增、修改、删除笔记后，记得调用 `saveNotesToDb()` 持久化。
   - 加载时（`loadNotesFromDb`）需要保证反序列化的类型安全。

## 未来扩展点

1. **按页筛选 / 分组显示**
   - 在右侧笔记列表上增加「只看当前页」「全部页」切换。
   - 或者按页折叠分组，展开某一页的笔记列表。

2. **搜索与过滤**
   - 支持按关键字搜索笔记内容，快速定位到相关记录。
   - 可结合页码过滤，支持“只搜索当前页笔记”。

3. **与 AI 功能联动**
   - 将某一页或某一条笔记发送给 AI 进行解析或总结。
   - 在列表中显示 AI 生成的标签或分类结果。

4. **笔记排序策略**
   - 支持按创建时间、更新时间、页码、在页中位置等多种排序方式。

5. **多文档共享笔记模型（远期）
   - 在当前文档级别 notes 之上，增加全局笔记索引，支持跨文档检索。

---

通过本次改造，右侧笔记列表从“当前页视角”扩展为“全局视角”，并且基于统一的 `PageNote` 数据模型，配合精确的 `scrollToNote` 定位逻辑，为后续的笔记管理、检索和智能化功能打下了基础。
