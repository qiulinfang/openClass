# 服务层重构计划

## 问题元信息
- **问题分类**：`前端` `架构`
- **严重程度**：`中`
- **影响范围**：`服务层代码组织`
- **发现日期**：`2025-12-12`
- **解决状态**：`进行中`

## 问题描述
当前服务层代码组织不够清晰，不同类型的服务混合在一起，导致代码可维护性和可读性降低。

## 重构目标
1. 将服务按职责分为三大类：`http`、`storage`、`business`
2. 提高代码的可维护性和可读性
3. 统一导入路径，使用`@/`别名

## 目录结构
```
src/services/
├── http/                # 网络请求相关
│   ├── http-client.ts    # HTTP 客户端
│   ├── auth-service.ts   # 认证服务
│   └── api-endpoints.ts  # API 端点配置
│
├── storage/             # 数据存储相关
│   ├── auth-storage-service.ts
│   ├── ai-textbook-session-storage.ts
│   ├── chat-storage.ts
│   ├── question-storage.ts
│   ├── resource-storage.ts
│   └── indexeddb-service.ts
│
└── business/            # 业务逻辑
    ├── api-service.ts
    ├── dialog-service.ts
    ├── draggable-dialog-service.ts
    ├── android-bridge.ts
    └── mock-teacher-bridge.ts
```

## 导出方案

更新 `src/services/index.ts`：

```typescript
// 核心服务
export { apiService, ApiService } from './business/api-service'
export { androidBridge, AndroidBridge } from './business/android-bridge'
export { httpClient, HttpClient } from './http/http-client'
export { authService } from './http/auth-service'
export { authStorageService, AuthStorageService } from './storage/auth-storage-service'
// ... 其他 storage 导出
export * from './http/api-endpoints'
```

## 导入路径更新

将相对路径：
```typescript
import { apiService } from '../services/api-service'
import { resourceManager } from '../services/resource-storage'
import { authStorageService } from '../services/auth-storage-service'
import { authService } from '../services/auth-service'
```

更新为别名路径：
```typescript
import { apiService } from '@/services/business/api-service'
import { resourceManager } from '@/services/storage/resource-storage'
import { authStorageService } from '@/services/storage/auth-storage-service'
import { authService } from '@/services/http/auth-service'
```
