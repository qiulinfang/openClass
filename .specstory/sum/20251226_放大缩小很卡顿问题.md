问题序号：放大缩小很卡顿问题

## 问题元信息
- **问题分类**：`前端/性能`
- **严重程度**：`高`
- **影响范围**：`PDF阅读器缩放功能，影响所有用户的浏览体验`
- **发现日期**：`2025-12-26`
- **解决状态**：`已解决`

## 问题现象
在PDF阅读器中进行缩放操作时：
- 放大缩小操作非常卡顿，响应延迟明显
- 缩放动画不流畅，出现明显的帧率下降
- 特别是在有大量笔记的页面上，卡顿现象更加严重

## 复现步骤
1. 步骤1：打开包含大量笔记的PDF页面
2. 步骤2：使用滚轮或双指进行缩放操作
3. 步骤3：观察缩放过程中的流畅度和响应速度

## 用户体验
- 影响点1：缩放操作响应慢，影响浏览效率
- 影响点2：动画不流畅，视觉体验差
- 影响点3：大量内容时几乎无法正常使用缩放功能

## 相关文件/模块
- **涉及文件**：
  - `index.html`：PDF阅读器缩放实现
- **涉及模块**：
  - 缩放控制系统：zoomAt 和双指缩放逻辑
  - Canvas 重绘系统：缩放过程中的重绘策略
  - 性能优化系统：CSS transform vs Canvas 重绘

## 技术原因 (❌)
1. 原因1：**缩放过程中频繁重绘**
   - 每次缩放事件都触发 redrawAllPagesInk()
   - 大量笔记的重绘开销导致性能急剧下降

2. 原因2：**Canvas 重绘策略不当**
   - 使用 Canvas 重绘而不是 CSS transform
   - 没有区分缩放过程和缩放结果

3. 原因3：**事件处理频率过高**
   - 双指缩放过程中每帧都重绘
   - 高频事件导致计算资源耗尽

错误示例：
```typescript
// ❌ 缩放过程中频繁重绘
const zoomAt = (delta, clientX, clientY) => {
  // 缩放逻辑...
  redrawAllPagesInk(); // 每次缩放都重绘所有笔记！
};

const onPointerMove = (e) => {
  if (activePointers.size === 2) {
    // 双指缩放逻辑...
    redrawAllPagesInk(); // 每帧都重绘！
  }
};
```

## 正确实现方案 (✅)
1. 方案1：**CSS transform 优化**
   - 使用 CSS transform 处理缩放动画
   - 避免 Canvas 重绘的巨大开销

2. 方案2：**智能重绘策略**
   - 缩放过程中不重绘，只在缩放结束时重绘
   - 利用浏览器硬件加速提升性能

3. 方案3：**性能分层处理**
   - 区分实时交互（CSS）和最终结果（Canvas）
   - 在适当时机进行高质量重绘

正确示例：
```typescript
// ✅ 使用 CSS transform 进行实时缩放
const containerStyle = computed(() => ({
  transform: `translate(${offset.value.x}px, ${offset.value.y}px) scale(${scale.value})`,
  willChange: 'transform' // 硬件加速
}));

// ✅ 只在缩放结束时重绘
const onPointerUp = (e) => {
  if (activePointers.size === 0) {
    // 缩放结束，进行高质量重绘
    redrawAllPagesInk();
  }
};
```

## 关键代码/公式
- 代码片段1：CSS transform 缩放
```typescript
// 利用硬件加速的 CSS transform
const containerStyle = computed(() => ({
  transform: `translate(${offset.x}px, ${offset.y}px) scale(${scale})`,
  willChange: 'transform', // 优化GPU加速
  transition: 'none' // 避免额外的动画延迟
}));
```

- 代码片段2：智能重绘时机
```typescript
// 区分缩放过程和结果
const onPointerMove = (e) => {
  if (activePointers.size === 2) {
    // 缩放中：只更新数值，不重绘
    scale.value = newScale;
    offset.value.x = newOffsetX;
    offset.value.y = newOffsetY;
    // CSS 会自动更新视觉效果
  }
};

const onPointerUp = (e) => {
  if (activePointers.size === 0) {
    // 缩放结束：高质量重绘
    redrawAllPagesInk();
  }
};
```
