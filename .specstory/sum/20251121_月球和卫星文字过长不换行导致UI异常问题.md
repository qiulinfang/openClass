问题序号：月球和卫星文字过长不换行导致 UI 异常问题

## 问题元信息
- **问题分类**：`[前端/UI]`
- **严重程度**：`[中]`
- **影响范围**：`[知识图谱视图，长标题或长知识点名称的场景]`
- **发现日期**：`2025-11-21`
- **解决状态**：`[已解决]`

## 问题现象
知识图谱中的：
- 月球（章节标题）文字
- 卫星（知识点名称）文字

在标题或名称过长时，会出现以下问题：
- 文本超出月球/卫星直径范围，导致文字溢出遮挡其他元素。
- 文本没有换行，仅单行显示，超出部分直接被裁剪，不易阅读。
- 旧逻辑对卫星名称做了简单长度截断（例如 >6 截断为 `...`），导致信息不完整。

## 复现步骤
1. 在章节或知识点名称中设置较长的中文标题（例如超过 10~12 个字）。
2. 打开知识图谱视图，让包含长标题的章节/知识点出现在画布上。
3. 观察月球中心标题和卫星下方文字的显示效果：
   - 超出范围的文字被截断或溢出圆形区域。

## 用户体验
- 影响点1：长标题信息无法完整阅读，用户需要通过弹窗等二次操作查看完整内容。
- 影响点2：文字溢出导致视觉层级混乱，影响整体美观度。
- 影响点3：简单的长度截断（固定字符数）在中英混排场景下表现不稳定。

## 相关文件/模块
- **涉及文件**：
  - `imates-web/src/components/knowledge-graph/newGrap.vue`：`Satellite.draw`、`Moon.drawFocused` 文本绘制逻辑。
- **涉及模块**：
  - Canvas 文本绘制模块。

## 技术原因 (❌)
1. 原因1：卫星文本绘制时直接使用 `fillText`，没有多行和宽度约束，仅简单做字符长度判断并截断：
```ts
// ❌ 旧逻辑示例
if (scale > 1.0) {
  context.fillStyle = '#fff';
  context.font = `12px "Microsoft YaHei"`;
  context.textAlign = 'center';
  context.textBaseline = 'top';
  const name = this.data.name.length > 6
    ? this.data.name.substring(0, 5) + '...'
    : this.data.name;
  context.fillText(name, this.x, this.y + r + 5);
}
```
2. 原因2：聚焦月球标题同样使用单行 `fillText` 绘制，并且字号随缩放动态变化，在固定直径范围内容易产生溢出和行数变化（文字“跳动”）。
3. 原因3：缺少通用的多行文本换行和省略号处理工具函数，所有文本绘制逻辑都是临时写法，难以统一控制。

## 正确实现方案 (✅)
1. 方案1：实现一个通用的多行文本绘制工具函数 `drawMultilineTextWithEllipsis`：
   - 按字符测量宽度，自动换行。
   - 支持最大宽度 `maxWidth`、最大行数 `maxLines` 和行高 `lineHeight`。
   - 超出最大行数时，在最后一行尾部添加省略号 `...`。
2. 方案2：在卫星绘制中，限定文本最大宽度为卫星直径（或直径的倍数），最多两行，超出省略号。
3. 方案3：在聚焦月球绘制中，限定文本最大宽度为月球直径的一定比例（例如 `r * 1.5`），最多两行，字号固定避免跳动。

✅ 通用多行绘制函数实现：
```ts
function drawMultilineTextWithEllipsis(
  ctx: CanvasRenderingContext2D,
  text: string,
  x: number,
  y: number,
  maxWidth: number,
  lineHeight: number,
  maxLines: number,
  textAlign: CanvasTextAlign = 'center',
  textBaseline: 'top' | 'middle' | 'bottom' = 'middle'
) {
  if (!text) return;

  const originalBaseline = ctx.textBaseline;
  const originalAlign = ctx.textAlign;
  ctx.textAlign = textAlign;
  ctx.textBaseline = 'middle';

  const chars = text.split('');
  const lines: string[] = [];
  let current = '';

  for (let i = 0; i < chars.length; i++) {
    const testLine = current + chars[i];
    const width = ctx.measureText(testLine).width;
    if (width > maxWidth && i > 0) {
      lines.push(current);
      current = chars[i];
    } else {
      current = testLine;
    }
  }
  lines.push(current);

  if (lines.length > maxLines) {
    const lastIndex = maxLines - 1;
    let fullRemaining = text.substring(lines.slice(0, lastIndex).join('').length);
    let testStr = fullRemaining;
    while (ctx.measureText(testStr + '...').width > maxWidth && testStr.length > 0) {
      testStr = testStr.slice(0, -1);
    }
    lines[lastIndex] = testStr + '...';
    lines.length = maxLines;
  }

  const totalHeight = lineHeight * lines.length;
  let startY = y;
  if (textBaseline === 'middle') {
    startY = y - totalHeight / 2 + lineHeight / 2;
  } else if (textBaseline === 'top') {
    startY = y + lineHeight / 2;
  } else if (textBaseline === 'bottom') {
    startY = y - totalHeight + lineHeight / 2;
  }

  for (let i = 0; i < lines.length; i++) {
    ctx.fillText(lines[i], x, startY + i * lineHeight);
  }

  ctx.textBaseline = originalBaseline;
  ctx.textAlign = originalAlign;
}
```

✅ 卫星文字绘制使用多行函数：
```ts
if (scale > 1.0) {
  context.fillStyle = '#fff';
  const fontSize = 13;
  context.font = `${fontSize}px "Microsoft YaHei"`;

  const maxTextWidth = r * 3; // 允许稍微宽一点
  const lineHeight = fontSize * 1.2;
  const maxLines = 2;
  const textStartY = this.y + r + 5;

  drawMultilineTextWithEllipsis(
    context,
    this.data.name,
    this.x,
    textStartY,
    maxTextWidth,
    lineHeight,
    maxLines,
    'center',
    'top'
  );
}
```

context.fillStyle = '#fff';

## 测试验证
- **测试场景**：
  - 场景1：短标题（少量字符）。
    - 预期：单行显示，垂直居中或顶对齐，无省略号。
  - 场景2：中等长度中文标题（如 8~12 字）。
    - 预期：自动换行为两行，无省略号。
  - 场景3：超长标题。
    - 预期：最多两行，第二行末尾显示 `...`，整体不超出月球/卫星直径范围。
- **验证方法**：
  - 人工对比不同长度标题的显示效果，确认未出现溢出或裁剪异常。

## 预防措施
- 措施1：对于 Canvas 中的文本绘制，优先使用统一的换行和省略号工具函数，避免到处出现临时实现。
- 措施2：在 UI 设计阶段明确“最大显示宽度”和“最大行数”等约束，并在实现中固化。
- 措施3：针对中英混排、不同字号场景做专项 UI 走查，避免字符个数截断这种不稳定方案。

## 可复用经验
- 经验1：前端 Canvas 中的文本渲染要与普通 DOM 文本一样重视“布局约束”，特别是宽度和行数。
- 经验2：构建可复用的文本绘制工具（如多行+省略号）能大幅降低后续维护成本。
- 经验3：与设计约定“文字不超过容器直径、最多两行”等视觉规范，是实现和验收的共同依据。
