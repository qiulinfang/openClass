# 作业作答页面按钮与交互逻辑说明文档

本文档详细描述了 `HomeworkAnswerView.vue` 中作业提交按钮、画板交互权限以及相关 UI 显示的逻辑判定规则。

## 1. 核心逻辑变量说明

| 变量名 | 来源 | 说明 |
| :--- | :--- | :--- |
| `isHomeworkSubmitted` | 本地/DB | 用户是否在当前 Session 或历史记录中点击并成功提交了作业。 |
| `status` | 服务端 | 作业的原始状态（如：1-进行中，3-已结束/已批改）。 |
| `resubmit` | 服务端配置 | 是否允许重复提交（'1'-允许，'0'-不允许）。 |
| `lateSubmit` | 服务端配置 | 是否允许逾期补交（'1'-允许，'0'-不允许）。 |
| `isExpired` | 实时计算 | 当前时间是否已超过作业的 `deadline`。 |
| **`isHomeworkLocked`** | **计算属性** | **核心判定位**。当该值为 `true` 时，画板禁用且提交按钮隐藏。 |

## 2. 状态判定矩阵

本矩阵描述了核心状态组合对 UI 表现（按钮文本、显示状态）和交互权限（画板书写）的最终影响。

| 序号 | 场景描述 | 本地提交状态 (`isSubmitted`) | 服务端状态 (`status`) | 重交配置 (`resubmit`) | 补交配置 (`lateSubmit`) | 截止状态 (`isExpired`) | **按钮文本** | **按钮显隐** | **画板书写** | **UI 提示文案** |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :--- | :--- | :---: | :--- |
| 1 | **正常作答中** | `false` | `1` | - | - | 否 | **提交作业** | 显示 | **允许** | - |
| 2 | **初次提交成功** | `true` | `1` | `0` | - | 否 | - | 隐藏 | **禁用** | 作业已提交 |
| 3 | **已交且允许重交** | `true` (UI解锁) | `1` | `1` | - | 否 | **提交作业** | 显示 | **允许** | - |
| 4 | **逾期允许补交** | `false` | `1` | - | `1` | 是 | **去补交** | 显示 | **允许** | - |
| 5 | **逾期不允许补交** | `false` | `1` | `0` | `0` | 是 | - | 隐藏 | **禁用** | **作业已截止** |
| 6 | **逾期且允许重交** | `true` (UI解锁) | `3` | `1` | - | 是 | **提交作业** | 显示 | **允许** | - |
| 7 | **已截止或批改且不可重交** | `false` | `3` | `0` | `0` | - | - | 隐藏 | **禁用** | **作业已截止** |
| 8 | **已提交且已逾期** | `true` | `3` | `0` | - | 是 | - | 隐藏 | **禁用** | 作业已提交 |
| 9 | **已结束但允许补交** | `false` | `3` | `0` | `1` | 是 | **去补交** | 显示 | **允许** | - |

> **注**：当 `resubmit === '1'` 时，系统在进入页面时会强制将本地 `isSubmitted` 视为 `false` 以解锁交互。

## 3. 关键逻辑实现规则

### 3.1 锁定逻辑 (`isHomeworkLocked`)
`isHomeworkLocked` 为 `true` 的触发条件（满足其一即可）：
1. `isHomeworkSubmitted` 为 `true` (用户已交)。
2. 且作业已截止 (`isExpired`) 且不允许补交 (`lateSubmit !== '1'`)，且**不属于**允许重交的情况。

### 3.2 允许重交的“特权”
在页面加载 (`onMounted`) 时，如果 `resubmit === '1'`，系统会强制执行 `isHomeworkSubmitted.value = false`。这会产生以下影响：
*   **解锁画板**：用户可以重新编辑之前的笔迹。
*   **恢复按钮**：顶部重新出现“提交作业”按钮。
*   **覆盖旧数据**：再次点击提交将产生新的作业快照。

### 3.3 画板与工具栏控制
*   **画板禁用**：通过 `:disabled="isHomeworkLocked"` 彻底拦截 `handlePointerDown` 事件。
*   **工具栏显隐**：通过 `:show-toolbar="!isHomeworkLocked"` 隐藏 UnifiedToolbar。

## 4. 维护与测试注意事项
*   测试场景 5 时，请确保系统时间晚于作业 `deadline`。
*   如果发现按钮文字消失且没有提示文案，请优先排查 `currentHomeworkInfo` 是否成功从 Store 中获取。
